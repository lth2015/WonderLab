# 13 · 远方怎样来到湖边

> 山川之间的生活长卷 · v0.4
>
> 看着同一片水，也能逐渐知道山后有林、林外有风，许多生命正在各自的地方生活。

## 一、远方先有一点动静

清晨，湖东边的水先起一层薄雾。

它沿着低处慢慢舒展，经过昨天那片荷叶。叶下的小鱼只露出一点尾，岸边的花苞比远山先显出来。

云眠原上，此刻草尖很湿。夜间聚起的水珠沿叶尖落下，浅沟把它们汇到坡脚。高地凉下来的空气也顺坡走，湖东边便有了这一点先于日光到来的朦胧。

湖边的人只看见雾，也已经与云原共同经过了一个清晨。

如果有一天走上那片高地，看见草间细细的水路，或许才会想起：原来湖上有些早晨，是从这里开始的。

## 二、同一场雨，有许多次抵达

海上的风带着湿意，先经过云眠原，再被北面的山脊抬起。云渐渐厚了，山的这一侧开始落雨。

高处的雨落在石上，声音短；林里的雨穿过好几层叶，落得更慢。树冠停留一阵，细枝停留一阵，苔与土又留下一阵。

听雨蜗探出触角时，湖上也许刚起风。

露角鹿在林缘把头偏了一点，让角尖的一滴水沿旁边的枝落下。水经过那段枝，落到一片宽叶；叶低下去，另一滴才接着落。

到湖边时，这场雨已经有许多不同的步子。

远处雨线先把山遮住，近处水纹渐渐密起来。人画的那条鱼在更靠上的水层游，身上的小弯断断续续经过一圈圈雨纹。海棠上的蝶已经找到背风的叶下，花仍轻轻向水倾着。

雷把山脊照清的一瞬，能看见同一场天气正在经过很远的地方。

雨停后，湖面先亮。林里的水还在往下走。许久以后，入水口仍有一段清而细的水声。

**天空的雨和林里的来水，可以前后抵达同一片湖。** 地方因此拥有了远近，也拥有了长短不同的光阴。

## 三、一片花的路，和一粒种子的路

一朵林缘的海棠先松下一瓣。

瓣落到溪里，绕过浅石，停在一片草的后面。水涨一点，它又被轻轻托开，后来才到初生湖的北岸。

它经过湖面时，颜色已经淡了。鱼碰了一下，花瓣转身，慢慢走向出水口。人若只见到这一刻，也许会想到水外还有正在开花的枝。

另一条路在枝头。

衔花雀来访过这片林，春天衔走一瓣花，秋天又从结实的枝旁带走一粒小种。它在花信溪的低枝歇脚，种子落入岸边湿土，安静地过了一段日子。

来年有了细小的新叶。更晚一些，才有能够让谁停脚的枝。

花瓣带来的是一段颜色与气息；种子在适合的地方展开新的生长。它们有各自的来路，也各有抵达以后的事。

这使一片新花有了两种可读的远方：眼前的颜色可能从上游漂来，岸上的新枝则可能来自很久以前的一次短飞。

## 四、芦苇后面，还是它熟悉的水

湖的南侧有一道芦苇弯。

水在这里缓下来，草根之间有细小的空隙。离开开阔湖面的鱼，先在这一段安静的淡水里停留。

一条尾部带弯的旧鱼，有时沿弯出去一点。它经过水草背后的凉处，遇见更细的溪纹；有时只在芦苇下转身，回到原来的水面。

回来的那一次，它从远岸边显出轮廓，仍带着起笔的小弯。人先看见熟悉的形，再想起它曾经经过荷叶、月光或一盏灯。

芦苇弯使“去了远处”有了可以想象的生活：那里有同一条水路，也有适合暂歇的地方。相认可以从一次重新经过开始。

更下游，花信溪逐渐变宽。锦鲤在淡水丰足的河湾停下，潮纹鱼在潮水里转向。淡水的来者和海边的居民，在各自合适的水中看见彼此。

海于是有了一种很温和的抵达：先听见新的水声，再看见另一种鱼。原来的生命仍有自己的栖居，远方也有自己的居民。

这里的旧鱼回游，写给“湖满后暂居远处”的创作方向。人亲手选择的一次告别，另有属于它的心意；具体来去仍承接既有产品约定。

## 五、一段风，让三种步子接上

午后，风从云眠原的凹地抬起。

最先动的是草。白色种絮离开草尖，一只风籽雀跟着起身。它沿暖风滑了一小段，在疏林边收住翅。

林里的衔花雀正准备去溪对岸。两只雀在同一片光里同行了一阵，一只继续借风向上，一只落到更低的枝。

低枝是人添的，末端还有起笔时留下的小弯。

风到湖边轻了一些，枝端先晃，花瓣再翻过身，最后水面添了一段比雨纹更长的细波。鱼转过来，从荷叶的暗处进入那段亮水。

这样一段风，可以把高地、林缘、花枝与湖面连在一起。各处有自己的速度，共同的方向仍能被看见。

风停时，雀有枝，种絮有凹地，鱼有水草。停下来也能把这幅画接完整。

## 六、鲸先经过水上的光

有一天下午，湖面忽然柔暗了一点。

山与水仍在，近岸的白花也还清楚，只是明亮的范围正在缓慢移动。人先低头看见一段影，抬头时，云边才露出鲸的一侧鳍。

它来自更长的海风，在高地的凉里渐渐有了身体。小云鳐沿它的影子走到山口，随后折回自己的云边；鲸继续往北，把一段细雨留在更远的坡上。

湖边只看见一次经过，也能知道：它有刚才来的地方，还有接下来要去的方向。

大鲸离开以后，那场雨慢慢进入山间细流。过了许多天，湖里又多一段清水。人也许没有把两件事立刻连起来，水路已经替它们接上了。

鲸的辽阔因此能在近处被感到：一次抬头、一片影、一阵后来才到的来水。那条最初的小鱼，仍在这些变化里拥有自己的日子。

## 七、春天怎样走得有长有短

这里的春天可以从南方的河湾先显出花色，再沿温暖的岸往上走；高处融雪的春水，则从北面缓缓往下到来。

两种路在湖边相遇。

湖岸已经有几朵花时，山上仍留着雪。林间有一处向阳坡先发出新叶，背阴的苔旁还留着冬天较慢的滴水声。

一个季节能够同时拥有这些差别。海棠枝上的一朵花与远山的一段雪，可以在同一片光里各自成立。

来者也能请来自己想看的时景。那是另一种亲近天地的方式：眼前呈现冬日，生命带着已经共同经历的春雨继续生活。

有的地方长留在暖季，有的地方愿意让四时经过。它们共享山水相接的道理，花开的日子与来水的快慢仍可以不同。

## 八、朋友的天地，在另一种远方

水路连接山、林、湖与海。朋友的湖则由远岸相接。

给朋友的一条鱼，可以从相同的笔迹醒来，随后认得另一片水。这里的花瓣顺溪向南，朋友那里正在下雪；同源的鱼已经开始两段不同的生活。

两种联系因此有了各自的温柔。

一方天地里的水、风与迁徙，使生命在同一个大世界里相互照应。一份主动送出的来处，让两个人各自的天地拥有可以回望的共同起点。

有天，朋友说那条鱼喜欢走月光边。发送的人想起自己的那条常在叶下停留。两个小小的习惯，使同一个弯有了两种可以讲述的后来。

人愿意讲时，故事越过远岸。水与风在各自的天地继续照顾生命。

## 九、一片湖，已经足够宽阔

把这些日子放在一起看：

| 眼前遇见的一点事 | 画面外正在生活的地方 |
|---|---|
| 东岸先起薄雾 | 云眠原湿草、坡脚与清晨的凉空气 |
| 雨停后，入水口还在细细响 | 听雨林的树冠、苔和慢慢走来的水 |
| 一瓣颜色渐淡的花经过 | 上游的枝、浅石与曾经留住它的草 |
| 旧鱼从芦苇旁重新显出那个小弯 | 连着湖的缓水与可以歇息的湾 |
| 风先动枝，再动花，最后动水 | 高地的草、林缘的雀和刚过去的同一阵风 |
| 湖面被一片移动的影轻轻遮住 | 云中的鲸与它将要经过的山口 |
| 远山有雪，近岸有花 | 高低与朝向不同的坡，也有各自的春天 |
| 一条来自朋友的鱼在月光边停留 | 另一方天地里，共同起点展开的另一段日子 |

一方天地的完整，可以藏在这些联系里。生灵并非都要同场出现；它们在各自适合的地方生活，偶尔有一点痕迹来到近处。

来者坐在湖边，仍可以自在地画一条小鱼。世界很大，这一笔也有值得认真相处的位置。
