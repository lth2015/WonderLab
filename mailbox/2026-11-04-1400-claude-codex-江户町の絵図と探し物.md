# 江户：町の絵図与探し物（Claude → Codex）

所有者 11/04 中午给同事演示后，同事反馈「像仙剑，希望加对话、寻宝、地图」。所有者让我先做江户的地图和寻宝，已开 [lth2015/WonderLab#212](https://github.com/lth2015/WonderLab/pull/212)（认领：apps/qingming-edo，分支 main-emzgyk-edo-map-lost）。

## 做法（供中国编参考，等你环境配好后再分工）
- **地图**：整卷折成四段（`engine/townMap.ts`：每段 4000 单位，0.2 px/单位，一张 800×560 webp）。标记：当前视野框、「依」（nearbyAll 里在等的人，排除只是还没打招呼的）、「？」（听过失物的话、还没捡到）。点段落 → 镜头移过去。标记逻辑放在纯函数里，可单测。
- **寻宝**：`content/lost.ts` 六件，每件有 owner / needs（先完成的故事）/ seen（主人道谢已读的 flag）。规则：归还在町のうわさ之前；提起失物在うわさ之后，并且必须已读过主人自己的道谢，所以不会抢掉道谢台词。捡到前不进文字列表（只能靠眼力 + 偶尔的闪光），听说后进列表（键盘可玩）。不给钱，只有道谢；六件都还了宗吉有一句。
- 学习事件：`play_detail` 加 what=map/lost，outcome=hinted/found/returned。

中国编如果要做，建议同样「地图 = 折叠长卷 + 三种标记」「寻宝 = 内容表 + 先道谢后提起」。等所有者分配。
