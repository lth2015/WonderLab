## R1：十二故事对照世界观的阅读意见（已完成，只读）

阅读基线 main@44f6e38：前三话在 content/script.ts，另九话在 content/stories/{kashi,fumi,yube,ai,hashi,neko,inkyo,ugoki,ame}.ts。对照 value 分支 01、07、14、15 篇。两作是画卷人间，世界观提供创作原则，不要求把湖里的生命机制硬套进历史街巷。

### 对上的

- 風のいたずら：从扶纸这样小动作建立相识；师父先看人的手，再画城。起点具体，亲历决定画页。
- 道具包み：父亲留下的便当盒、每年补漆，使物有来处；亲送和托付都能有自己的结果。
- 藍の手拭い：结法/波纹是可相认的「痕」，亡妻染布的来处落在每日使用里，不只是一件寻物道具。
- 河岸の子：祖母凭声音认出孩子，一起看完卸货后孩子自己起身；别人有自己的愿望，玩家可以陪着。
- 母への文：保留原信与补写柳色都有去处；故事没有替所有人规定唯一正确的孝心。
- 夕べの灯：三十年点灯的人受邻里照应，光把街道远近串起来；玩家能看到动作之后的街景。
- 朝の藍：颜色来自光与晾晒的时间，世界本身也在参与创作，晨光有具体作用。
- 橋のたもと：旧故事里的人带着旧物重新相见；回收便当盒、手巾、书信等经历，比凭空合照厚实。
- こはく：猫先有看船的偏好，玩家肯等，它才自己靠近；回茶摊后的作息也延续这个生命。
- 川端まで：老人走自己的步子，听往事或一起安静都成立；没有要求用说话来证明陪伴。
- 動く人：观察人的来往，再记住经过的一瞬；街上继续有自己的生活。
- 雨宿り：借伞继续流向下一个雨天，给予没有系住收下的人；雨改变人站的位置，而非只有屏幕滤镜。

### 偏了的／后续应留意的

1. **描线目前留下固定范本。** 很适合低门槛入门，但离「最初一笔的弯还能被认出」还有距离。现阶段应明确是引导写生，不宣称保留了个人手绘作品；以后若要保存个性，先决定本机数据边界，不能顺手上传轨迹。中国本次也明确只存固定笔段。
2. **找齐三个／跑遍几处的结构较密。** 灯、藍、雨伞、合照都成立，但连续玩容易变成清单。真人试玩先看玩家能否说出谁变了，再决定是否把下一段做成可停留、非收齐式的故事；本轮无需再扩任务数量。
3. **有几处结尾把意味说满。** 如借伞的“返ってこなくてもいい”是喜助自己的话，可以保留；后续少再添旁白总结，把伞下的人重新上路、老人坐定等结果留给玩家看。温柔不必每次变成一句哲理。
4. **绘卷帐满本与生活继续之间有张力。** 师父“また歩け”已经化解一部分；之后不要只靠加页数来表达世界还在。相熟人物再见时的细小差异，比无限册满奖励更合方向。

这些是创作阅读意见，不是阻塞修复；没有修改江户代码、测试句或发布安排。C3 完成后建议按已定计划进入真机/真人试玩，再按观察修入口与反应。
