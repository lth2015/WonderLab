# 汴河拾光 · 清明上河图中国篇

手机浏览器优先的本地脚本小游戏。六位原创角色、三条微故事、理绳与茶摊配席两种轻互动、十二页画册、1440×1800 PNG 留念、本地存档与 JSON 导入导出。无需账户或服务端。

在仓库根目录安装依赖后：

```sh
npm run dev:qingming
npm run test:qingming
npm run build:qingming
```

也可在本目录运行 `npm ci`，然后 `npm run dev`、`npm test`、`npm run build`。本地开发地址为 `http://localhost:5175/`，本目录的独立构建输出为 `dist/`。依赖版本已锁定，可复用仓库上层已安装的 React/Vite。

## 玩法

- 点击「入画」，替小柳压住画纸，选择构图后落笔。
- 拖动画卷双向探索；桌面也可使用两侧箭头或聚焦街景后的左右方向键。
- 「附近」列出三条故事，展开文字探索可以找到所有人物与八处环境互动。
- 理绳可拖拽，也可先点绳索再点对应系缆点，不限时。
- 茶摊配席按两位客人的偏好选择；错误选择可以修改。
- 香囊需观察绣纹，再问何娘与阿成，最后归还。
- 「画册」打开已记录的画页并保存 PNG。纸铺可换构图，船运可换路线重逢补页，不重复奖励。
- 师父会回应玩家实际选择的画页；今日小记只记录发生过的事。
- 「设置」可开关声音、减少动态、大字与提示，并导入/导出本作存档。

## 隔离与发布

`base: './'` 使同一静态构建可放在 `/qingming/` 或独立域名 `/`。场景深链接采用 `?scene=paper|bridge|tea`。未配置服务工作线程。

存储键为 `ww:qingming-china:save:v1`，拒绝江户版和未来未知版本存档；支持 `saveVersion: 0 → 1` 的音量迁移。损坏存档在显式备份或导入前不会被自动覆盖。所有奖励由本地确定性状态机一次性发放，不是联网防作弊系统。

公共 TypeScript 契约位于 `../../packages/scroll-contracts/index.ts`，与应用一起构建，不需单独安装公共包。它是待江户侧核对的初始提案，不宣称已共同冻结。

详细限制、资产来源与验收记录见 `../../docs/painted-worlds/china-implementation.md`。
