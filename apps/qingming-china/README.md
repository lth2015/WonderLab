# 汴河拾光 · 清明上河图中国篇

手机浏览器优先的原创脚本小游戏。当前候选包含24000×1200连续长卷、六位街头角色与货港/城门/乡野三位新相识、六段免费小故事、15页画册、1440×1800 PNG留念、本地存档与JSON导入导出。无需账户或服务端，默认静音，没有真实支付。

仓库根安装后：

```sh
npm run dev:qingming
npm run test:qingming
npm run build:qingming
```

也可在本目录运行npm ci与npm run dev/test/build；可复用上层已安装依赖。默认开发端口5175，独立产物dist/。根站全量build另将作品放入dist/qingming/。

- 入画后到纸铺压纸、选构图/题签，留下第一幅画；也能自由拖卷、方向键或通过附近文字路径探索全部人物和环境。
- 原三故事是一纸春风、这一船日常、谁的香囊；后续货港《半步相让》、城门《认得归路》、乡野《这一程，不催》。后三段均0文奖励，原三段合计54文，初始60文。
- 理绳有拖拽与点按替代；茶摊按偏好配席；失物靠观察与询问。错选可改，没有限时、永久失败或体力限制。
- 画册15页均有实际事件来源，师父与小结只回应实际记录；原14页ID和顺序保留。回放能补构图/路线，不重复领奖。
- 顶部“春日”可回看已达晨/昼/暮；默认随故事流转，设置会保存。减少动态、大字150%、闲时提示与音量均在设置中。
- 设置的“本次试玩记录与隐私”主动导出本机内存操作类型/耗时，无身份、对话、原URL或存档内容，不上传；刷新清空。详见docs/painted-worlds/china-playtest-v1/。

相对base支持/qingming/与独立域名根路径，scene查询只接受章节白名单。未配置service worker。存储键ww:qingming-china:save:v1，当前saveVersion4，兼容v0/v1/v2/v3；拒绝跨作和未来未知版本，损坏档显式处理前不覆盖。奖励是本地确定性状态机，不是联网防作弊系统。
