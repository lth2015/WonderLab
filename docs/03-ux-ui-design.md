## 1. 美学方向：夜湖水墨

**一句话：** 一幅会呼吸的水墨夜景。墨在宣纸上洇开的质感，配上月光与萤火的微光。

| 关键词 | 是 | 不是 |
|---|---|---|
| 水墨 | 墨的浓淡干湿、晕染、留白 | 国潮贴纸、仿古边框、红灯笼堆砌 |
| 夜色 | 深而透的蓝黑，有层次 | 纯黑 #000、霓虹赛博 |
| 微光 | 月光、萤火、水面反光，克制的辉光 | 大面积高饱和发光、镜头光晕 |
| 运动 | 像水和风一样的缓慢、连续 | 弹跳、闪烁、游戏化的爆点特效 |
| 留白 | 画面至少 40% 是“空”的 | 塞满物体和装饰 |

**参照：** 宋代山水的远近层次（近水、中山、远空）；吴冠中的点线面；水墨动画《小蝌蚪找妈妈》的墨韵。参照的是方法，不是照抄画面。

**渲染手法要点（交给实现）：**

- 远山：多层带噪声边缘的剪影，越远越淡、越偏冷色（空气透视）。
- 墨迹：笔画渲染成带“飞白”和边缘晕染的墨线（基于速度控制粗细，用噪声纹理控制边缘），不是均匀的矢量线。
- 鱼：身体由墨的浓淡构成，半透明，鳍和尾的边缘洇开；运动采用沿脊线的正弦摆动。
- 水面：深色，带缓慢流动的法线扰动；倒影随波纹轻微扭曲。
- 月光倒影：不是镜像的圆盘，而是被波浪打碎的一道竖向光带（浮光跃金），近地平线处最亮，向观者逐渐稀疏；倒影圆盘本身的亮度封顶到周围夜空的水平，不能留下一块“贴纸”。
- 鱼尾：分叉、末端渐隐，任何时候都不能出现直线截断。
- 全局：极轻的宣纸颗粒纹理叠加（opacity ≈ 0.04），让画面不显得“太数码”。

## 2. 构图与空间

```
┌──────────────────────────────────────────┐
│                                    ◐ ⏺ ⋯ │ ← 右上角控件区（安全区内）
│            天 空 区                         │
│       （星、月、云、天气）                    │   约 50%（桌面）/ 45%（竖屏手机）
│  ～～～～ 远 山 剪 影 ～～～～～～～～～～～～  │
│━━━━━━━━━━━━ 水 天 线 ━━━━━━━━━━━━━━━━━━━━━│
│            湖 面 区                         │
│       （鱼、涟漪、倒影）                     │   约 50% / 55%
│                                           │
│        ╭──────────────────────╮           │
│        │  写一句话…           ↵ │           │ ← 底部输入框（安全区内）
│        ╰──────────────────────╯           │
└──────────────────────────────────────────┘
```

- 水天线位于画面高度的 50%（桌面横屏）或 45%（竖屏），这是天空与湖面识别区域的分界。
- 竖屏时湖面区域更大，因为大部分创作（画鱼）都发生在这里。
- 实体的位置用**归一化坐标**（0–1）存储，窗口变化时按比例重新布局。
- 输入框和控件都不遮挡水天线附近的区域，这里是视觉焦点。

## 3. 色彩

### 3.1 界面色（UI Chrome）

界面控件始终叠在深色的半透明墨底上，以保证在任何世界氛围下都可读。

| Token | 值 | 用途 |
|---|---|---|
| `--ink-950` | `#0B0E13` | 最深的夜色，页面底色 |
| `--ink-900` | `#121721` | 控件实底 |
| `--ink-glass` | `rgba(12, 15, 21, 0.62)` + `backdrop-filter: blur(12px)` | 输入框、浮层的底（高档位） |
| `--ink-solid` | `rgba(12, 15, 21, 0.82)`，无模糊 | 低档位替代 `--ink-glass`：模糊叠在逐帧变化的画布上开销很大 |
| `--paper-100` | `#EFEADF` | 主文字（月白宣纸色） |
| `--paper-300` | `#C9C3B6` | 次要文字、占位符 |
| `--paper-500` | `#8E897F` | 禁用状态、分隔线 |
| `--cinnabar` | `#C8553D` | 朱砂：录制状态、印章水印 |
| `--moonlight` | `#E9D9A6` | 月光金：焦点环、强调 |
| `--focus-ring` | `2px solid var(--moonlight)`，外偏移 2px | 键盘焦点 |

**对比度（WCAG）：**

- `--paper-100` 叠在 `--ink-glass` 上（底下是最亮的“白昼”氛围时）≥ 7:1。
- `--paper-300` 叠在 `--ink-glass` 上 ≥ 4.5:1，可以用于占位符和次要文字。
- 朱砂只用来表示状态和装饰，必须同时配合图标或文字，不能单独靠颜色传达信息。

**直接写在画面上的提示文字**（不在玻璃底上）：默认使用 `--paper-100` 加暗色光晕 `text-shadow: 0 0 12px rgba(0,0,0,.6)`。文字颜色按**文字背后区域的实际亮度**决定（引擎提供该区域的平均亮度），不按时段切换；当背景亮度过高时改用 `--ink-900` 配浅色光晕。PoC 的色板都是暗调，通常只会用到浅色文字。

### 3.2 世界色板（随氛围变化）

每个 `palette` 是一组 5 个颜色：天顶、天际、远山、水面、点缀。氛围切换时在 OKLCH 色彩空间中插值，避免中间出现灰色。

**P0 只做前三套**（serene、warm、melancholy），配合两个时段（night、dusk）。其余三套作为储备，等 P0 的组合都通过艺术验收后再启用。

| palette | 天顶 | 天际 | 远山 | 水面 | 点缀 |
|---|---|---|---|---|---|
| serene（默认夜） | `#0E1524` | `#22314A` | `#2B3646` | `#0C141F` | `#E9D9A6` 月光 |
| melancholy | `#14161D` | `#2E3440` | `#3A3F4A` | `#11141A` | `#9FB3C8` 冷雾蓝 |
| warm | `#2A1A1F` | `#7A4A3A` | `#4A3330` | `#1E1517` | `#F0B46A` 暖金 |
| mysterious | `#120F22` | `#2C2350` | `#2A2440` | `#0D0B18` | `#9C8CF0` 幽紫 |
| joyful | `#16243A` | `#3E6A8A` | `#34506A` | `#122234` | `#F4C9A8` 桃色 |
| cold | `#0F1A22` | `#2F4A5A` | `#3C5260` | `#0D171E` | `#DCEBF2` 霜白 |

`timeOfDay` 会在色板的基础上调整明度：dusk 抬高天际的明度和暖度。（储备中的 dawn、day 同样保持“水墨淡彩”的低饱和度，避免变成明亮的卡通风格。）

墨色本身随色板变化：夜色中的墨偏蓝黑，暖色调中的墨偏褐。鱼的点缀色取自当前色板的“点缀”色。

## 4. 字体

中文字体文件很大，所以采用**系统字体为主、风格字体按需加载**的策略。

| 角色 | 字体 | 加载方式 |
|---|---|---|
| 界面文字（按钮、输入框、提示） | `"PingFang SC", "Noto Sans SC", "Microsoft YaHei", system-ui, sans-serif` | 系统字体，零加载 |
| 诗意文字（echo 诗句、情境提示） | `"LXGW WenKai"`（霞鹜文楷，开源 SIL OFL） | **只包含句库和固定文案用到的字**（字符集已知，约 1–2 千字以内，目标 < 300KB），空闲时预加载，`font-display: optional` |
| 诗意文字的后备 | `"Kaiti SC", "STKaiti", "KaiTi", serif` | 文楷没加载完就直接用系统楷体，**不在显示过程中切换字体** |
| 加载标语「一念起，万象生」、品牌印章 | 设计成 SVG，不使用字体 | 内联 SVG |

echo 诗句和墨点文字需要录进视频，因此它们在画布内渲染（文字先绘制到离屏 canvas，再作为纹理使用），不是 DOM 文字。

**字号：**

| 用途 | 桌面 | 手机 |
|---|---|---|
| 首屏提示、情境提示 | 20px / 字距 0.08em | 18px |
| echo 诗意回应 | 28px / 字距 0.15em | 22px |
| 输入框文字 | 16px（防止 iOS 缩放） | 16px |
| 按钮标签、tooltip | 14px | 14px |

行高 1.6。不使用 12px 以下的字号。

## 5. 界面结构与控件

### 5.1 常驻控件（总共 4 个，遵守 P6）

| 位置 | 控件 | 形态 | 说明 |
|---|---|---|---|
| 底部居中 | 一句话输入框 | 玻璃底胶囊，桌面宽 min(480px, 90vw)，高 48px | 占位符「告诉这个世界你在想什么…」，不轮换示例句（02 §5.3：画是主角，写是魔法） |
| 右上角 | 声音开关 | 图标按钮 | 静音/有声两种状态，图标不同 |
| 右上角 | 录制 | 图标按钮（圆点） | 录制中变为朱砂色进度环 |
| 右上角 | 更多 | 图标按钮（⋯） | 菜单：撤销、重新开始、关于 |

- 图标统一使用 Lucide（描边 1.5px，尺寸 20px），不使用 emoji。
- 每个图标按钮的可点击区域是 44×44px，即使图标本身只有 20px；按钮之间间隔 ≥ 8px。
- 每个图标按钮都有 `aria-label`，桌面悬停 400ms 后显示文字 tooltip。
- 控件面积预算：桌面 < 5%，手机 < 8%（见 01 P6）。手机上输入框保持展开，因为它是“一句成境”唯一的发现入口。

### 5.1.1 临时控件：「墨散」撤销按钮

- 每次创造完成后，在新创造物旁边出现一个小的墨点按钮（可点击区域 44×44px，`aria-label="撤销这次创造"`），4 秒后淡出。
- 点击后撤销这次创造，被撤销的东西以墨散的方式消失。
- 它不算常驻控件，也不会被录进视频。

### 5.2 作画时控件自动隐退

- 落笔时，所有控件在 200ms 内淡出到 opacity 0.15（不完全消失，这样用户知道它们还在）。
- 抬笔 1.2 秒后恢复。
- 输入框获得焦点时，不会自动隐退。

### 5.3 输入框行为

- 回车或点击 ↵ 按钮提交；空内容时提交按钮处于禁用状态。
- 提交后：文字以墨点形式飘向天空（约 800ms），输入框清空并保持焦点（桌面）或收起键盘（手机）。
- 字数达到 40 时显示计数「40/50」，到 50 时不能再输入。
- 被限流时，输入框下方显示一行轻声提示（`--paper-300`，`aria-live="polite"`），5 秒后淡出。
- 字数计数等辅助信息如果需要用颜色表示状态，必须同时配合文字。
- 手机上软键盘弹起时，输入框随 `visualViewport` 上移，始终在键盘上方。

### 5.4 浮层

只有两种浮层：录制完成后的预览浮层，以及“更多”菜单。

- 预览浮层：居中，底下是 50% 不透明度的墨色遮罩；视频预览循环播放；操作按钮为「保存」（主要操作，唯一的实心按钮）、「重录」、「放弃」。
- “更多”菜单支持 `Esc` 和点击遮罩关闭。预览浮层在 `Esc` 或点击遮罩时先询问「放弃这段作品？」，避免误触丢掉作品。
- 打开浮层时焦点移入浮层，关闭后焦点回到触发它的按钮。
- 浮层从触发点附近缩放淡入（200ms），退出时 140ms。

### 5.5 提示条（Toast）

只用于“重新开始”之后的撤回：「世界已重置 · 撤回」，底部输入框上方，5 秒后自动消失，`aria-live="polite"`，不抢焦点。

## 6. 交互规范

### 6.1 指针与笔触

- 统一使用 Pointer Events，同时支持鼠标、触屏和触控笔。
- 画布设置 `touch-action: none`，阻止滚动、下拉刷新和双指缩放干扰作画。页面本身没有滚动。
- 桌面光标：自定义毛笔笔尖光标（SVG，热点在笔尖）；悬停在可点击的鱼或月亮上时，光标变成手指形状的墨点。
- 笔触粗细：鼠标根据速度变化（越快越细）；触控笔使用 `pressure`；手指使用固定的中等粗细，再叠加速度变化。
- 笔迹跟手：用预测点（`getPredictedEvents`，如果支持）和 `getCoalescedEvents` 提高平滑度；落笔到墨迹出现 ≤ 1 帧。

### 6.2 判定阈值（对应 02 §4 判定表）

| 参数 | 初始值 | 说明 |
|---|---|---|
| 点按位移阈值 | 8px | 位移小于它算点按或长按 |
| 长按时长 | 500ms | 小于 500ms 的按压一律按点按处理（没有空档） |
| 短笔上限 | 路径长度 < 画面短边的 6% | 判定表 #3 |
| 闭合 | 首尾距离 < 包围盒对角线的 25%，或转过的角度 ≥ 330° | 判定表 #4、#5。“转过的角度”见下方说明 |
| 圆度 | 包围盒长宽比 ≤ 1.6，且圆拟合残差 < 半径的 18% | 不满足的闭合形状按“细长”处理 |
| 弧 | 转过的角度 150°–330° 且圆拟合残差 < 半径的 18% | 判定表 #6 |
| 月相 | 闭合 → 满月；240°–330° → 凸月；150°–240° → 弦月/新月 | |
| 笔性：快 | 速度 ≥ 分界（画面短边 / 秒）：鼠标 0.5、触屏 0.8、触控笔 0.7 | 首轮值；用 `npm run calibrate` 的「笔性分界」按真实笔迹重定（`src/engine/koi-style.ts`） |
| 笔性：弯 | 平滑后总转角 ≥ 0.5π（约一个直角） | 同上 |
| 本族花色几率 | 75% | 其余 25% 在其他花色中均匀选 |
| 鱼的命中半径 | max(鱼身长的一半, 22px)，沿游动方向前移 0.15 秒的位移 | 手机上点得中 |
| 屏幕边缘 | 左右 16px 内开始的手势不作画，仍可点按 | 避免与系统返回手势冲突 |

- 点按：落笔瞬间先显示墨点，抬手时墨点化为涟漪（湖面）或星光（天空）。
- 多指：第二根手指落下时取消当前笔画，墨迹淡出。
- 示范笔触播放期间，点击虚影等同于用户落笔（示范结束），不会出现点了没反应的情况。
- 转过的角度：笔画能拟合成圆（残差 < 18%）时，取绕拟合圆心扫过的角度；否则取笔画的净转角。净转角在每 4px 重采样、平滑后计算——慢速起笔收笔时的手抖会产生大量小锯齿，逐点累加会把半圆算成几度、把 U 形算成几百度。
- 阈值用 02 §4 的测试用例集调整，调整后更新本表：把 `?collect` 导出的文件放进 `strokes/`，运行 `npm run calibrate -- --sweep`，得到各形状的判定分布、验收结果、判错的笔及其测量值，以及按验收排序的候选阈值（只是建议，由人决定改不改）。`--synthetic` 用合成笔迹替身试跑，不能单独作为调参依据。

### 6.3 反馈时序

| 阶段 | 时间 |
|---|---|
| 落笔到墨迹出现 | 下一帧（≤ 16ms@60fps） |
| 任何输入的第一个可见反馈 | ≤ 100ms |
| 界面控件的状态变化 | 150–250ms |
| 世界内的创造动画（化鱼、月升） | 1.2–1.8s，默认 1.5s（叙事动画，有意放慢） |
| 氛围过渡（一句成境） | 3–6s，默认 4s；强度越大越长 |
| AI 指令等待上限 | 2.5s，超时只用本地结果 |
| echo 有效时限 | 提交后 3s 内到达才显示，显示 4s 后淡出 |
| 首次进入后示范笔触 | 无操作 4s 后播放，最多 2 次 |
| 情境提示 | 显示 6s 后淡出；被错过可再出现 1 次 |
| 作画时控件隐退 | 落笔 200ms 内淡到 0.15；抬笔 1.2s 后恢复 |

所有动画都**可以被打断**：用户在化鱼动画进行中继续作画、点击，都会立即响应，绝不因为动画而锁住输入。

## 7. 动效语言

**原则：** 像墨在水里、风过湖面——连续、有惯性、没有生硬的起止。

| Token | 值 | 用途 |
|---|---|---|
| `--ease-ink` | `cubic-bezier(0.22, 1, 0.36, 1)` | 墨的晕开、实体出现（快起慢收） |
| `--ease-exit` | `cubic-bezier(0.55, 0, 1, 0.45)` | 退出、消散 |
| `--dur-micro` | 160ms | 按钮状态 |
| `--dur-ui` | 220ms | 浮层、控件隐退 |
| `--dur-create` | 1500ms | 化鱼、月升 |
| `--dur-atmos` | 4000ms | 氛围过渡 |

- 鱼的游动、群体行为、水波使用物理或程序化运动（弹簧、噪声、转向力），不用固定时长的补间。
- 同一时刻只有一个“主角”动画：化鱼时，其他鱼的游动不变，但不同时触发月升等其他大动画（如果用户同时触发两个，依次播放，间隔 ≥ 300ms）。
- 界面元素只对 `transform` 和 `opacity` 做动画。

### 7.1 世界里的关系（对应 02 §5.5）

数值在 `src/engine/relations.ts` 的 `RELATIONS` 里，改了同步更新本表。

| 关系 | 条件 | 表现 | 数值 |
|---|---|---|---|
| 月下跃鲤 | 有月亮 | 不时有一条鱼游到月亮倒影处；到了之后有一定几率跃出水面，月光一亮，轻磬一声 | 每 7–13 秒一条鱼去看月亮；跃起几率 45%；两次跃起间隔 ≥ 18 秒 |
| 雨中浮鱼 | 下雨 | 鱼浮近水面，不时在头部点出一圈小涟漪 | 雨量 ≥ 0.45 时每 2.5–6 秒一次（雨越大越密）；鱼深度减少 70% |
| 雾里鱼影 | 起雾 | 鱼略沉，影子变淡 | 影子不透明度最多减 65% |
| 群鱼成圆 | ≥ 4 条鱼在游，且 8 秒没有落笔 | 鱼各自就位，首尾相接绕成一个扁圆（随湖面形状，宽约为高的两倍），游一圈左右后散开；成圆时月光一亮（有月亮时）、轻磬一声 | 两次之间 40–80 秒；持续 14 秒；落笔、按键、重新开始立刻散开 |
| 本命鱼回出生地 | 停手 ≥ 20 秒，有本命鱼在游 | 它游回最初落笔（收笔）的地方，停留片刻的牵引 | 每 45–90 秒一次机会，几率 50%；牵引 8 秒 |
| 写给鱼的话 | 一句成境里有 explore / gather / rest / play（02 §5.3） | 游向最远的湖边 / 绕成一圈或聚到本命鱼身边 / 慢下来浮近水面 / 一两条先后跃起 | 探索牵引 9 秒；聚拢牵引 6 秒；休息 20 秒，速度降 60%；跃起 2 条，间隔 0.7 秒 |
| 本命鱼应声 | 点空白湖面 | 它从更远处（画面短边 75% 内）更快地游来 | 约七成；速度 ×1.35 |
| 流星入湖 | 天上画一笔向下、终点离地平线不到天空高度 20% 的流星 | 流星划到地平线落进湖里，水花，游出一条小的淡金色发光的鱼 | 发光的鱼计入鱼的上限，可保存；撤销流星时一起消散 |

- 这些都是世界自己的回应：不产生撤销步骤，不计入「创造」，事件日志记为 `emerge`。流星入湖属于用户画的那颗流星，跟着它撤销。
- 减少动态效果时只保留雨和雾的关系，不跃起、不成圆。

## 8. 无障碍

画布艺术本质上是视觉的，我们尽量让它对更多人可用，并对局限保持诚实。

- **键盘：** 画布本身可以获得焦点（`tabindex="0"`），Tab 顺序为画布 → 输入框 → 声音 → 录制 → 更多。**只有画布获得焦点时**，按 `F` 在湖面随机位置“画”出一条鱼，按 `M` 生成月亮，按 `Enter` 在随机位置点一下——单键快捷键不会和输入框打字冲突（符合 WCAG 2.1.4）。快捷键列在“关于”中。（P1）
- **屏幕阅读器：** 画布设置 `role="img"`，并且有动态的 `aria-label` 描述当前世界（例如“夜晚的湖面，有月亮和三条小鱼，正在下小雨”）；每次创造通过 `aria-live="polite"` 播报一句（例如“一条小鱼游入湖中”）。
- **减少动态效果（`prefers-reduced-motion: reduce`）：**
  - 关闭视差和镜头漂移；雨保留，但改为稀疏、缓慢的细雨（不改变用户表达的语义）。
  - 化鱼、月升改为 600ms 的淡入，不做生长过程。
  - 鱼的游速降低 50%。
  - 示范笔触改为静态的虚线提示。
- **对比度：** 遵守 §3.1。焦点环在所有背景上都可见。
- **不只靠颜色：** 录制状态同时有朱砂色、进度环和「录制中」文字（屏幕阅读器可读）。
- **缩放：** 不禁止页面缩放（`viewport` 中不设置 `user-scalable=no`）；画布内的双指手势由 `touch-action: none` 处理。

## 10. 画质分级

PoC 只做两档，减少调试和验收的组合。

| 档位 | 像素比上限 | 鱼上限 | 粒子 | 后期效果 | 界面底 |
|---|---|---|---|---|---|
| 标准 | 1.5（桌面独显可到 2.0） | 12 | 全量 | 颗粒 + 轻辉光 | `--ink-glass` |
| 轻量 | 1.0 | 6 | 40% | 无 | `--ink-solid` |

- **帧率目标：** 标准档 60fps；轻量档至少 30fps 且稳定。
- **按帧耗时判断，不按帧率：** 统计每帧的 CPU/GPU 耗时。连续 3 秒有超过一半的帧耗时超过帧预算时降档。iOS 低电量模式会把刷新率锁在 30fps，这种情况下帧耗时并不高，不会被误判。
- **忽略干扰：** 页面从后台切回前台、窗口缩放之后的 2 秒内不统计。
- **可以回升：** 降档后如果稳定运行 30 秒且帧耗时余量充足，回升一档；每次会话最多回升 1 次，避免反复跳档。
- 档位切换用 300ms 淡入淡出过渡。

**录制参数：** 录制期间锁定档位和渲染尺寸；长边不超过 1080px；30fps；码率约 6 Mbps（H.264）/ 5 Mbps（VP9）。

## 12. 声音设计

- **环境层：** 夜湖底噪（极低频的水声 + 远处虫鸣），音量 −28 LUFS 左右，循环无缝。
- **互动层：** 落笔是轻微的纸面摩擦声；化鱼是一声水滴；涟漪是柔和的水波声；月升是一声低沉悠长的磬音；氛围变化时有对应的过渡音（雨声渐入等）。
- **音阶：** 互动音效使用五声音阶（宫商角徵羽），保证随意组合时也和谐。
- **原则：** 声音是点缀，不是提示音；同类音效 200ms 内最多播放一次，避免连点时变得嘈杂。

## 13. 文案语气

- **像诗，不像软件：** 「在湖面上画一笔」，而不是「请使用鼠标在画布上绘制」。
- **短：** 情境提示 ≤ 12 个字；其他说明性文案 ≤ 16 个字。
- **不说“错误”“失败”“无效”：** 能力受限时用委婉、温和的说法，并且告诉用户还能做什么。
- **不用感叹号，不用网络流行语。**

| 场景 | 文案 |
|---|---|
| 首屏提示 | 轻轻画一笔，看看会发生什么 |
| 情境提示 | 点一点小鱼 / 在天上画一个圆 / 写一句话，世界会听见 |
| 输入框占位符 | 告诉这个世界你在想什么… |
| 鱼回应文字（读屏） | 鱼儿游向远处 / 鱼儿聚到了一起 / 鱼儿慢了下来 / 鱼儿欢跃起来 |
| 限流 | 灵感歇一会儿，画笔仍在 |
| 重置 | 世界已重置 · 撤回 |
| 不支持 WebGL | 这里进不去，换个浏览器试试 |
| 微信中录制 | 在浏览器中打开，才能保存作品 |
| 放弃录制确认 | 放弃这段作品？ |

## 14. 设计验收清单

**视觉**
- [ ] 任意截一帧都可以当壁纸；画面留白 ≥ 40%
- [ ] 界面控件面积：桌面 < 5%，手机 < 8%；没有使用 emoji 作为图标
- [ ] P0 的 3 套色板 × 2 个时段 × 4 种天气都检查过一遍，过渡中没有出现“脏灰”的中间色

**交互**
- [ ] 落笔 ≤ 1 帧出现墨迹；任何输入 ≤ 100ms 有反馈
- [ ] 所有动画都可以被打断，没有任何时刻锁住输入
- [ ] 可点击区域 ≥ 44×44px，按钮间隔 ≥ 8px

**无障碍**
- [ ] 开启“减少动态效果”后完整体验一遍
- [ ] 只用键盘能完成：一句成境、录制（P1：生成鱼、生成月亮）
- [ ] VoiceOver 能读出世界描述和创造播报
- [ ] 文字对比度达到 §3.1 的要求

**设备**
- [ ] iPhone（Safari）、Android（Chrome）竖屏和横屏
- [ ] 桌面 Chrome、Safari、Firefox
- [ ] 375px 宽度下没有任何元素溢出或被遮挡；软键盘弹起时输入框可见
- [ ] 录制出的视频包含 echo 诗句和水印，不包含界面控件
- [ ] 微信内置浏览器能打开并正常游玩

## iOS 原生容器与交互补充（2026-10-25）

- **视觉连续性**：保留夜湖水墨、留白、首屏「轻轻画一笔，看看会发生什么」、输入框「告诉这个世界你在想什么…」；不引入原生导航栏遮挡世界，不以文字输入取代画笔主角。
- **屏幕与安全区**：支持 iPhone 竖屏首发；尊重刘海、Dynamic Island、Home Indicator 的 safe area；键盘弹出时输入框可见、画布不意外缩放，关闭键盘可继续画；旋转、后台恢复不丢鱼。
- **触摸**：Pointer Events 行为在 WKWebView 真机核验；手势绘画不触发网页滚动/缩放，系统返回/边缘手势与绘画冲突需实测；不同刷新率设备不得改变笔性归一化结果。
- **触觉与声音**：轻触反馈只用于第一条鱼诞生、保存完成等关键时刻，遵循系统减少动态效果与静音/无障碍偏好；不能用触觉代替视觉反馈。
- **原生操作**：作品保存使用系统分享或相册授权流程；权限按需请求、被拒绝后提供无障碍的文件保存退路。分享取消不误报成功。
- **性能与稳定性**：遵循本文已有画质档位、帧率与资源预算；新增真机记录 iPhone 型号、iOS 版本、画质档、首次可交互时间、内存压力/热状态和连续交互表现，数值目标仍以本规范现有章节为准。
- **审核材料**：App 图标、启动画面、截图、说明与实际功能一致；提供隐私政策和支持入口；不得在界面中承诺尚未实现的 AI/视频功能。
