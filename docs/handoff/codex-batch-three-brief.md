## 一、为什么它们会来

人留下的鱼，让水开始有了可以相认的生活。叶荫里偶尔伸出一个小头，雨叶上慢慢出现一段有方向的湿痕，便会让人知道：自己正在与一方更大的天地相处。

龟来自连着湖的浅湾，蜗来自近岸湿润的草与叶背。它们都有看不见的来处，也有离开画面以后的栖居。人的一笔使它们愿意多停一会儿，天地也在认真回应这一笔。

它们属于世界来客：自然而来，自行离开，不占鱼的数量，不记为用户亲手创造，不改变当前送鱼的含义。来访发生在当前画面里；第一版无需增加离线模拟、新收藏目录或持久化的来客档案。

## 二、舟背龟：一片荫开始有了重量

### 模样与位置

一只年轻的淡水舟背龟，背壳低拱，像一块被水磨圆的小石，壳上有一处可暂留花瓣的浅凹。壳纹灰橄榄，颈与足偏暖灰，细节柔和。头探出来时，才清楚知道石头也有自己的去向。

它和锦鲤处于相同的俯视／轻斜俯视画面。身体长度先以短屏边的约十分之一至七分之一试起，手机上约四十至五十五像素；与用户的鱼共同出现时仍能认出鱼。

位置选荷丛边缘的浅水，最好靠左右一侧，半身能借到叶荫，面前有短短的清水路。中央画画的水面保持开阔。龟脚下仍是水，有遮蔽、轻微下沉的颜色与一圈细小的动水。

### 何时出现

荷塘已展开，白昼或黄昏，风不很急，人的手停了一会儿。

第一回可以在叶荫稳定十几至二十几秒之后来访；若用户正画鱼或一个生命正在初醒，先让那一笔完成。第一版同一时刻最多一只，偶尔来一次已足够。

它从叶丛旁的画外浅水游入。先有一小段不同于鱼尾的水纹，再有低低的壳面，最后头从壳边探出。来者可以在任何一段注意到它，也可以继续画自己的鱼。

### 这一小段生活

1. 从叶缘游到背风的一小块水，速度比旁边的鱼慢。
2. 停下，颈稍伸，四足收得松一点，水纹慢慢散。
3. 一条熟悉的鱼经过，龟把头轻轻偏向它；鱼可以经过壳边，随后继续自己的路。
4. 过一阵，龟再往叶下走一点，或换到同一片叶的另一侧。

这几件事不需要排成每次相同的表演。先实现“能游来、愿意停、会再出发”，就已经有完整的一小段日子。

### 人怎样参与

轻点附近水面，涟漪来到龟边，它缓缓转头看一眼，或把颈收近一点；稍后仍按自己的速度舒展。反馈只需一次轻微动作，不需要惊跳或反复触发的奖励。

若一条用户画的鱼本来就在附近，可以让龟选一个不会挡住它的位置。鱼从叶底出来、龟在叶旁停着，两种速度共同使叶荫可被感到。

以后若当前场景本来就有落瓣，才考虑“花瓣刚好停在龟背浅凹”的小事。当前荷塘与落花的状态未必共存，第一版不为龟额外制造一场落花，也不把携花写成必需依赖。

### 停多久，怎样离开

一次停留大约半分钟至一分钟多一点，其中大部分时间只是歇着。它随后沿可见的浅水路回到叶丛或画外，最后才收住轮廓。

场景转入深夜或雪时，它也可以先把头收近，再循水路回避风的浅湾。景色转身的几秒里，它仍是同一个正在离开的生命。

留给人记住的，是“那片叶旁边，原来还有一处适合慢下来”。

## 三、听雨蜗：雨有一处可以走得很慢

### 模样与栖居

一只住在岸边的陆栖小蜗，圆壳的螺旋像一笔慢慢收拢的线。壳是淡灰褐，有浅浅的暖纹，身体灰米色，触角细而清楚，湿润处只显一点柔亮。

它要有适合托住身体的叶，来自靠岸的湿草或一片较宽的低叶。当前细长的垂柳叶不必承担它；若以后展开这条生活，可在最低的一角给它一片低垂的宽叶，或沿已有湿叶来访。

这片栖居叶只占一角，手机中先试约五十至八十像素长；蜗身约十五至二十二像素，旁边仍有能看清移动的空隙。输入框与湖心留出来。叶、蜗和雨处于相同的光照里，叶影与水边湿墨相连。

### 何时出现

雨已经稳定十几秒，叶上有清楚的湿意，人的手也暂时停了。

先从叶背探出两根触角，再慢慢露出壳的一侧。白昼雨、黄昏雨都成立；夜雨也有自己的生活，只让壳边与触角接到很轻的近光。

蜗来自叶背，雨只是使这段生活更容易被人遇见。第一版同一时刻一只，一场雨不必重复来很多次。

### 这一小段生活

1. 触角先试探，身体从叶背缓缓伸展。
2. 沿叶脉走一小段，壳随后慢慢越过那一道弯。
3. 一滴水在前方聚起来，它先停一下，触角收近，稍后换一点方向继续。
4. 经过叶尖附近时，一滴水落向湖面，鱼若刚好在下面，会遇到那一圈很轻的纹。

看上去很少的移动，也可以有清楚的先后。先看触角，再看身体，最后才发现壳已经离原处远了一点。

### 人怎样参与

轻点叶边，可以让一滴原已聚着的雨水落下；蜗暂停、收近触角，再慢慢探出来。人的动作影响了叶、水和这段经过，也给生命留下继续选择走法的余地。

若鱼不在附近，水纹自己散开，这一小段生活也完整。鱼在时才多一次相遇，来客不负责把鱼从远处强拉来。

### 停多久，怎样离开

可在叶上留一分钟左右，走过半片叶已足够。雨缓下来以后，湿叶还能留水，它可以再停一阵，再转到叶背或近岸草里。

阳光回来时，壳逐渐被叶遮住，触角最后收起。来者记得那里有过一条慢路；下次雨来，也许又会留意叶背。

## 四、与当前世界怎样相接

| 眼前已经有的生活 | 龟或蜗添上的一段关系 |
|---|---|
| 叶下的鱼偶尔歇息 | 龟也来到同一片荫，两种生命共享一个地方 |
| 人轻点水面，涟漪向外走 | 龟只是缓缓注意到，又继续自己的步子 |
| 雨经过远山与湖 | 近叶的一滴雨经过蜗，随后来到鱼所在的水 |
| 柳与岸把湖面留出来 | 蜗只在最低的一角经过，使近岸有细小的尺度 |
| 一条亲手画的鱼有自己的小弯 | 来客围绕栖居与它相遇，人的来处仍能被认出来 |

两者不必同场，也不必同时开发。龟与已有荷叶的关系更直接，可以先做；蜗需要一片合适的湿叶，等近岸构图站稳后再展开更自然。

## 五、第一版值得先看什么

看一小段实际画面：人的鱼还容易被认出吗？龟像真在叶旁停了一会儿吗？蜗的触角、身体、壳能显出缓慢的先后吗？来去有路，少看一会儿也能自在离开吗？

先让少量动作形成完整的日子，再决定是否增加携花、借叶渡水或更长的共同往事。关于更多远方，继续回到 value/06 与 value/13 的水路和栖居里取意。

本稿交付的是设计与素材需求。当前没有对应新图，也没有把这些来访写成已经实现；由所有者看过决定是否展开，再由 Claude 安排实现和具体素材交接。
