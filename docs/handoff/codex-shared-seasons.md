## 这篇解决什么

一页时景怎样让不同的人相遇，又让各自的天地与生命完整。延续16篇的阿禾、阿遥，再加入一个还没有画过鱼的陌生来者。

- 阿禾想给一个普通雨夜留页；小画留下近岸与雨，不替人画生灵。
- 阿遥在自己的白昼看过夜雨，可以继续留在晴日；后来愿意采用，自己的圆承接月光，原有的鱼一起遇雨。
- 陌生人看见同一页，在自己的水里画出第一条急着转身的小鱼。共同的时景带来不同的初生。
- 作者收回公开页时，原来的画与字可以退出公开；来者亲手创造的生命仍属于自己的湖。
- 同样平常的天气也能承载不同来处；新的风物先有栖居、时节与来去，再进入可取意的册页。
