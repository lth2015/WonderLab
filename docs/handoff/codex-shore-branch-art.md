## 背景

世界观 09 §13「近岸」和 10 §四「一根枝」：人在水边画一笔，长成一根略斜的花枝；花沿枝开，一瓣落进水里与鱼相遇；黄昏有蝶停留，夜里萤火从花间起。这是下一批要实现的主功能（见 main 的 `docs/世界观落地.md`）。

**花枝本身就是用户画的那一笔墨线**（笔触保留，像水墨画里的枝干），花和蝶贴在枝上。所以需要的是小的花朵与蝴蝶素材，不需要整根枝。

## 请做的事

1. **先定种类**：按你的世界观，近岸这根枝开的是什么花（听雨林、花信溪的性情）？蝶是什么样？在本文末尾「Codex 回复」里写两三句理由。没有特别想法就用：**桃花或垂丝海棠（粉白五瓣）**、**一种素雅的蝶（白或浅黄，翅上有淡墨纹）**。
2. **出图 6 张**，照片写实，和 `public/art/koi-*.webp`、`public/art/lotus.webp` 一个风格；**512×512 PNG，透明背景**（不支持透明就用纯白底，处理脚本会抠掉与边缘相连的纯色背景）；每张主体居中、留一点边、**不要阴影和枝干**：
   - `blossom-open.png`：一朵盛开的花，**正面**（花心朝镜头）
   - `blossom-side.png`：一朵盛开的花，**侧面**（看得到花萼）
   - `blossom-bud.png`：一个将开的花苞
   - `petal.png`：一片单独的花瓣
   - `butterfly-open.png`：蝴蝶**正上方俯视、双翅展开**，身体竖直、头朝上
   - `butterfly-closed.png`：蝴蝶**侧面、双翅合拢**（停在枝上的样子），头朝右
3. 自查：视角对不对、是否透明或纯色底、主体有没有被裁掉、有没有多余的阴影或文字。不对的重出一次。
4. 提交到 `collab` 分支的 `art-incoming/shore/`，推送前 `git pull --rebase origin collab`，不 force-push。
5. 在本文末尾「Codex 回复」写：选了什么花和蝶、几张图、提交号、自查结果、不满意的地方。再在信箱留一封短信指向这里。
