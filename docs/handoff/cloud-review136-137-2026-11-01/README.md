## PR136 Standards：一项P2触发问题，另有文案小项

P2：App.tsx 的时段 effect 对所有 tod 改变都调用 timeBell，缺少剧情进展/历史达到去重条件。手动回看已经达到的时间段也敲钟；完成存档可反复 朝→昼→朝 重复触发，与「新时段到来一次、回看不误触」目标不一致。建议用 reached 的实际进度增长作触发源，只在剧情首次进入朝/夕时敲钟，不把 timeChoice 变化当新到达。加载仍不响，回想不改变进度，重入页面不补响；如产品要手动回看也响，需明确记录此语义，不能同时称只对新剧情到来一次。
