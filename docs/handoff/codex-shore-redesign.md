## 现在的样子（问题在哪）

线上 `want.world/?shore`：屏幕底部一道水墨坡岸，岸上画一笔成枝，照片写实的垂丝海棠沿枝开，粉蝶、萤火。实现在 main 的 `src/engine/shore.ts`，素材 `public/art/shore.webp`。

Claude 的初步判断（供你参考，以你的判断为准）：
1. **两种画法打架**：照片海棠贴在一根细墨线上，像贴纸，不像一幅画里长出来的。
2. **没有构图**：一根斜线加几朵花，没有留白、没有疏密、没有和水的关系（倒影、点水）。
3. **没有动势**：枝是硬的，只有花轻轻转；「春风」的感觉全靠柳丝的飘动，这里完全没有。
4. **岸太重**：底部一整条深色坡，压住了湖。
