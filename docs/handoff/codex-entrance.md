- **A 四时册页**：「更多」菜单里加一项「四时」，打开一本册页。按春、夏、秋、冬，以及晨昏、月夜排列，每页一行诗、一个场景名，点一下就走进那个场景。
- **B 场景链接**：每个场景一个网址，例如 `want.world/柳`、`want.world/荷`（也接受英文 `want.world/willow`）。收到链接的人打开就在那个场景里，自己的湖和鱼都还在。
- **C 首页随时辰**：第一次来、没有存档的人，按本地时间看到白天、黄昏或夜晚。天上的第一行诗也会早一点出现。

## 册页内容（Codex 填写）

### Codex 第一版定稿 · 对照 main 29a6ad1 的十四页

上表已直接更新为建议用稿。可复制的数据在 art-incoming/book/pages.json，十四句用真实 interpret 检查，天气均相符，句内时辰与入口时辰无冲突，也没有改用固定十句作册页文字。检查记录 lines-check.json。

**阅读顺序：** 春（柳、落花、虹）→ 夏（荷、雷雨、惊鹊、鸣蝉、萤火、星河）→ 秋（秋、月、河灯）→ 冬（流星、雪）。

“惊鹊”与“鸣蝉”并在暖季夜色里，承接同一首词；星河移到夏夜长卷中。月色与流星并非秋冬专属，册页的四时用于带人浏览，不把全年都可发生的天象锁在一个季节。雷雨可以昼夜发生，沿用当前时辰；它的小画会取偏暗的夏日，文字不替人强制换成夜晚。

册页里的晴日、月色都可以从画外来光。插画不预制一个醒目的太阳或月亮，以免让人误以为点场景就会代替自己画圆；仍让亲手的那一笔拥有位置。也不在小画里预设“这是你画的鱼”。

《接天莲叶无穷碧》取杨万里，《明月别枝惊鹊／清风半夜鸣蝉》取辛弃疾，《满船清梦压星河》取唐珙；其余为本轮册页原创短句。出处供维护者留存，不必把作者和考据塞进每一页的视觉中心。

**插画第一批：** 柳、落花、虹、荷的 480×640 webp 已交；原始 PNG 保留在 art-incoming/book/source/。剩余十页继续同一湖山与纸感，换近景、光、风与时景。小画是场景索引的取意，不是引擎截图或已验收实景。

**入口仍要看见对应生活。** 当前十四句天气映射符合；“清风半夜鸣蝉”带 wind=0.45，但不是横划 gust，夜间自动蝉又不定时启动；“惊鹊”只有 moonlit 也不会等同新画一个圆。实际进入这两页是否能在合理停留内遇见所名的生活，还需运行复核并由你定节奏，不能仅因天气字段对上就认定已验收。
