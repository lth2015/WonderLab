## Codex 初稿：一页可以继续生活的地方 · 2026-10-30

状态：创作侧方案已交付，待 Claude 对读；本节都是提议，未写产品代码、未启用收费。已读所有者「1200次／月」「按次」「先想法」「众人四时可以公开」的最新补充。

### 1. 先定下卖出的是什么

我赞成「一次创作，一页自己的册页」。这一页应有一句来者留下的心意、一处真实能进入的时景、一幅与它相符的小画，以及可以再次打开的地址。

它的价值在于把一份心意编织成可重访、可继续创造的地方。人愿意来这里画一条鱼，停一会儿，也能把这页交给朋友。基础画笔、原有场景、本地保存、自主分享和生命的相处照常免费；已有世界不会因没有购买新页而少了什么。

**这一页的中心仍是来者自己的动作。** 生成不会替他画第一条鱼，不把模型画出的鱼冒充他的生灵，也不替他在天上安放第二个圆。小画是一扇入口，进入以后仍是能画、能触碰的实时湖面。

我会把第一版说成「留一页自己的天地」。如果暂时只能组合现有湖景，就明确展示这种能力；还没有新地形、建筑和物种时，不能让付款人以为能任意生成一个新大陆。

### 2. 世界如何越来越大

「场景总是有限的」有两层：我们写的十四个入口有限；引擎会做的事也有限。开放来者创作，可以先打开第一层，第二层仍需逐步做出新的生活能力。

| 层次 | 持续保留什么 | 可以怎样变多 |
|---|---|---|
| 共同的天地道理 | 光阴、栖居、人的一笔、同源而各自生活 | 所有人的册页都守相同世界规则 |
| 一处地方 | 湖、近岸、画外山林，和已经在这里生活的生命 | 逐步加入真正实现且通过艺术验收的栖居与风物 |
| 这一刻的时景 | 时辰、天气、风、水与声音 | 来者组合引擎已支持的条件，留下自己的取意 |
| 相处的经过 | 鱼经过光、鸟离枝再归、雨停之后的水声 | 随能力扩展形成有先后的生活；不是每次同时播放所有回应 |
| 人留下的来处 | 自己的一笔、一句话、愿意分享的心意 | 相近的湖景也会承载不同生活，不靠稀有度和数量证明价值 |

所以我赞成「众人四时」。它像许多人留下的地方与时刻，可以按季节、时辰、风雨慢慢翻阅。初版不需要热榜、点赞竞赛、创作任务或付费买曝光；公开收录由作者主动选择，浏览、进入和继续画画免费。

这一点也划清预期：第一版的多样性来自已有能力的个人表达与组合。山后新的林、浅湾里的新居民、同一场雨不同时间的抵达，是后续能力扩展的方向，尚未实现的部分写进创作愿望，不装成已经付费获得的实景。

### 3. 一次完成，交付一页

建议一次成功交付包括：

- 一个短页名、一句可由创作者修改的题句；
- 一组经过世界规则校验、实际能执行的场景设置；
- 一幅统一画风、与已确定的设置一致的册页小画；
- 一个固定内容版本的页面与可分享地址，支持再次进入与本地导出；
- 清楚的预览：付费生成的小画与实时世界分开可见，能检查是否相符。

同一页再次进入、继续作画、修改自己写的题句、分享已有页，不再调用生成模型，也不再次扣一次创作费。再生成一幅新画、另创一页，才产生新的、事前说明的费用。技术性失败的重试和用户主动要求另一幅画要分开记，不能用“重试”掩盖第二次收费。

本次购买不包含所有其他人的生灵，不自动备份整湖，也不承诺尚未建立的永久云托管。生成内容与场景描述可以导出；跨设备保存整湖是另一项需要单独说明的能力。

### 4. 从一句心意到可以进入的一页

1. **从正在生活的湖边发起。** 菜单里轻轻留一个「留一页」入口，不挡住第一次落笔。来者给一句话；季节、时辰可以选，也可以交给我们。原来已经画过的笔继续留在本机，不为出图上传整湖或轨迹。
2. **先看免费的本地取意。** 先用现有场景与本地规则给一个可玩的近似预览，显示这次能做到的内容。用户明确选了夜晚就保留夜晚；「雪夜有夏蝉」这类冲突先说明可实现的两个方向，让来者自己选。不要在付费后悄悄换掉心意。
3. **确定范围与这次价格。** 说明会生成一页、含几幅画、包含什么重试、什么时候算交付；需要把这句话发送给模型的动作也发生在这里。公开收录不是购买的必选项。
4. **生成同一份内容。** 文字模型给出页名、题句、受约束的场景描述和小画构图说明；先核对世界规则，再按通过的描述生成小画。图像只画本次支持的地方、光、天气和风物。不要让诗、画、实景分别自由发挥成三处地方。
5. **先回到活的世界，再安放成页。** 生成期间照样能画、能看水；成功后展示题句、小画与实际场景，来者可以试着画一笔。交付必须包含可用页面与资源，不能把“收到付款”或“拿到一张图”当成完整成功。
6. **由作者决定去向。** 默认仅本人查看；明确分享后才生成对外可访问的链接；另选「放入众人四时」才进入公开浏览。编辑已分享内容时保留固定版本，让朋友再次打开仍认得原来那页；需要替换或撤回时给作者清楚的操作。

第2步的本地预览是范围示意，不冒称已经完成了个人生成。修改明确条件应在第3步前完成；付费后若内容无法成立，就按失败／恢复额度处理，不能静默降级成另一页算交付。

### 5. 三个能拿来讨论的来者故事

**「给晚归的人留一片不用说话的水。」** 先取黄昏、微风、柳岸。册页小画留下近岸与晚光，题句可以是「晚光还在，水替你留着」。朋友打开时先在单独预览里看这页；愿意采用这种时景，才让自己的鱼经过这段光。没有读后状态，也没有“他还没来”的催促。

**「我想再见一次小时候的雨。」** 先取白昼细雨与安静水色。若人想的是老家屋檐，而当前没有建筑，就在付款前说清：先把雨与水声留下，屋檐还不能进入实景。不能在小画里画出可供进入的老屋，再把用户送到完全没有屋的湖边。

**「想给朋友一个雪夜。」** 雪色与夜光可以相伴；夏蝉与萤火休息。朋友原有的圆承接月光，原有的第一条鱼照样在。发送者送的是一页可选的时景；若还想送一条自己画的鱼，另走现有赠鱼的主动收下流程，两件心意可以同行，不能混成自动复制整湖。

这些故事承接 value/13 的远方、value/15 的相应与 value/16 的留水；后三者的文稿与具体产品完成状态仍各自区分。

### 6. 地址、自己的湖、礼物：三件事分别成立

| 动作 | 可以带来的内容 | 留在各自天地里的内容 |
|---|---|---|
| 打开别人分享的页 | 已发布的题句、小画、场景描述；在隔离预览中看看 | 不写接收者存档，不复制作者的鱼、月或笔迹 |
| 主动「用这页的时景」 | 一次应用经过校验的环境设置，可一次撤回 | 自己的生灵、来源、年龄、本命身份、圆与枝不被替换；排队中的原笔也要保住 |
| 自己画一笔 | 由自己的动作产生新的生命或天体 | 作者与其他访客的天地没有同步变化 |
| 主动收下一条赠鱼 | 现有赠鱼实验的共享起点 | 两边以后独立生活，不产生转赠、行踪或收礼回执的新承诺 |

预览与应用是新设计建议，当前固定十四场景地址的直接应用行为没有因此被我们擅自改掉。新页面尤其需要复用刚修好的 LIFE-3 与 LIGHT-2：不能靠清空世界进入，不丢出生队列，显式时辰只提交一次，撤销能回到整个选择之前。

新分享页只保存发布内容与场景描述，不放原始笔画、整湖存档或私下的原句。付款记录与作者控制权留在授权服务里，不随公开页发给访客。“仅链接可见”表示拿到链接的人可看，不应当作真正的私密访问；默认本人查看需要相应的访问控制，不能靠猜不到地址代替。

### 7. 诗、画与实景要一起守的边界

- 以引擎的能力清单和 world-rules.ts 为准。现有 SceneCommand 同时只有一种 weather，不能因为模型说得好听就承诺“荷塘＋雷雨＋星河同时叠加”。season 目前主要用于册页归类，不等于完整生态模拟。生灵出现还要有真实栖居、时景和行为入口；当前专用 moment 只有 magpie/cicada。
- 一天至多一个可见太阳，一夜至多一个月亮；白昼不展示夜空层，雪里没有夏蝉或萤火。显式条件比默认取意优先。插画同样守这些条件；日月光可以从画外来，不给用户预制第二个主体。
- 不在封面预画“属于创作者的鱼”。已有的画风参考和整体构图可以共用，创作者的原笔不作为模型输入，更不因付费而被公开。
- 古诗从核实过出处的句库挑选，保留原文与来源；新写的短句明确是原创题句，不伪称古人作品。作者自己的题句仍是自己的表达。
- 个人回忆可以通过天气、光与生活节奏取意；不承诺真实地点、真实人物复现，不冒用人物或品牌，不生成不当内容。公开版本再检查姓名、联系方式、题字等是否夹带私密内容；仅去掉账户字段还不够。
- 公开同意只针对这页内容。作者可撤下收录、撤销分享或删除其发布内容；已被他人本地保存的副本无法远程收回，要把这个边界说清。不能用公开浏览权推导出允许我们训练模型或任意再许可。

现有 P7 的正式体验只从人工句库取句、AI 只任导演；新服务若允许原创题句与生成封面，是明确新增的创作范围。所有者这次同意讨论付费，不等于相关产品文档已改完。落地时应由 Claude 把新服务边界写清，保留原有即时体验与固定十句；本轮无需为这个文档差异再打断所有者。

### 8. 实际需要几次模型调用

我不建议先把“5次文字调用”当作不可变成本。一份结构化创作内容可以合并生成；重复进入、分享、浏览不能悄悄再请求模型。

| 步骤 | 正常路径调用 | 得到什么／需要核对什么 |
|---|---|---|
| 本地取意、范围预览、规则检查 | 0 | 引擎现有能力、用户明确条件；不生成远程图像 |
| 内容编织 | 1次文字 | 同时给出页名、题句、场景参数、小画说明；只传本次主动提交的需求 |
| 图像生成 | 1次图像 | 一张通过规则描述的封面，明确生成尺寸、质量与模型版本 |
| 交付核对 | 计划1次支持图像输入的模型调用，另加本地检查 | 题句、图像和场景一致，兼顾公开内容检查；不替代规则校验与真实资源加载 |
| 已交付页的进入、应用、分享、公开浏览 | 0 | 使用固定页面与缓存资源，本地运行 |

目前只是调用计划，没有发任何付费请求。若图像失败后服务端重试，可能已经产生供应商费用；业务额度能回退不表示供应商成本也退回。需为一次订单设定尝试上限，把这些尝试作为同一创作的内部成本，不让重载页面或重复点击发起另一轮任务。
