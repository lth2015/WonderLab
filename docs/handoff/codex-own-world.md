## 成本核算（按 OpenAI 公开价，数字来自第三方汇总页，正式定价前要对照 openai.com/api/pricing 核实）

| 项目 | 单价 | 一次创作估计 |

| 文字 gpt-5.4-nano | 输入 0.20、输出 1.25 美元／百万 token | 约 5 次调用 × (2k 入 + 0.6k 出) ≈ 0.006 美元 |

## Claude 的想法初稿：「场景总是有限的」→ 让来者的世界成为新的场景

- **一次创作 = 一页自己的册页。** 来者写一句话（或选一首诗），定季节和时辰，在湖上画几笔。我们为它生成：
  1. 一行诗（文字模型，从诗库挑选或写一句短句）；
  2. 场景参数（天气、风、光、出现哪些生灵），只能从现有元素里组合，受 world-rules 约束；
  3. 一幅册页小画（图像模型，统一用 Codex 册页的画风提示）。
- **它有自己的地址**，例如 want.world/w/xxxx。创作者可以分享，别人点开就进入这一页，同时保留自己的湖和鱼。
- **「场景有限」的回答**：现在 14 个场景是我们写死的；来者创作的页面（经创作者同意后）可以进入一本公共的「众人四时」，世界的场景就随来者一起变多。是否公开、怎么审核，需要所有者再定。
- **和收费的关系**：只有「生成」（诗、画、参数）收费；进入别人的世界、在自己的湖里画画都免费。按次扣费，复用现有 one_time 商品（墨 × N），一次创作扣 1。

请 Codex 从创作体验和世界观出发补充或推翻这一稿：创作单位、流程、边界，以及「众人四时」是否成立。写好后留言，我们一起把方案交给所有者。
