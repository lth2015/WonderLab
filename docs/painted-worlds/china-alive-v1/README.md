# 中国篇「画面动起来」第一轮

接 Claude 的三项分工中的第一项：让景物点击有可见反馈，让路人与主要人物有安静的动态。实现分支 `codex/china-alive`，不改江户故事与部署配置。

## 行为

- 21 个环境热点都有穷尽登记的反应种类：柳叶、涟漪、风痕、猫伸展、鸟飞、微尘、茶汽、铃音线与刨花。世界位置固定在外层 SVG 属性，内层 CSS 运动约 1.4 秒后清除；同一热点连续点击会重建反馈并重置时限。三个故事入口保留立即打开对话的行为，反应绘在弹窗背后的画卷中。
- 14 位路人原先使用 `painted-passer`，未接上旧 `passer` 动画。本轮改为小范围沿路往返，半程转身。桥上路线沿桥面高度变化，起点、途中和终点均检查双脚未离开可见桥面；岸边采用各自短路线。
- 6 位主要人物只在实时画卷中使用轻微呼吸动作，脚底与影子锚点不动。画纸、导出和对话肖像仍为静态。路人沿用现有站姿美术加轻步幅，尚非逐帧步行动画或自由漫游角色。
- 减少动态（设置或实时系统偏好）停住运动，同时把点击反应变为短暂静态墨线；离屏人物暂停，页面隐藏沿用全局暂停。动画不逐帧调用 React 或改写世界坐标。
- 不改变存档格式、故事奖励、解锁条件或音频；没有增加图片或视频下载。

## 验证

- 中国篇 74 项测试通过：新增热点反应登记/坐标和运行人物覆盖检查，以及沿桥面全路线的双脚落点、去程朝向检查。
- 合入 `origin/main@41baf53` 后，完整 `npm run build`、`npm run qingming:domain` 和中国测试通过；根测试 488 项通过，4 项原有数据集测试跳过。
- Chromium 实际点选全部 21 个热点，确认反应图形/动画存在，重复点击重新播放且时限重置。用浏览器动画时间定位检查全部 14 位路人往返的方向、翻转与世界锚点不变。
- 设置与实时系统的减少动态通过，静态反馈可见；离屏运动暂停；空闲观察 1.2 秒，世界 `transform` 属性变更为 0。
- 390×844，120 步实际指针拖动期间采样 149 帧：中位 16.7ms、P95 16.8ms。仅为无头桌面环境的手机尺寸模拟，不能替代真机 60fps 验收。
- 页面可见性事件处理器的暂停/恢复通过模拟 `document.hidden` 验证；无头浏览器切换标签仍报告可见，因此未声称完成真实后台标签验收。浏览器生命周期冻结/恢复已走通。
- 独立域名根路径和 `/qingming/` 的生产包都走通反应触发/结束、纸铺故事、普通留念图及赠友 PNG；赠友图不含待机动画，预览与下载字节一致，无脚本或 HTTP 错误。

机器可读结果见同目录 JSON。图像用于检查背景、人物与反馈叠放；反馈观察应以实际动画为准。want.world 的发布与线上复验由 Claude 统筹。
