# 江户画面、环境声与重复路人修复

基线 main b3bad08（含PR139/140），分支 codex/edo-scene-polish。对应所有者河渠/竹篱截图，商业化工作暂停；Claude确认本批范围没有并行未交付修改。

## 实际改动

1. **截图断口**：世界x≈1000，旧底图石沿突然错层、竹篱/屋檐沿原切口碎裂。本轮image_gen局部重绘，在运行坐标x600–1400取样和接回；窄的最小差异左右切线、4px边沿混合，保留外侧原画。已实际替换street-0/1，不再只交候选。地图、镜像方向、人物/热点世界坐标与画卷长度未变。
2. **可重建**：完整对齐的生产补丁在docs/painted-worlds/art/edo/seams-v2/canal-x1000-v4.webp，元数据.rect.json的dst为(840,0,1120,980)运行像素。cx-build.cjs先应用外部既有rects，再自动应用本目录checked-in .rect.json；0/1用quality94。移除sharp的旧主机绝对路径。合成fixture运行整个构建并逐像素确认补丁留在runtime-full；这不是声称重建了Claude机器所有未入仓的原始素材/旧补丁。
3. **降噪**：移除持续人声频带的噪声床和定时合成叫声，水/风更低更柔；旧存档音量仍保留，内部音源混音降低。新存档环境声默认小(.35)，操作音/音乐通道与故事不变。脚步/鸟/音乐变稀疏，各次启动至少间隔8秒，钟后保留14秒空间；隐藏页不启动事件，0音量立即置0。定时器集合不再随调度次数累计增长。
4. **人物重复**：原8种素材循环摆了39体，现8种各一次，按道路固定位置分布；不靠翻面或换色冒充新人物。主要人物与剧情姿态未改。整体比原来稀疏，这是本批取舍；没有制作新的人物美术。
