# 江户编：加一段场景、加一个故事要改哪里（路线 #158 第 3 项）

根据加「向こう岸の河岸」和「河岸の朝」（#167）时实际改过的地方整理。`apps/qingming-edo/src/content/registry.test.ts` 会检查下面打 ✅ 的项，漏了会直接报出文件和键名。

## 加一段场景（长卷变长）
| 步骤 | 位置 | 检查 |
| --- | --- | --- |
| 画：每 1000 单位一张 `street-N.webp`（1400×980） | `assets/art/` | ✅ 每段都有图 |
| 长卷宽度（区段数、导出、相机都由它算出） | `content/world.ts` `SCENE_W` | ✅ 区段数 × 1000 = 宽度 |
| 水声、热闹程度（按 x） | `engine/sound.ts` `WATER`、`busyAt` | 手动 |
| 导览站 | `content/world.ts` `GUIDE_STOPS`（从右到左，id 唯一） | ✅（engine.test） |
| 可点的景物：热点 + 文字 + 标签 | `HOTSPOTS`、`AMBIENT`、`AMBIENT_LABEL` | ✅ |
| 素材来源 | `docs/painted-worlds/qingming-edo/素材台帳.md` | 手动 |
