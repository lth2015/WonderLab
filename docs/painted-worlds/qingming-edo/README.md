## 2. 現在の状態（§20-2・3 の途中）

遊べるもの：「一頁目：風のいたずら」が最初から最後まで。

- 日本橋北詰の創作街区（3000×700 の場面単位、三区間：橋詰・茶店・振売り）。右端の橋から始まり、左へ続く。
- 指一本で通りを動かす。8 CSS px を超える移動はドラッグ扱いでタップを取り消す。選択範囲は最低 44×44 CSS px。同じ優先度が重なったら最大三つの候補。
- 紙を一度タップ → 清太の礼 → 宗吉「何を描く」→ 働く手／店先／通りの往来 → 近景／全景と題箋を選ぶ → 頁ができる → 宗吉の一言 → 12 文。報酬は一度だけ（再読込・再会話でも増えない）。
- 写生や礼の途中で閉じても、宗吉か清太に話しかければ続きから。断っても物語は閉じない。
- 絵巻帳（12 枠）、頁の拡大、PNG 保存（1200×1600、小さく作品名入り）、作品リンクのコピー（残高や報酬は含めない）。
- 環境の反応 9 か所（暖簾 2、雀、犬、湯気、天水桶、擬宝珠、柳、荷舟）。物語前後で変わる状態：紙（めくれる → 文鎮で落ち着く）、清太の姿勢（手を伸ばす → 礼 → 立つ）。
- 「近くのこと」：今できること最大 3 件と、通りの人と物の一覧（キーボードと文字だけでも全対象に届く）。8 秒操作がなければ消せる案内。
- 設定：動きを減らす、文字 100/125/150%、記録の書き出し・読み込み（失敗しても今の記録は消えない）、最初から、作品について、「ほかの世界へ」。
- 新しい版の記録は書き換えない。壊れた記録は退避してから新しく始める。ストレージが使えない環境でもメモリ上で遊べる。

## 6. Codex の長巻原画の接入（2026-10-31〜11-01）

- 町並みを Codex の原画に置き換えた（母稿＋区間 03–12、計 12 区間）。区間 13–14（臨水庭院・静かな河岸）は Codex が制作中で、届くまではカメラが x 2000 より左へ行かない。
- 配置は Codex の manifest（world.x、sourceWindow、1128×700）どおり、1.4 px／単位（原寸以下、拡大なし）。重なり部分は最小差異の縦の切れ目で接合し、全巻を左右反転（x′=14000−x）。
- 物語の場所：桟橋・柳・荷舟（13）、紙屋・道具屋（12）、茶店（11）、米屋（7）。人物の足元・選択範囲・環境反応 26 か所を新しい絵で引き直した。路人は護岸の上に立たないよう x ≤ 12760。
- 既知の問題：接合 4 か所（x 2000、4000、10000、11000、反転前の座標）で路面・路縁の段差が見える。Codex に補絵を依頼済み。
