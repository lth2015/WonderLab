## 2. 現在の状態（§20-2・3 の途中）

遊べるもの：「一頁目：風のいたずら」が最初から最後まで。

- 日本橋北詰の創作街区（3000×700 の場面単位、三区間：橋詰・茶店・振売り）。右端の橋から始まり、左へ続く。
- 指一本で通りを動かす。8 CSS px を超える移動はドラッグ扱いでタップを取り消す。選択範囲は最低 44×44 CSS px。同じ優先度が重なったら最大三つの候補。
- 紙を一度タップ → 清太の礼 → 宗吉「何を描く」→ 働く手／店先／通りの往来 → 近景／全景と題箋を選ぶ → 頁ができる → 宗吉の一言 → 12 文。報酬は一度だけ（再読込・再会話でも増えない）。
- 写生や礼の途中で閉じても、宗吉か清太に話しかければ続きから。断っても物語は閉じない。
- 絵巻帳（12 枠）、頁の拡大、PNG 保存（1200×1600、小さく作品名入り）、作品リンクのコピー（残高や報酬は含めない）。
- 環境の反応 9 か所（暖簾 2、雀、犬、湯気、天水桶、擬宝珠、柳、荷舟）。物語前後で変わる状態：紙（めくれる → 文鎮で落ち着く）、清太の姿勢（手を伸ばす → 礼 → 立つ）。
- 「近くのこと」：今できること最大 3 件と、通りの人と物の一覧（キーボードと文字だけでも全対象に届く）。8 秒操作がなければ消せる案内。
- 設定：動きを減らす、文字 100/125/150%、記録の書き出し・読み込み（失敗しても今の記録は消えない）、最初から、作品について、「ほかの世界へ」。

## 7. 音（2026-11-01）

仕様書の「足音、呼び声、紙や道具の音を中心に、音楽には余白を作る」に沿った最初の版。すべて `engine/sound.ts` で WebAudio により合成し、音源ファイルはない。

| 層 | 中身 | 場所・時間による変化 |
| --- | --- | --- |
| 町の音 | 往来のざわめき（声の帯域の雑音がゆっくり息づく）、下駄の足音、水音、かすかな風、雀 | ざわめきと足音は店の並ぶ区間で多く、庭の端で少ない。水音は橋の下・河岸・庭の池の近くで聞こえる。夕方は往来が静まり、雀は朝に多い |
| 操作の音 | 紙に触れる音（人や物を選ぶ）、頁をめくる音（会話の送り）、木を打つ音（町の反応）、筆を引いて頁を置く音（絵巻帳に頁ができた）、銭の音（報酬）、紙を上げ下ろす音（帳面・設定・遊びの開閉） | — |
| 音楽 | 陽音階の撥弦音で 3〜5 音の短い句。18〜42 秒の間を置く | — |

- 最初の操作（タップかキー）までは AudioContext を作らない。タブが隠れると止まる。iOS では消音スイッチに従う（`navigator.audioSession.type = 'ambient'` が使える Safari では明示）。
- 設定で三つを個別に 切・小・中・大。既定は 中・中・小。古い記録は既定値で読み、不正な値は捨てる（単体テスト）。
- 音で伝える情報は、すべて画面の反応（会話、頁、文の表示、揺れ）と同時に出る。無音でも全部遊べる。
- 検証（ヘッドレス Chromium、作業用 `sound.cjs`）：最初の操作前は AudioContext 0 個、操作後 1 個。橋の付近で RMS 約 0.026・ピーク 0.12、店の区間で 0.022・0.09（歪みなし）。三つとも「切」で無音。再読込後も設定が残る。コンソールエラーなし。
- 未対応：呼び声（声の合成は不自然になりやすく、録音は由来の記録が要る）、石町の時の鐘（位置と聞こえ方の調査が先）。実機の耳での調整はまだ。

## 8. 町の写生と絵巻帳 12 頁（2026-11-01）

仕様書の完成見本「絵巻帳12頁（独立構図）」を満たすための仕組み。物語の頁は 3 本＋回想の 2 頁なので、残り 7 頁を町の景色の写生で埋める。

- 一頁目のあと、宗吉が「気になる景色があれば、足を止めて写してみろ」と言う。長巻の端から端まで 7 か所（柳と荷舟、井戸と梅、桶屋の店先、河岸の小舟、紺屋の干し場、庭の池、川端の縁台）で、環境の反応の代わりに「この景色を写す／眺めるだけにする」を選べる。一度写した場所は、ふだんの反応に戻る。
- 頁の絵は Codex の長巻から 520×660 の構図で切り出す（`content/world.ts` の `SKETCHES`）。写した時間帯（朝・昼・夕）を記録し、題箋の地名と色合いに反映する。色合いは SVG の feColorMatrix なので、保存した PNG にも残る。
- 文は増えない（報酬は三つの物語だけ、仕様書 §文）。回想の対象でもない。
- 「近くのこと」は、進行中の物語 → 次に写せる場所 → まだ会っていない人の順。「この通りの人と物」の一覧では、写せる場所に「（写生できる）」と添える。
- 検証：単体テスト 54 件（場所と頁と会話の対応、12 枠ちょうど、時間帯の記録、報酬なし）。ヘッドレスで 7 か所を写して 10/12 頁、回想の 2 頁と合わせて 12 頁。保存 PNG に夕の色合いが残る。150% 文字・キーボード操作の確認も従来どおり。
- 一頁目「風のいたずら」の 6 構図も、線描の仮素材から長巻の切り出し＋立ち絵（清太の三姿態、宗吉、路人）に替えた（`KAZE_VIEWS`）。これで絵巻帳 12 頁すべてが Codex の絵の上にある。線描の通り・人物・店のコード（`scene/art.tsx` の大部分、`PageArt` の線描構図）は削除。
- **絵巻帳が一冊に**：12 頁そろうと「近くのこと」の先頭に「一冊になった絵巻帳を、宗吉に見せる」。宗吉の締めの言葉（町は明日も続く、また歩け）で無料体験がひと区切りになる。文は増えない。以後は短い挨拶に変わる。条件は新しいデータ演算子 `pagesAtLeast`（コードではなくデータ）。
- 題箋の縦書きで、括弧・句読点・かぎ括弧を縦用の字形に替える。
