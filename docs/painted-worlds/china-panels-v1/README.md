# 中国篇弹窗收纳与固定返回

接 Claude 的同事演示反馈：返回和主要操作不应藏在长内容后面。此改动接在赠友画纸 1B（`0f811b5`）之后；请先合入 1B，再合本分支。

## 改动

- 所有通用弹窗采用固定标题、可滚动内容、固定底部返回区。底部使用不透明纸色，长内容不覆盖按钮；短屏最大高度统一为可视高度的 90%，保留安全区内边距。
- 画页的「保存留念图」「送给朋友」「回到画册」固定在底部，回忆正文收进「画中记忆」。从赠友返回画页，焦点落在固定保存按钮上。赠友沿用自己的三步底栏，不重复添加返回区。
- 设置保留常用开关，将存档、试玩记录、关于与重新入画折叠收纳。试玩会主持工具可展开使用，换人确认仍保留；损坏存档的备份区域自动展开。
- 画册优先展示已收集画页，待落笔的风景折叠为仍可点选提示的列表，编号与解锁条件不变。附近列表减少空白间距。
- 不改故事、奖励、存档字段或试玩会隔离规则。长篇剧情、全部画页或用户展开的说明仍允许内容滚动，返回操作始终留在视野中。

## 验证

- `npm run build` 与中国篇 70 项测试通过。此变更未新增镜像式样式测试；通过真实浏览器检查布局与交互。
- Chromium：1280×800、390×844、360×740，各自普通/150% 大字，检查设置、空画册、附近、画页、有画页的画册。滚动内容前后底栏均在屏幕中，弹窗与页面无横向溢出。
- 存档导出与原文一致；导入合法档恢复，错误档不覆盖进度；损坏档保留至手动备份，恢复区域自动展开。折叠后的试玩记录仍能导出。
- 试玩会主持工具的导出、确认/取消换人、开始下一位通过，日常存档保留。关于弹窗 Escape 后焦点返回来源，取消重新入画保留进度。
- 合法合成完整画册仍有 15 页可点选；普通留念 PNG 可下载；赠友返回后聚焦底部保存按钮。部分系缆进度在固定退出后保留；货港、城门、乡野长对话可固定退出。
- 回归赠友图片的预览/保存/模拟原生分享内容一致、过期渲染隔离、失败素材重试和三步底栏。
- 生产打包根路径与 `/qingming/` 均验证 360×740 大字设置一屏、画页固定操作、普通 PNG 下载，以及赠友与返回焦点，无脚本错误。

机器可读结果：`layout-result.json`（30 种面板/尺寸组合）、`functional-result.json`、`gift-regression-result.json`、`production-result.json`。普通模式的上述常用面板均无需滚动；大字模式中只有「附近」长列表仍需滚动。全量画册和展开的长说明允许内容滚动。
