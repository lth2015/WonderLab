# 中国长卷复核与修正 · 2026-11-01

基线：Claude PR130 `6b3e10ee4f4550c1ee72435689b6110ca16274a7`，相对 PR129 `1905a53640c2a970d9720acca87b3574fc219ae2`。沿用其 24000×1200、20 瓦片和 ORIGIN=10800，原故事、存档和桥栏覆盖不变。两轴独立审查，不将一轴的通过视作另一轴通过。

## Standards

发现 1 项 P2：`RollTiles` 只保留目标镜头及左右一块预留图，镜头却以 .28s CSS tween 穿越旧位置和中途已经卸载的瓦片。纸铺→城门可露出空纸和悬浮精灵。

修正：镜头直接跟随输入，不再进行 CSS transform tween；拖拽仍随指针连续移动。最初只关闭远跳的候选修法未采用：快速连续 ±800 或方向键会累积目标与实际镜头的距离，也可能超出预留图块。最终无需增加状态或预载整卷。

## Spec

发现 2 项 P2：上述长跳空白不符合连续长卷与按需加载；农人热区落在两农人左下方空路，点画中的农人不能触发。对 13 个新增小景逐块目视复核，校正 5 处锚点，其余 8 处仍在相应对象上。

## 美术与历史初筛

游戏画面的城门、驼队、牛车、店肆和木桥属于合理的创作题材；参考故宫博物院的[张择端清明上河图卷介绍](https://www.dpm.org.cn/collection/paint/228226.html)，其记述包括城郊、虹桥、街市以及驼队和车马。这里只核对题材层面，不能据此宣称生成图中屋顶、服饰和每件器物的形制已经通过历史考据。生成画面仍应作为受原作启发的创作，不称原作复刻或实景地图。

美术续项：新增区域人物目前烘焙在背景里；画面偏统一褐灰，清晰度和分层动态仍有提升空间。江户接缝 v2 与晨夕色稿已在美术分支 `ba94ac8`，等待 Claude 按实际切线验收；原生 2× 清晰度没有完成。
