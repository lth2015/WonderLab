# 验收清单：演示反馈之后（2026-11-04 〜 11-09）

给所有者在无痕窗口一次看完用。上一个标签 `poc-r1.10` 停在 10/29（#89）。下面只列 11/04 中午演示后，按同事反馈「像《仙剑奇侠传》，想要对话、寻宝、地图」加上的部分。两个地址内容相同：

- 江户：<https://want.world/edo/> 或 <https://edo.want.world/>
- 中国：<https://want.world/qingming/> 或 <https://qingming.want.world/>

**看得最快的办法**：在江户里玩完前两三个故事（约 10 分钟），再打开绘卷帐，用「この場面を回想する」直接看后面几个故事的插画。回想不加钱，也不改动进度。

## 江户

| 看什么 | 在哪里、怎么做 | 应该看到 | PR |
| --- | --- | --- | --- |
| 町の絵図（地图） | 点左上角地名旁的「図」 | 长卷折成四段；红框是当前位置；见过的人以小立绘头像显示在各自位置；「依」= 有人在等；「？」= 失物线索；点哪一段就走到哪里 | #212 #229 |
| 地图入口提示 | 做完第一个故事「風のいたずら」后 | 提示「左上の「図」を押すと…」；打开过一次地图后就不再出现 | #218 |
| 探し物（寻宝） | 做完「風のいたずら」后，街上会出现偶尔闪光的小东西；或者听物主自己说起 | 物主道谢之后才会提起失物；提起后地图上出现「？」；捡到放进持ち物，还给物主有道谢；全部六件还完，宗吉会说一句话 | #212 |
| 立绘 | 任何对话 | 文字左边有这个人的半身画像（十个人），和街上的样子一致 | #213 |
| ご隠居 | 茶店一带（中午） | 是一位老爷爷（以前看起来像老太太） | #214 |
| 町の人のこと | 和人说话 →「少し話す」→「町の人のこと…」 | 可以问 A 怎么看 B（共 55 句）；只能问一起经历过故事的人 | #213 |
| 即兴对话会看时间和天气 | 傍晚或下雨时，「少し話す」→「今日の町のこと」 | 说的话和傍晚、雨天对得上（模型生成的、备用台本都一样） | #227 #228 |
| 一服（6 文） | 喜助 →「一服する（6文）」 | 画面换成茶店长凳望出去的插画；看到帮过的人后来的日子；有倒茶声（需要打开声音） | #215 #220 #223 |
| 記念の題箋（12 文） | 清太 →「題箋を見る」 | 有三种可买；买了以后，绘卷帐的页面上可以「題箋を貼りかえる」 | #215 |
| 人物帳 | 绘卷帐 → 上方「町の人」 | 每人一栏：立绘、交情（初めて／顔なじみ／気の置けない間柄）、一起经历过的故事、还回的失物、「このごろの様子」；点「会いに行く」直接走过去 | #216 #224 |
| 故事插画 | 这些场面会出现插画：ご隠居の散歩（河边长凳）、雨宿り（伞）、河岸の朝（亀吉）、夕暮れの灯（灯笼）、橋のたもと（九人合影） | 对话时整个画面换成一幅插画，说完就回到街上 | #221 #222 #230 |
| 键盘 | 只用 Tab 和 Enter | 地图的四段、标记列表、「少し話す」和买东西的面板都能操作，焦点不会跑丢 | #219 #226 |
| 大字号 | 手机字号调到最大 | 底部按钮不会断字；顶部地名会缩成「…」，但不和别的东西重叠 | #213 #216 |
