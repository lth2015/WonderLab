# 试玩当天：一页流程卡（主持人用）

打印或放在手边。详细说明见 [README.md](README.md)。

## 开始前（10 分钟）

- [ ] 手机充电；屏幕亮度调高；关掉通知。
- [ ] 江户：`https://want.world/edo/?session=1`　中国：`https://want.world/qingming/?session=1`
      左上角看到「試遊会」／「试玩会」小标才对。
- [ ] 两作各自点开设置，确认「试玩会」区块在；声音保持关（默认）。
- [ ] 观察表 `observation-sheet.csv` 打开；本场编号从 P01 起。
- [ ] 一半人玩江户、一半人玩中国；有时间的人两个都玩，先后顺序交替。

## 每一位（约 20 分钟）

| 时间 | 做什么 |
| --- | --- |
| 0:00 | 只说一句（不多讲）：江户「これは江戸・日本橋の町を歩く短い遊びです。好きなように触ってみてください。」／中国「这是在汴河岸边走走看看的小游戏，想点哪里都可以。」 |
| 0:00–10:00 | 不提示、不解释。被问到只说「自分で試してみてください／你自己试试看」。卡住超过 2 分钟可提示一次，观察表记「有」。 |
| 边看边记 | 观察表的「看到的玩法」「卡住或不明白」两栏随手记（见下方清单）。 |
| 10:00 | 请对方停下，导出记录：江户 設定 →「試遊会」→「この方の試遊の記録を書き出す」；中国 设置 →「试玩会 · 本位玩家」→「导出本位记录」。文件改名 `P01-edo.json` 等。 |
| 10:00–13:00 | 两个问题，一字不改：「さっきの町で、誰かに何か変化がありましたか？」「次にどこへ行ってみたいですか？」（中文：「刚才在河边，有谁发生了什么变化吗？」「接下来想去哪里看看？」） |
| 13:00–15:00 | 自由感想一句（记原话要点，不记名字）。 |
| 结束 | 江户「次の方へ」→「消して次の方へ」；中国「下一位」→「确认开始下一位」。 |

## 江户：值得特别留意的地方

这几种玩法刚上线，只在模拟器里验过：

- **入口**：第一次拖动画卷用了多久；有没有找到会动的纸（第一个故事）。
- **「近くのこと」**：有没有人打开；开了以后是否知道该去哪。
- **描线（写生时）**：手指描得顺不顺；有没有人直接按「なぞらずに描く」。
- **抓时机（動く人を描く）**：知不知道要等人走进框里。
- **同行（ご隠居の散歩）**：一分半的路，会不会觉得长；有没有把老人甩在后面。
- **雨**：有没有人发现上面的「晴／雨」。
- **说话的路人**：点没点路人；点完后有没有继续点别人。

11/04–05 按同事演示反馈（「像仙剑，想要对话、寻宝、地图」）新加的，也请留意：

- **町の絵図（地图）**：有没有人点左上角地名旁的「図」；点了以后会不会用「点一段就走过去」。
- **探し物（寻宝）**：有没有人先在街上发现发光的小东西；听人说丢了东西后，会不会去地图上找「？」。
- **立绘与「町の人のこと」**：对话框左边的立绘有没有人提起；「少し話す」里会不会去问别人的事。
- **買い物**：有没有人在喜助那里「一服」或在清太那里买「題箋」；花钱时有没有犹豫或误会。
- **人物帳（絵巻帳的「町の人」）**：有没有人自己翻到；会不会用「会いに行く」。

## 中国：值得特别留意的地方

- 热点反应（#195 新上线）：点了以后看不看得出有反应。
- 路人往返走动：会不会误点到路人。
- 画册、留念图、赠友图：有没有人主动去做。
