# 两作真人试玩工具包（江户编・汴河拾光）

当天直接用：**[当日流程.md](当日流程.md)**（一页流程卡）、[真机检查.md](真机检查.md)（试玩前自查）、[报告模板.md](报告模板.md)（试玩后填写）。

规格书（`docs/painted-worlds/spec/清明上河図-江戸編-仕様書-v1.0.md` 第 289 行）给出的扩展内部基准：

| 指标 | 基准 | 怎么得到 |
| --- | --- | --- |
| 入场 30 秒内做出首次有效操作 | ≥80% | 试玩记录（自动） |
| 10 分钟内独立完成一个小话 | ≥70% | 试玩记录（自动）＋观察（是否需要提示） |
| 能说出「谁、发生了什么变化」 | ≥60% | 试玩后访谈（观察表） |
| 主动去探索别的地方 | 过半 | 观察表 |

规格书同时要求：写明实际人数和取整方式，**不能用小样本证明市场**；达不到时修入口、反应和故事，不要靠增加内容数量来补。

## 准备

- 手机（iPhone Safari、Android Chrome 各至少一台为佳）。
- 链接：江户 `https://want.world/edo/?session=1`（试玩会模式，见下），中国 `https://want.world/qingming/?session=1`。
- 每位试玩者一行观察表（`observation-sheet.csv`）。
- 不录屏、不记名字。编号用 P01、P02……

### 试玩会模式（`?session=1`）

同一台手机轮流给几个人玩时使用。

- 网址加 `?session=1`。画卷左上角有小标「試遊会」／「试玩会」。
- 进度存在单独的存档里（江户 `ww:qingming-edo:save:session`；中国 `ww:qingming-china:save:v1:session`），**不会碰到这台手机本来的存档**；不加参数打开就是平常的样子。
- 试玩记录也存在这台手机上（江户 `ww:qingming-edo:study:session`；中国 `ww:qingming-china:study:session`），中途刷新不会丢；记录里 `environment` 为 `playtest-session`。中途刷新不记作「再訪」。
- 每位结束，先导出，再交给下一位（文件名已带本场编号）：
  - 江户：設定 → 「試遊会」→「この方の試遊の記録を書き出す」，再按「次の方へ」→「消して次の方へ」。
  - 中国：设置 → 「试玩会·本位玩家」→「导出本位记录」，再按「下一位」→「确认开始下一位」。
- 只清掉本作品的试玩进度和记录，回到标题页；下一位是新的 session_id。取消确认则继续本位。日常进度保留。
- 不需要再手动「最初からやり直す」。

## 主持方式（每人约 15 分钟）

1. 只说一句（不要多讲）：
   - 江户：「これは江戸・日本橋の町を歩く短い遊びです。好きなように触ってみてください。」
   - 中国：「这是在汴河岸边走走看看的小游戏，想点哪里都可以。」
2. 计时 10 分钟。**不提示、不解释**。试玩者开口问时，只回答「自分で試してみてください／你自己试试看」；如果卡住超过 2 分钟，可以给一次提示，并在观察表里记「提示あり」。
3. 10 分钟后请试玩者导出记录：
   - 江户（试玩会模式）：設定 → 「試遊会」→「この方の試遊の記録を書き出す」，然后「次の方へ」
   - 中国（试玩会模式）：设置 → 「试玩会·本位玩家」→「导出本位记录」，然后「下一位」；普通模式仍在「本次试玩记录与隐私」中导出。
   - 文件名改成编号，例如 `P01-edo.json`，放进同一个文件夹。
4. 访谈两个问题（一字不改）：
   - 「さっきの町で、誰かに何か変化がありましたか？」／「刚才在河边，有谁发生了什么变化吗？」
   - 「次にどこへ行ってみたいですか？」／「接下来想去哪里看看？」
   能说出具体人物和变化的，「説明できた」记 yes。

## 汇总

```sh
node docs/painted-worlds/playtest/summarize.mjs <导出的 JSON 所在文件夹>
```

- 按作品、按会期输出：首次操作用时、第一个小话完成用时、是否打开画册、导出／分享尝试、错误代码、是否带档回访。
- 输出四项指标里能自动算的两项，同时给出「分子/分母」和百分比（四舍五入到整数）。
- `elapsed_ms` 从本位玩家首次载入开始计，包含标题画面停留；试玩会模式刷新后继续按首次载入的墙上时间计时（含后台停留），所以 30 秒的口径偏严。普通模式刷新另开一场。
- 另外两项（能说出变化、主动探索）用观察表人工统计。
- 江户还会列出各种新玩法的使用情况（`play details`，次数 / 人数）：描线是描完还是跳过（`trace:traced/skipped/left`）、抓时机点空几次（`ugoki:miss/caught`）、同行时把老人甩在后面（`companion:behind/arrived`）、是否发现晴雨（`weather:rain/clear`）、点了说话的路人（`passer:tapped`）、打开「近くのこと」和「ほかの頼みごと」（`nearby:opened`、`nearby_more:opened`）、开了几章（`chapter:opened`）。

## 隐私

- 普通模式的记录仅在浏览器内存中，刷新清空。试玩会模式将本位的记录保存在本机浏览器，刷新可续接；「下一位」清除本位记录。由试玩者或主持人主动导出，不上传，不含名字、存档内容、网址参数和自由文本。
- 试玩会模式只用于同一台设备轮流试玩；同一位期间不要同时操作多个标签页。退出或最后一位结束前，先导出，再按「下一位」清除最后一位数据。
- 试玩结束后，汇总只保留编号和数字。导出的 JSON 按观察表的约定保管或删除。

## 样例

`samples/` 里是自动脚本跑出来的真实导出文件，不是真人数据：江户第一个故事一轮、刷新后的回访一轮，以及 Codex 交付的中国纸铺一轮。可以先用它们试运行：

```sh
node docs/painted-worlds/playtest/summarize.mjs docs/painted-worlds/playtest/samples
```

注意：现在两作的 `build_id` 都是 `unversioned`，同一天内不同部署的数据请按日期分开放。
