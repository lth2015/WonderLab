## 整卷导出等待

回应 Claude 线上首次制作用时 21.7s 的观察：向前预取最多四个背景瓦片，只绘制当前瓦片，仍只保留一张活动画布。缓存按每次制作隔离，同一源图仅请求一次。制作成功、失败或取消都会中止该任务剩余请求，释放画布与临时 URL。

在每个瓦片额外等待 250ms 的本地模拟中，整卷制作从 6.69s 降至 2.51s，JPEG SHA-256 完全相同。原版本桥栏的相邻瓦片会局部并发，观测峰值为 2；新版本峰值为 4，20 个瓦片仍各请求一次。这个模拟不能直接换算线上或真机耗时。

结果：[prefetch-result.json](prefetch-result.json)、[prefetch-cancel-result.json](prefetch-cancel-result.json)。

## 下载与资源回收

- 保留 #166 将下载链接接入 DOM 再点击的行为。点击抛错时也移除链接，并安排 Blob URL 回收；失败后能再次保存。
- 普通留念图与赠友 PNG 在编码完成或失败后清空画布尺寸，避免反复导出时保留约 10MB 的原始像素缓冲。生成的两种 PNG 与原版本字节一致。
- 真实下载检查了中文 PNG/赠友 PNG/存档 JSON 的文件名和内容，存档原文保持不变；检查了链接连接状态、故障后的链接/URL 清理和重试。
- 重跑 C1 完整浏览器回归：两档尺寸、20 段顺序与源像素、三种短屏/大字、取消、源图错误、画布分配失败和编码失败均通过。四个预取同时等待时，取消或任一源图失败都能终止其余请求，失败后重试恢复。

结果：[download-result.json](download-result.json)、[scroll-regression-result.json](scroll-regression-result.json)。
