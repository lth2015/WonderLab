# 中国篇赠友画纸 1B

从已解锁画页点「送给朋友」，按「选景 → 选句 → 看画纸」制作 1440×1800 PNG。底部操作区固定；作品链接收进可展开的小节。四类赠言各四句，分类 ID 与江户篇一致，中文原文见 `apps/qingming-china/src/content/gift.ts`。

## 图像与数据

- `GiftPaper` 只接受 `{pageId, note, close}`，不读取进度、文钱、任务数或用户存档；导出的图像不含游戏统计。
- 「执纸的手」是首张 J02 绘画式构图，复用纸铺背景、人物与纸张素材。其余十四张暂用现有 `JournalArt`，后续逐张替换，未宣称十五张全部完成 J02。
- 生成时先克隆 SVG，再内嵌图片素材，最后转成 PNG。预览、保存与原生分享复用同一个 PNG Blob。过期生成结果丢弃；失败可重试；图片缓存有上限，Blob URL 会释放。
- 原生分享在点击手势内调用，只发送图片、标题和所选赠言。设备不支持图片分享时提示先保存；取消不弹错误。作品链接仅带已知场景，不沿用当前 URL 的查询参数或片段。
- 不修改存档结构、故事奖励或付费权益；普通画页原有导出仍保留。

## 验证

- `npm run test:qingming`：70 项通过，新增 5 项覆盖分类、16 句排版、15 张画页的数据边界、首张绘画式构图和两种挂载路径的链接。
- 合入 `origin/main@f3a1afd` 后，`npm run build` 通过；根目录 `npm test` 488 项通过，4 项原有数据集测试跳过。
- 打包后的独立根路径和 `/qingming/` 子路径均走通故事到生成/下载，PNG 宽度 1440，未发生脚本错误或 HTTP 错误，见 [production-result.json](production-result.json)。
- Chromium 浏览器走通实际「一纸春风」到赠友流程，比较预览、下载及原生分享附件的 SHA-256；快速切换赠言时延迟旧渲染，确认不会覆盖新图。
- 检查原生取消、分享能力探测抛错、剪贴板拒绝后的手动复制、素材失败重试，以及制作前后存档原文相同。
- 360×740、390×844、1280×800，开启 150% 大字阅读，检查三步的操作区可见、键盘焦点、Escape 关闭及无横向溢出；15 种场景用合法合成存档检查，不能视作全部故事的端到端验收。
- 原生分享通过浏览器接口替身验证文件内容和错误分支；未验证真实手机系统分享面板。want.world 在此环境被网络策略拒绝，线上由 Claude 发布后复验。

一般弹窗的固定返回按钮与设置/画册内容折叠另外交付，本次只覆盖赠友流程。
