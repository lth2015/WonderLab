# C4：中国篇长卷地图

2026-11-06，Codex。分支 `codex/china-town-map`，代码提交 `8865e17`；基于 main@`af47e62`。回应 Claude 的 C4→C5→C6 分工，本次只交付 C4，由 Claude 审阅、开 PR、部署并线上复验。

现在可从画卷地名旁的「地图」或「附近 → 展开长卷地图」展开全卷。四段从卷首野渡排到城内静巷；鼠标/触摸点一处即可过去，键盘 Tab 选中一段后 Enter 或空格前往段落中间。「标记所在」用文字列出同一批标记，选中后走到对应位置。前往后焦点交回画卷，关闭则回到原入口。

## 标记与发现

- 视野框来自 ScrollView 的实际、已经限制在卷内的视野；跨折口时分别画在两段上，旋转和缩放后也按实际范围更新。只在地图打开时回传视野，平时拖动不为地图额外刷新 App。
- 「待」只表示明确的待办相遇，不是每位尚未寒暄的人。绳索理好后改为认货签，货签认出后指向阿成；香囊线索按已听内容指向何娘/阿成，齐备后指向陈生。完成的请求移除，重逢时再出现。
- 纸铺首画后开放描柳与晾画；同一人物的两个邀请合并为一个位置，文字列表保留两个标题。远端城门、货港、乡野故事，见到对应环境或开始故事后才标记，不提前把全卷变成待办列表。
- 纸铺首画开放新请求后，关闭面板时提示一次地图入口；打开过地图后不再提醒。遵循玩家「闲时提示」开关，损坏存档待备份时不写提示状态。
- **C5 接口已预留，当前不虚构失物。** `LostMapHint` 只接收固定内容表的 id、位置、标签和 heard/found 状态。纯函数只显示已听过、尚未拾取的线索，去重并剔除非法位置；存在这类标记时才显示「？」图例。C5 另行实现拾取/归还与状态，不在 C4 添未交付玩法。

## 数据与素材

地图只增加 `progress.map={opened,hinted}` 两个本机布尔值，`parseSave` 为旧档补默认值并校验类型。版本仍为5，与已有可选展示数据的兼容方式一致，不改原故事 ID、步骤、画册、文钱或存档键。正常与试玩会保持各自独立的存档。

试玩事件只有固定枚举 `play_detail {what:'map', outcome:'opened'|'tapped'}`。不记录地图坐标、标记内容、人物台词或用户文本；地图查看不冒充故事首个有效操作，不上传数据。原有两作汇总脚本可按次数/人数汇总。

缩略图沿用中国篇二十张底画，以1200单位一张的原顺序缩为160px，五张为一段，四段合成800×640 WebP，106410字节（约104 KiB）。只在打开地图后加载。地图文字与标记是界面元素，未烘焙进图片；没有新人物生成、伪文字或衣手绘制。原图像与动态叠层不修改。
