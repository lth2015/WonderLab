## 共同的画法

以细线勾出真实器物，以薄淡彩建立材料与前后关系。细节密度来自每个人正在做的事、器物的使用痕迹与合理的建筑连接，不能只靠铺更多瓦线、重复路人和纸张噪点。

下列是制作目标，不是对生成图像像素的反推测量。以 1000×700 世界单位的一段为基准，重要结构线约 0.7—1.1 单位，衣褶、瓦片、绳股等细线约 0.25—0.5 单位；2× 输出时同步放大。外轮廓不要全部等粗，近景略实、远景渐淡，避免纯黑描边。

| 用途 | 目标色 |
|---|---|
| 纸底 | 米绢 `#e9ddbd`，保留亮部，不做满屏灰黄滤镜 |
| 主墨 / 远墨 | `#514d3e` / `#96917d` |
| 河水 / 柳叶 | `#95a99a` / `#849068` |
| 旧木 / 土赭 | `#967555` / `#bba070` |
| 朱色点睛 | `#a25540`，用于少量布料与界面印章 |

晨：纸底略冷亮，水为灰青、木色克制；昼：米白更清楚，衣料和货物增加明暗；暮：薄赭洗染、墨色略暖，保持脸部与任务物品可辨。三时段先做色稿，不用一张橙色透明层覆盖所有材质。

纸纹只在近看时可见，不得吞掉人物眼鼻、船缆和文字。云霞用于疏淡过渡，江户篇如保留金云，以薄染、破边和留白融入远景，避免大片纯色几何云块。两作可以使用不同的具体云形。

人物约 5.5—6 头身，常用角色高度约 60—70 世界单位；头、肩、袖、腰、膝和脚的转折需可辨。不要用圆头接三角袍替代人物。先统一一个人物的站立、伸手、致谢三个姿态的体型、衣色、脚底落点，再扩充走路、挑担、搬货、坐下等姿势。脸不必写真，但要有朝向；袖口不能直接代替手。宋人与江户人的衣制、发式、鞋履分别画，不从同一人像换色复制。

建筑采用可步移观看的斜俯视组织，不强行使用单一消失点。每栋建筑内部的檐、梁、柱、地板方向必须自洽；屋顶瓦作有疏密变化，门窗有真实厚度，物件有接触面。整条街保留可走的间隙，不把高密度做成器物堆积。

题签、招牌、落款用独立可校对的文字层。生成图中要求招牌留白；中国篇使用简体界面，江户篇按自己的文字与年代设定填写。界面可以延续米纸、灰绿、朱印与宋/衬线字的基调，禁止把小字作为装饰填满画面。

## 对江户篇临时画面的直接意见

已查看 `2026-10-31-phone-street.png`。目前的色调与长卷入口可以保留，但人物轮廓、建筑面、霞块都过于规则；把生成图直接叠在这些几何角色后面，会产生两种画风。

优先替换一段店头、一位人物和一组纸/文镇：先让屋架、瓦作、纸层与布幔有材料感，让按纸、站立、道谢能看出手臂动作。先验证手机上是否认得出纸角和人物动作，再增加路人数量。不要先把整条街换成不可交互的一张精绘背景。

中国样稿可借鉴笔触与层次；其中桥形、屋面、店铺布局、衣装和货船不供江户篇直接复用。江户篇以其独立参考为准，重新确定桥头构件、暖帘和器具。

## 素材切分与交付

参考全景实际为 2172×724，并非江户场景的 3000×700。不要拉伸贴满；视角、地面接触线与热点需要在本作镜头中重新标定。下一轮运行素材按三个连续的 1000×700 画面段制作，推荐每段 2× 栅格输出、两侧各留 48—80 世界单位的衔接余量。先用目标手机检查质量，再确定最终分辨率。

| 层 | 建议内容与格式 | 注意事项 |
|---|---|---|
| 远景 | 城郭、远屋、薄霞；WebP/PNG | 不烘焙主要人物与近处摇动的柳枝 |
| 中景静物 | 建筑、岸、桥、店铺陈设；分段 WebP/PNG | 交互纸张、茶器、货担与桥栏遮挡分别留层 |
| 动态物件 | 船、纸角、绳索、蒸汽、招幌；透明 PNG/WebP 或可编辑 SVG | 只为这些局部制作动效，别整体摇晃街道 |
| 近景 | 少量树枝、檐角、栏杆；透明 PNG/WebP | 不遮挡操作目标；人物穿过时遮挡关系明确 |
| 主要人物 | 同一角色三姿态，各自透明底，建议 256×384 起 | 同画布、同缩放、脚底锚点一致，四边留边；阴影独立 |
| 文本 / 命中 | HTML/SVG 与世界坐标元数据 | 与美术分离，热区按屏幕保持至少 44×44 CSS 像素 |

每份素材同时给出世界范围、像素尺寸、锚点、可遮挡区域与证据类型。不要把一张完整合成图“裁三块”后声称已经完成远中近分层；人物移除后的背景也需有完整补画。

首个可玩画面的压缩必要资源总计仍控制在 5 MB 内，建议给场景约 2.5 MB、人物与物件约 1 MB、其余资源及余量约 1.5 MB。这是初始预算，尚无分层压缩结果。当前 3.79 MB PNG 是参考交付，不进入首屏资源包。

## 首张样稿的自查与待修

- 已查看实际整图：纸铺、茶桌、岸边劳动、船只和柳叶均有细节，画面不含生成文字；材质层次可作为下一轮方向。
- 桥体使用了连续弧形、层叠木梁的表现，不能直接作为原画虹桥结构的复原依据，需单独校正桥体构造。
- 船缆、系缆桩和岸边交接动作需要在局部放大后逐一修连，避免绳索无端消失或接错对象。
- 小人物衣纹与方向可辨，但整图分辨率不足以确认所有手指与肢体细节；未通过逐个人物精修验收，不能声称全部无异常。
- 当前为一张不透明合成图，没有三姿态角色、透明边或背景补画，不能当作已完成素材包。
