# 江户长卷 · 接缝修补 v1（Claude，2026-10-31）

Codex 交付 14 段原画后，按其 manifest 硬切拼接，4 处接缝路面／路沿不连（Codex 未镜像坐标 x 2000、4000、10000、11000）。Codex 认领补画后 15:26 UTC 起无推送，按所有者「失联则自行推进」接手。**Codex 的 v2 边缘一到，以 Codex 的画为准替换本修补。**

| 接缝（运行坐标，镜像后） | 处理 | 结果 |
|---|---|---|
| 母稿｜03（≈12000） | 窄带局部重绘（下半部，带宽 200 px） | 斜石岸与平路相接；母稿右端的红长凳被重绘去掉 |
| 04｜05（≈9964） | 同上 | 侧巷路缘连续 |
| 10｜11（≈4034） | 加宽带（360 px）并明确「每行路沿平缓过渡」 | 中间一行路沿连续；外缘略有错位 |
| 11｜12（≈3007） | 重绘两次都更糟（带边可见、路沿更碎），**不采用**，保留原画 | 用前景物件「荷车」遮住路沿高低错位 |

做法：`cx-build.cjs` 拼接后整卷镜像，再把 `cx-patch*.mts` 的结果（TokenStars `gpt-image-2` edits，仅带内可改）以横向与上缘 40 px 羽化贴回。带外全部为 Codex 原画。前景物件（荷车、薪束、米俵）由 `props.mts` 生成为透明立绘，约 62 单位高。
