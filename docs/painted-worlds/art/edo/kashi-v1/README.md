# 江户编 · 向こう岸の河岸（2026-11-02，Claude）

路线 #158 第 4 项：长卷向右延伸两段，日本桥过桥后是对岸早晨的河岸；同时新增第四个故事「河岸の朝」。

## 怎么做的
1. **外扩方向向右**：原有的 14 段是 Codex 的画，已左右镜像成桥在右。这次从 `street-13.webp`（缩放到 1024 高）右边取 512 px，放到新画布左侧，用 TokenStars `gpt-image-2` 的 `/v1/images/edits` 往右续画，连续三次（K1：桥落到对岸、石阶、柳；K2：一排河岸棚屋、篮、樽、系着的荷舟；K3：河岸收尾，开阔的水面和留白的纸）。脚本：`kashi.mts`。
2. **拼接**：每个 512 px 重叠区先按通道增益对齐颜色（1.00–1.04），再用动态规划找一条「两版差异最小」的切线，只羽化 6 px（`stitch.py`，方法同 `../README.md` 第一轮第 3 步；在放着 K1–K3 的目录里运行）。第一条切线落在第 13 段内，所以 `street-13.webp` 右端 168 px 换成了新画（桥的延续）。
3. **切分**：拼好的条幅缩回 980 高，切成 `street-14/15.webp`（每段 1400×980＝1000×700 场景单位）。
4. **人物**：おまつ、亀吉各生成一张三姿态透明图，按透明空隙切开（`cut.py`）。对岸在画面更深处，所以人物比主街略小（おまつ 74、亀吉 50 单位）。

生成次数：背景 3 次 + 人物 2 次 = 5 次 high。

## 提示词要点
沿用第二轮的 INK 段（淡彩、墨线、无文字、无现代物）；外扩时只说「与左边已画部分同比例、同水平线、同纸色」，不写绝对大小（第二轮发现写大小会让每段越来越小）；背景里不画人和动物。
