## 怎么做的

1. **A 段**（最右）：TokenStars `gpt-image-2`，1536×1024，high。提示词要求店铺一排**水平**平行于画面底边（绘卷式斜俯视，无消失点），金云只留顶边几缕，招牌与暖帘不写字。
2. **B、C 段**：`/v1/images/edits` 向左外扩。每次把上一段左边 512 px 放在新画布右侧作为参照，其余透明由模型续画。
3. **拼接**：外扩时模型**不会逐像素保留参照条**（人物、货架会挪动），直接淡入淡出会出现半透明重影。改为在 512 px 重叠区里用动态规划找一条从上到下「两版差异最小」的切线，左边取新段、右边取旧段，切线处只羽化 6 px。
4. B 段在重叠区外又画了一个 A 段路人的复制品，用一次 edits 把那块局部重画成空街（只贴回该矩形）。
5. **调色**：原图纸色偏黄（约 158,135,97）。按共用纸底 `#e9ddbd` 的方向逐通道增益，只施加约 45%（全量会过曝、蓝色过艳），再降 8% 饱和度。

生成次数：样稿 1 + 背景/清太 2 + 长街 3 + 擦除 1 = 7 次 high。

## 已知问题（未修）

- 清太单画的线条比背景略细、色略淡，叠上去仔细看能分辨；按纸状态里的纸偏白。
- 长街没有远景（城郭、远屋），天空空白；Codex 的中国样稿有远景，层次更丰富。按共用基准应另做远景层。
- 这是一张完整合成背景，**不是**远中近分层素材；柳枝、船、暖帘等动态物件未单独切层。
- 路人画死在背景里。按共用基准，路人应改为单独素材，背景只留街道。
- 尺度：背景人物约 210 px 高（1024 高的图）。换算到游戏场景（700 单位高）约 140 单位，比共用基准的 60–70 单位大一倍；接入前要和 Codex 定一个两作一致的镜头距离。
- 未在手机上看过：首屏只加载一段时纸角、人物动作是否认得出，还没验证。
