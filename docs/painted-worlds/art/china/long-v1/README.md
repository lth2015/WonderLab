# 汴河拾光 长卷 v1（2026-11-01，Claude 代 Codex）

Codex 在 2026-10-31 13:43 UTC 认领了「中国十四景连续长卷」，之后失联，原画没有推送。所有者指示由 Claude 接手。本版以 Codex 的河景原画 `river-v1.webp`（2172×724，虹桥—茶坊—纸铺）为种子，用 TokenStars gpt-image-2（所有者批准）向两侧外扩。

- **尺寸**：24000×1200 世界单位，20 块 1024×1024 webp（`apps/qingming-china/public/art/china/scroll/`，共约 3.7 MB，只加载镜头附近的块）。原画段保持局部坐标 0–3600，长卷原点 `ORIGIN = 10800`。
- **方法**（`cn-long.mts`）：
  - 每步保留已画好的 512 px，新增 1024 px。
  - 提示词沿用 Codex 的风格词，并写入绝对位置（远景在上 15%、近处屋顶 12–30%、岸或街在 45–55%、人约为画高 1/9），防止尺寸逐段漂移。
  - `cn-stitch.cjs` 以 48 px 羽化拼接，`cn-tiles.cjs` 负责切块。
- **顺序**（参照原作卷首到卷尾，屏幕上从右到左）：
  - 虹桥以东：野渡（卷首）→ 麦田、渡船 → 村口、驴队 → 水磨 → 河畔客店 → 船坞 → 货港 → 水埠浣衣 → [原画：纸铺、茶坊、虹桥]。
  - 虹桥以西：桥头摊棚 → 河畔正店 → 染坊与木作 → 河道转弯、大道车马 → 城门与驼队 → 城内市肆 → 寺前井台 → 静巷小河（卷尾）。
- **状态**：AI 生成的制作素材，没有输入馆藏图像。画中人物是画的一部分，不可交互；新区域有 13 处可点的小景，只给提示文字。
- **待 Codex 复核**：
  - 画面的历史合理性：城门形制、正店的彩楼欢门没有文字。
  - 接缝：每步的保留区就是上一张图本身，目视没有段差，但没有逐像素复验。
  - 如有 Codex 的版本，以 Codex 的为准替换。

`full-preview.webp` 是整卷缩略图。
