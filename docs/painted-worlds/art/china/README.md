五张合计 2,864,856 字节（约 2.73 MiB）；尺寸是生成实际尺寸，没有放大后声称原生 2×。实际文件散列、字节和人物裁片见 `runtime-manifest-v1.json`；完整提示词见 `prompts-v1.json`。图像已在真实浏览器纸色背景上检查，透明图集没有预览渲染器所见的红黄边缘。

画卷使用 3600×1200 坐标，以维持底景 3:1。主角默认实体高为 1200×90/700 = 154.286；世界显示高 700 CSS 像素时为 90 像素。路人高约 100–124（对应 58–72），对话近景实体高 140。此值取人物实体，不含透明留白。三姿态按同角色站姿缩放，逐帧鞋底锚点一致；地面投影由渲染器独立绘制。

`PaintedArt.tsx` 通过 SVG 子视口引用图集；没有用等分网格截断手臂。角色、船、小物、前景各自摆放；角色按脚下 y 排序。`layout.ts` 与 `content.ts` 同时服务画面、相机、点击热区；热区至少 48×48 CSS 像素。节点动作、送货地点、茶客入座均来自既有存档状态，旧档无需重置。

本轮仍有明确后续项：远/中景未拆成两层；路人暂复用主角立绘，没有完整步行动画；未生产带 64 世界单位重叠的原生 2× 分段；画册仍为矢量小画。当前底景是风格与可玩接入过渡稿，不能计作所有 13 条已全部交付。画中城郭、建筑和人物为原创虚构，非文物图像复原。

## 桥面落脚修正

首轮路人虽然对齐了精灵鞋底，但独立填写的场景 y 坐标没有对照可行走桥面，导致桥中和东坡四人落在桥拱轮廓下。已按底图原生坐标描出桥面边界，七位桥上人物移至桥面内部；前侧三道横栏从同一底图按原位重新遮挡在人物前方。站姿人物的水平滑移动画已移除，等待具有步态帧及地形路径后再启用行走。

`walkers.test.ts` 用独立标注的桥面多边形校验双脚，旧坐标下 7 项中 4 项失败，修正后全部通过。验收截图见 `screenshots/china-bridge-grounded-middle-v1.png` 与 `china-bridge-grounded-west-v1.png`（相对于 painted-worlds 目录）。回归测试只能校验标注边界，实际视觉遮挡另经浏览器截图核对。
