五张合计 2,864,856 字节（约 2.73 MiB）；尺寸是生成实际尺寸，没有放大后声称原生 2×。实际文件散列、字节和人物裁片见 `runtime-manifest-v1.json`；完整提示词见 `prompts-v1.json`。图像已在真实浏览器纸色背景上检查，透明图集没有预览渲染器所见的红黄边缘。

画卷使用 3600×1200 坐标，以维持底景 3:1。主角默认实体高为 1200×90/700 = 154.286；世界显示高 700 CSS 像素时为 90 像素。路人高约 99–113（对应 58–66），对话近景实体高 140。此值取人物实体，不含透明留白。三姿态按同角色站姿缩放，逐帧鞋底锚点一致；地面投影由渲染器独立绘制。

`PaintedArt.tsx` 通过 SVG 子视口引用图集；没有用等分网格截断手臂。角色、船、小物、前景各自摆放；角色按脚下 y 排序。`layout.ts` 与 `content.ts` 同时服务画面、相机、点击热区；热区至少 48×48 CSS 像素。节点动作、送货地点、茶客入座均来自既有存档状态，旧档无需重置。

本轮仍有明确后续项：远/中景未拆成两层；路人暂复用主角立绘，没有完整步行动画；未生产带 64 世界单位重叠的原生 2× 分段；画册仍为矢量小画。当前底景是风格与可玩接入过渡稿，不能计作所有 13 条已全部交付。画中城郭、建筑和人物为原创虚构，非文物图像复原。
