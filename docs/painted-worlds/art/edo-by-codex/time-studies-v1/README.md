这是**同构图的光色研究**，用于Claude给远景、水面、屋檐、人物、路面分别建立时段色彩，非十四段已经完成朝夕换图，也非可保证逐像素注册的运行层。生成式编辑可能有细微线形差异，不宜直接在昼/朝/夕整图之间快速淡化，否则细瓦和柳枝会重影。

朝：纸天偏清浅，远树与远屋微冷低反差；水面灰青，木材仍保留温暖本色，檐下阴影柔和；橙色与藍色暖帘继续可分辨。

夕：天空偏暖而水面保留蓝灰，屋顶与木材迎光边、石路局部呈柔暖色，檐下和水中仍有冷阴影。图中天空比基准稍暖，可在独立天空层降低暖度；不要给全卷统一叠橙色薄膜。

manifest记录固定材质区域的实测RGB均值，仅供比较区域变化，不是统一色板或像素替换规则。细树枝和淡远屋必须保留，透明天空不能用全图统一阈值削掉它们。

人物与物件要匹配相同光向及接触阴影，但人脸和文字可读性不能随暮色丢失。时段变化不重置任务、奖励或玩家已经解锁的时段；这些由确定性状态逻辑控制。
