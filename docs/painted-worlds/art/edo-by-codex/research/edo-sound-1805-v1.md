# 江户日本桥声音考据：约1805年的报时钟与物卖声

状态：研究交付，未改产品、未录音、未接入或验收声音。  
整理：Codex，2026-11-01（日本时间）。  
适用：以《熈代勝覧》约1805年的日本桥通为创作参照的游戏；不是当年实地声景的复原证明。

## 给 Claude 的可执行结论

| 判断 | 建议 | 证据与边界 |
| --- | --- | --- |
| 可做 | 低密度、画外传来的报时钟；晨、夕均可有一个报时事件 | 石町钟属于昼夜报时制度。声源应在旧本石町三丁目一带，不能放到今天保存铜钟的十思公园。晨夕事件须表示到达报时时刻，不能把整个早晨、傍晚都铺满钟声。[S1] |
| 可做 | 鱼、青菜行商经过时的局部人声层，暂用听不清词义的远近交谈或叫卖声，标为创作音效 | 原卷有这类行业；原卷没有记录他们说了什么，也没有精确时刻。[S3–S5] |
| 可做（有对应人物时） | 募缘行列的小型手铃声 | 藏馆对原卷须原屋附近行列的解说明确提到三位老妇以手铃伴随募缘。这个证据比把任意寺钟铺到全城更直接；节奏、音高仍无记录。[S3] |

| 谨慎做 | 文字说明中举一例短叫卖语，并同时显示资料年代 | 1835写本可以核到「あめこかいな」这一短语，但不足以认定它在1805年日本桥每天出现。暂不据此制作“1805考据原声”。[S8] |
| 暂不做 | 声称还原石町钟在1805的准确音阶、声压、混响、打击间隔；固定每两小时公历整点敲一次 | 没有查到这些测量或记谱。江户用不定时法，不能直接映成全年固定的现代时刻。[S1–S2] |

## 1. 石町钟在哪里，离日本桥北诘多远

### 已核实的位置事实

中央区教育委员会学艺员的文化财说明把江户时期地点记作**本石町三丁目，今日本桥本町四丁目、室町四丁目一带**。铜钟在关东大震灾后才移到十思公园。现存钟被判断为1711年改铸，现代保存地不能用作1805年的声源坐标。[中央区《銅鐘石町時の鐘》，2024-07-24，正文“広報紙コラム”](https://www.city.chuo.lg.jp/a0052/bunkakankou/rekishi/tokyobunkazai/dosyokokutyotokinokane.html) [S1]

**到北诘的距离应取“约0.6公里、数百米外”，不要写成已经精确复原的某个米数。** 算距依据是中央区立图书馆公开地图，而非十思公园到桥的路线。[《本町周辺〜日本橋エリア・現在の町なみ》，印刷页146–147，地图在147页](https://www.library.city.chuo.tokyo.jp/images/upload/2a01.pdf#page=1) [S7]

可复算的图上估计：把该双页PDF等比栅格化至2200×1556后，地图“石町時の鐘・鐘撞堂跡”标点约在(1588,314)，北诘路口约在(1727,803)，200m比例尺约178px；`hypot(139,489) / 178 * 200 ≈ 571m`。这是人工读图的**现代代理点直线距离**。考虑标记、桥头选点和旧钟楼地块范围，给声音设计用约0.5–0.7km区间即可。地图上的遗址标记并不证明1805年的钟楼中心就精确在那里；还欠历史地块的配准。

三种距离不要混用：

- **几何距离**：上述约0.6km；是粗略图测，不是古地图实测。
- **步行距离/时间**：本次未复原1805年的街巷、出入口和可通行路线，**不提供历史步行分钟数**，也不拿今天导航时间替代。
- **传播时间**：只为说明量级，假设直达空气声速343m/s，则600/343约1.75秒；实际路径、气温和风并未复原。这不是“应在游戏延迟1.75秒播放”的史料结论，也不能据此算出音量。声速随介质与温度变化，公式见[NASA Glenn《Speed of Sound》](https://www.grc.nasa.gov/www/k-12/BGP/sound.html) [S9]。

### 可推断的听感，不冒充原声

旧地离北诘是数百米，因此将其处理为**画外远钟**比贴在桥头的近距离撞钟合理，这是空间创作推断。钟是否在某次天气、某个位置清晰盖过鱼市，不能只从距离推定。源强、钟楼结构、建筑遮挡、风向和背景噪声均无本次可用的1805测量。

官方说明有当时410町负担钟撞钱的记述，说明它服务较广范围；行政收费范围不是一张逐点声压/可听度地图。官方所写“黄鐘調”描述的是**今日**钟声，不足以锁定1805在日本桥听见的基频、音程或频谱。[S1] 不要拿现代钟录音的绝对音高和衰减直接冠名“1805准确复原”。

实现时可先用无特定寺名的合成/原创梵钟型余韵，降低突出的近距离锤击感。滤波、响度和衰减以听感验收调整，并在素材说明写“时代参照的创作音效”；本报告不指定伪精确Hz、dB或混响秒数。

## 2. 朝夕是否应响

中央区说明支持昼夜每“一时”报时，并解释“明け六つ”“暮れ六つ”等称法及不定时法。[S1] 因而**晨与夕均可响**，但前提是场景真的跨过相应报时时刻，或把那次过渡明确设为报时瞬间。

不要把“晨景”理解为每次进场都必须敲钟，也不要把“夕景”当作葬礼或除夜钟的语义。昼、夜时段长度随季节改变；[精工博物馆《江戸時代の暮らしと時間》](https://museum.seiko.co.jp/knowledge/relation_07/) [S2]可用于核对制度。它是钟表博物馆对制度的解释，不是石町在1805某日的值班日志。

建议本轮只做“报时事件”的节制提示；**先不重建完整的捨て鐘、计数、分隔节奏**，直到有明确落实到本钟/适用年代的资料。选择“六つ”的时刻名，不等于本次已核实完整敲钟编排。不要硬编码为全年06:00/18:00。现代“日出/日落”的粗略说法也不能替代历史历法中曙暮界限的专门考证。

## 3. 约1805年哪些行业可用，什么时候、喊什么

《熈代勝覧》的藏馆把它断代为约1805，而非卷上有明确签署的精确制作日；馆藏号2002-17。藏馆说明包含商贩、店铺、募缘人群，但画面仍不是声音记录。[柏林国立亚洲艺术博物馆藏品页，Details与Objektbeschreibung](https://search.smb.museum/object/obj-755958) [S3]

| 行业/场景 | 对1805附近的支撑 | 时段边界 | 本轮可用措辞 |
| --- | --- | --- | --- |
| 鱼的立卖、棒手振鱼贩 | 原卷日本桥北诘东侧的鱼市区域；可对照授权原卷局部及第31号说明。[S4] | 原卷无钟点；“清早更热闹”另有较晚图像参照[S6]，只作倾向 | **未查到落实到1805日本桥的原始叫卖文本，留空。** 不自行编“新鲜的鱼便宜卖”等日语。 |
| 菜卖/青物行商 | 原卷有菜卖；第11号原卷局部可复查。[S5] | 不从白日画面推定固定上午/下午营业表 | 留空；可用不可辨词义的人声。 |
| 鱼加工店、固定铺面 | 原卷第27号局部画蒲鉾制作；固定店存在不等于需要街头循环吆喝。[S10] | 未核实 | 留空，不给每家店强制配一句叫卖。 |
| 节令临时市（雏市等） | 原卷第15号区域有雏市及相应陈列。[S11] | 具有节令约束；不能把雏市、端午、年末叫卖全放在同一天 | 留空；游戏若未锁定月份，先不做具体节令口号。 |
| 心太、枇杷叶汤等夏向行商 | 东京都立图书馆所藏《近世流行商人盡詞》保存天明、宽政时期商人形象与呼声记录；展示说明明确称这两项为夏向。[S12] | 较1805早近邻年代，且资料有临摹、转录、补记层；不能断言1805春天仍以同样词句出现 | 暂不配词。可列入未来夏日扩展考据。 |
| 飴売り（卖糖） | 1835《近世流行商人狂哥絵図》有卖糖图及画中词。[S8] | 写本比1805晚30年，又可能回述更早风俗；具体人物/口号不能自动倒推 | 核到短语「あめこかいな」，释意约“来买糖”。**仅作1835记录例，不是1805对白定稿。** |

第31、11、27、15号链接是日本桥观光案内所发布的藏馆授权原卷局部与现代解说。**图像可作为原始视觉资料查看，现代解说不是1805的逐字记录。** 行业判断只取画面所支持的层级；解释中的更广泛商品、年份、人物推定未全部转成游戏史实。[S4–S5,S10–S11]

### 卖声短引文的出处与限制

实际查看了NDL藏《近世流行商人狂哥絵図》**第6コマ左页**“あめこかいな飴”图，采用上述极短片语的现代常用假名转写；不是严格校勘全篇。原书为公版，NDL IIIF元数据标PDM、写本年代天保六年（1835）、索书号W89-N15。直接复核：[NDL第6コマ](https://dl.ndl.go.jp/pid/11038510/1/6)、[该コマ原扫描](https://dl.ndl.go.jp/api/iiif/11038510/R0000006/full/1800,/0/default.jpg)、[馆方IIIF元数据](https://dl.ndl.go.jp/api/iiif/11038510/manifest.json) [S8]。

这只能支撑“1835保存的画中词存在这个片语”；**无当时声音录制，也没有从该页推出1805日本桥的说话者、音调、持续时长或营业时段**。原卷图中的文字不等于可按现代语感唱出来的谱。

## 4. 不宜倒推的资料与仍未解决的项

- **《守貞謾稿》**：NDL明确说明1837起、约三十年写作；很有价值，但比1805晚。[《国立国会図書館月報》747/748号，2023年7/8月，印刷页3](https://dl.ndl.go.jp/view/download/digidepo_12894638_po_geppo230708.pdf?contentNo=1#page=5) [S13]。本轮没有把其中的纳豆、豆腐、荞麦等声词直接装入1805场景。
- **《近世職人尽絵詞》**：与目标年代接近，可继续研究；但词书有沿袭中世职人歌合的成分，不能把所有画中词当作街头录音逐字稿。国立历史民俗博物馆的研究报告特别指出旧翻刻不充分、需要重新解读注释。[2014年度年报，研究“都市風俗と『職人』”，印刷页84](https://archive.rekihaku.ac.jp/research/nenpo/2014/pdf/004.pdf) [S14]。NDL公开的《職人盡繪詞》第1轴为**和田音五郎临摹本**，书写年未详，不能把该实体误写为1805原卷：[馆藏书目](https://ndlsearch.ndl.go.jp/books/R100000039-I11536004)。
- 仍缺：旧钟楼1805地块配准、1805具体日期的打钟日志/计数法、在北诘的听感描写；鱼/菜/豆腐等各行业在1805日本桥的精确原文卖声及可验证语音；昼夜各时段的密度。**这些目前均不可考定，不补造对白。**
- 现代观光页川柳“オランダまで聞こえ”的双关、今天新年敲钟录音、昭和行商回忆，都不能独自证明1805年的实际声学范围或节奏。下一步有针对性地查原始文献即可，不必为本轮环境音等待一个虚构的“考据完成”。
