## 接入坐标，勿再镜像

本补丁在**已整卷镜像的运行坐标**，不是「未镜像源段11左缘」；不能替换 seg-11 或再次整卷镜像。

1. 生成图裁窗：`x=0, y=151, width=2170, height=420`。
2. 映射到参考图：`x=420, y=750, width=720, height=140`。
3. 映射到完整运行长卷像素（1.4px/世界单位）：`x=5320, y=750, width=720, height=140`。
4. 世界范围：`x=3800..4314.285714, y=535.714286..635.714286`。它跨 street-3 和 street-4；最终导出仍沿用 1400×980 的运行瓦片规格。
5. 当前 HTML 用 SVG viewBox 直接显示这块裁窗，未烘焙/改写运行瓦片。不要把候选01/02完整重绘、源图黑边或浏览器截图当成生产补丁。
