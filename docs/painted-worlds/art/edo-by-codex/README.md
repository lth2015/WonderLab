## 续画可照做的清单

1. **先用江户原图加文字描述笔法。** 江户参考负责町屋、瓦顶、格子窗、暖帘、器物；细线、薄彩、材质与空气感用文字写明。实际试画发现，把中国母图即使标为“只参考笔法”，仍会带入中国屋顶、服饰乃至背景人物；这轮桥头初稿因此弃用。不能只看提示词宣称文化已隔离，必须看实际结果。中国图适合人工并排看笔法，不应默认作为江户生成输入。
2. **先定三层空间。** 近处水岸/石路，中处可走路面与店铺，远处低对比小屋顶/树。远景逐层减细节、减反差，不能靠整图蒙一层黄雾。
3. **每个可见段有方向变化。** 河岸弯折、桥头连接、巷道斜入或店铺退让至少取一种。不要每段都正对一排同高度屋檐。
4. **建筑之间有生活连接。** 柳荫、侧巷、桶、竹篓、晒布等少量穿插，位置有用途，主要走道保持畅通。
5. **留白有具体载体。** 淡水面、浅石路或纸色天空承担呼吸；留白边缘有细波、石缝或渐远屋顶，避免大片等色平涂。
6. **线条有轻重。** 檐下、梁柱连接、器物交叠处稍重；瓦、布、树叶轮廓稍轻。不能所有边都用同样粗黑线。
7. **材质要能辨认。** 木纹顺构件、瓦片逐层搭接、竹器有编织方向、布有垂坠和褶皱、石头有砌缝和水线。纸纹不能替代物体细节。
8. **色彩分区。** 暖木/浅纸底，灰绿树、蓝灰水/瓦，少量柿色与藍色布。先维持干净淡彩，再加局部旧痕；不要统一褐黄色滤镜。
9. **锁定尺度后续画。** 人物基准 90@700；同距离门约为成人的 1.4–1.6 倍。以实际已有门高为后续标尺，不能每次再取整个画布的一部分导致越画越小。
10. **先画空底景，再标人物脚点。** 桥面、岸路、门前台阶必须连通；记录实际画面上的落脚线与遮挡线，再放人物。桥栏/树枝前景另按深度遮挡，不能把人贴在水上。
11. **整卷按 14×1000×700、至少20:1 验收。** 先定关键画，再依左右相邻画续场景。不可用一张图拉伸/循环复制来凑长度。接缝同时比道路高度、河岸、纸色、建筑大小，预留邻接重叠区。
12. **运行前看真实尺寸。** 原生图按需编码 WebP，记录尺寸/字节，不二次放大冒充分辨率。桌面、390px 手机、深浅时间状态分别看；文字留给运行 UI。无人物背景和独立远景层的生产约束继续执行。

## 验收方式

先把新旧样稿按相同门高并排看，再看 100% 原生细节；最后在 700 高场景里用 90 高人物校核桥面、台阶和门口。纹理清楚但人物无落脚面，或纸色一致但桥/路接不上，都不能通过。

日本桥北诘关键画负责构图、路线和气氛基准；旧店铺材质对照稿只作局部画法辅助。
