新段完整画布1128×700，左右各64余量；第N段的可见范围为 `[(N-1)*1000,N*1000]`，完整图放在 `x=(N-1)*1000-64`。请求原生2256×1400，实际输出逐张登记，不二次放大冒充2×。若工具返回的宽高比略有偏差，保持等比、按manifest给出的裁切窗口使用，不拉伸。
