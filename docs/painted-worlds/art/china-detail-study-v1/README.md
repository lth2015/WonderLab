## 实际图像判断

新画的木纹、砖缝、布褶和人物更清楚，单独近看有效；但模型没有严格遵守指定窗口：画入了更完整的上部拱形，人物、驼队与门洞相对位置改变。它是参考重绘，不是与现有道路、人物脚点、建筑轮廓配准的增强图。裁边不能修复内部构图漂移。

因此本轮不接入生产，不改任何人物脚点。新图也不能证明全卷已经具备原生2倍细节。后续若试 v2，应直接提供精确局部参考并锁定轮廓，先验脚点、门洞和接缝再决定是否扩大。
