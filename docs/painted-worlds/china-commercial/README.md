## 方向判断

当前最值得验证的是「完成一个小故事后，是否愿意带走画册，并继续看另一段生活」，而非购买按钮的点击数。继续沿用 Wonderful World / 汴河拾光品牌，保留免费三条原故事、货港第四条与城门第五条；不把已有结尾或清晰导出改为付费。

买断续篇是首选假设。《汴河夜归》能提供与白日不同的氛围和共同照应的主题，但仅换夜色不够构成商品。本轮用《桥边留一盏》验证“给晚归的人留光”的互动，未来区域、人物与美术必须有实质差异。所有者新增的买断赠友纪念品方向已做三款内部样品，详见 [keepsakes.md](keepsakes.md)；正式商品须有额外内容，免费画册继续免费。文化街区定制以真实客户/范围另行评估。

没有需求或付款证据。本轮代码与自动化不代表15–20位真人观察，更不代表20位陌生购买用户。未定经营地区/币种，不把中文当大陆发行，也不套用江户试价。继续投入前先看观察结果，不先批量制作新卷。

## 启动与演示

从仓库根目录运行：
```sh
npm ci
npm run dev:qingming
npm run test:qingming
npm run build:qingming
npm run typecheck
npm run build
npm run edo:test
```

开发服务5175端口。纪念品演示使用 `?study=souvenirs`，行囊→打开数字纪念小铺；自用/赠友各有独立PNG，可发送给朋友，全部标为未发售样品，不发放正式权益。生产包剔除研究组件与商品标题。

普通体验不显示商业研究卡；开发时使用查询参数 `?study=night-return`，在「画册」或「今日小记」中找到内部试样。卡片明确开发中、价格待定、尚未发售，点“我想继续逛”只记本次兴趣，不下单、不给权益、不通知、不留邮箱。生产构建即使带此参数也不显示卡片。

真实流程：入画→附近/文字探索找小柳→压纸→选构图/题签→落笔→查看画页→保存/分享/复制→回画册试走《桥边留一盏》。小样选择将两盏灯分到石阶/弯道，等船稳再收灯；错选可改，允许回放。小样只存在组件内存，关闭页面后重来，不写免费存档/画册/文钱。

配置 `VITE_QINGMING_PUBLIC_URL` 为此作品正式HTTPS入口（如目标 song.want.world），可在构建时注入；未配用当前作品目录。无DNS操作。分享链接仅 world=qingming-china、白名单scene、source=journal；不转发原查询/fragment、邀请、邮箱、钱包或存档。目标子域名是计划，不代表已解析。子路径迁移到子域名需应用内JSON导出/导入，跨origin存档不能自动继承。

可设非秘密 `VITE_QINGMING_BUILD_ID` 给事件标记构建；默认development-unversioned不可用于混合发布版本的比较。

## 权益与未来支付接入

contentAccess 免费包直接返回free，根本不查询权益服务；服务失败/异常/未知包返回unavailable，不能误授予或阻断免费篇。测试替身仅在 commercial.test.ts 中；生产没有“已购买模拟”开关。样例是开发预览，不冒称已拥有。

canCheckout只描述未来目录条件：显式releaseEnabled、on_sale/public、有效正价与税务口径；当前商品development/internal/price=null，实际没有下单入口或支付适配器。未来必须由可信服务端重新校验商品/价格，创建托管结账，验签通知并幂等授予按world_id隔离的内容包权益。当前公开静态包中的预览素材没有复制保护，前端门禁不是付费资源保护。

待实际销售任务处理：经营地区/主体、币种/税费与试价、一次购买的内容承诺、身份及跨设备恢复、退款/撤权、重复购买、延迟支付、通知重试/乱序、资源交付保护程度、联系方式及素材授权。经营者信息留空，不编造；测试阶段不依赖生产配置。

## 研究资料

- keepsakes.md：一次买断、长期个人使用与赠友的设计样品、接口边界和后续验证。
- events.md：数据字典、去重与分母。
- night-return-brief.md：续篇假设、故事清单、资产缺口、停止条件。
- observation.csv：15–20位目标用户观察表模板，无虚构样本。
- costs.csv：投入/变动成本账表模板，无虚构金额。
- validation/：本轮浏览器脚本、真实导出PNG、截图、事件样例与验证结果。系统分享/剪贴板通过测试替身覆盖结果分支，不等于系统面板真机验收。

评估顺序：观察独立开始/第二处探索/人物记忆/主动导出，再对符合条件且看过同版本真实小样的人问兴趣原因；兴趣不是购买。若免费完成差先修体验；若完成好而无人继续先改主题；不以加内容或投广告统一解决。真实销售20单只是学习节点。
