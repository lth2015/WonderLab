# 汴河拾光 · 开发与验收记录

日期：2026-10-31。首个可运行体验切片，使用用户提供的产品策划作为设计参考。

## 目录与影响范围

- `apps/qingming-china/`：React 18 + TypeScript + Vite 独立应用。源代码、内容、原创矢量插画、声音、状态与测试在此。
- `packages/scroll-contracts/index.ts`：schemaVersion 1 类型与存档信封校验提案；不包含任一文化的任务或货币规则。
- `docs/painted-worlds/`：开发说明与素材台账。
- 保留原有 `src/` 体验；没有搬迁旧项目、接入 AI、账户、现实支付或埋点服务。

本地曾发现同目录下另有一个独立 Git 检出的 `WonderLab/`，其主分支代码比外层检出新。最初在用户指定外层工作目录完成独立子应用，发布集成以最新远端主分支为准，不把整个嵌套副本加入提交。

## 已实现

1. 三段连续街景：桥西茶坊、虹桥渡口、河东纸铺。散点组织的 SVG 远景、建筑、河流、桥、船、人物、近景柳树，均为代码绘制。支持双向拖动与 8 CSS 像素点击取消阈值；小游戏期间由原生模态对话框锁定街景。
2. 六位人物；纸角压平、船靠稳、货担转移、阿成移动到茶摊、客人入座、人物姿态等状态变化。
3. 一纸春风、这一船日常、谁的香囊三个故事；选项脚本、温和错误反馈、一次性奖励与回放；游戏数值初始 60 文、奖励 12/24/18 文，茶 6 文、纸签 12 文。
4. 理绳三组形状配对，点按与拖拽两种输入，失误后可选引导；货签辨认；两位客人的茶点组合选择。
5. 十二页可实际解锁的画册。写生构图/题签选择，师父回应所选页，按实际事件生成小结，1440×1800 PNG 导出。
6. localStorage 自动保存；JSON 导出、校验与导入；损坏存档保留并支持下载备份；拒绝跨世界存档。
7. 默认静音、用户开启的原创合成水声与轻铃，后台暂停；大字、减少动态、可关闭闲时提示；原生 dialog 焦点约束、Escape 关闭、返回原触发控件；所有环境与人物有文字按钮路径。
