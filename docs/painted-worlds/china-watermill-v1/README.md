# 水磨：透视转轮与落水动态

状态：Codex 代码、素材与本地验证已完成，待 Claude 代开 PR、合入最新 main、部署并复验。基线 `main@5ca7907`，目标分支 `codex/china-watermill`。本项是所有者指定的今日最后一项，J02/图集瘦身/赠友画纸留到后续工作。

## 可见行为

水磨在“汴河上游 · 水磨 · 竹林”。入画后可从“附近 → 以文字探索街巷 → 看看水磨”到达。

- 木轮约28秒一周，顺时针，右侧叶片顺落水向下。原画位于轮后的木墙、石基和水面有局部补画；轮前轴承、立柱、横梁和进水槽保持静止。
- 输入是透视椭圆源片，逐层执行 `translate → scale(.85,1) → rotate → scale(1/.85,1)`；定位不与动画共用 transform，轮心不随旋转漂移。
- 落水沿原轮廓保留原画水纹，再叠向下移动的半透明 SVG pattern，落点有很轻的水花与池面涟漪。
- 只接近水磨时挂载并请求新图层；进入可见范围后播放，离开可见范围立即暂停，远离后卸载。减少动态（应用设置/系统偏好）或后台可见性信号会停止动画，静止画面仍完整。
- 新图层解码前或加载失败时不显示替换层，原静态瓦片继续可见，不留下空洞。不改热点、剧情、奖励、画册或 saveVersion 4。

| 图层 | 来源 | 大小 |
