## 状态与边界

- `saveVersion` 4 → 5，仅补 `trace`、`breeze` 两段未开始的故事；0–3 仍逐级迁移。不改已有画页、钱包、回放、购入物或设置。
- 描线每完成一笔保存一次；不完整的一笔留在面板内存，抬手、取消或离开后重来。顺序通过后才能收页，重复按同一笔不推进下一笔。
- 晾画保留已搭好的上沿、已夹好的纸角。八秒风周期中有三秒风轻；没赶上只显示小柳替你扶住的反馈，没有扣钱、次数上限或画纸损失。减少动态下直接用竹夹。
- 新故事不增减文钱，重逢不重复领取画页或奖励。存档校验要求画页与领取账本一致，拒绝超界步骤和未完成纸铺却已有新玩法进度的存档。
- 描线是固定引导写生：保存的是完成的固定笔段，不保存个人手绘轨迹，不宣称复制了玩家的笔迹。新画页均使用本作自己的简笔图，不借江户角色、对白或图片。
- 试玩 `play_detail` 与江户共用固定 `what/outcome` 结构：`trace × traced/tapped/left`，`ugoki × caught/miss/tapped/left`。仅操作节点提交，不记录坐标、原始笔画、寄语或存档；通常只在内存，显式试玩会保存在本机，不自动上传。故事首通与重逢由实际状态转换记录。
- 新画页可翻看、给师父看、写入今日小结、保存留念图或寄给朋友。赠友图保持题签、固定短句、印与落款，不含任务数、钱包或进度。
