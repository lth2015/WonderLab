# 纸铺入口：让被风掀起的纸可辨认

状态：Codex 实现和本地验证完成，待 Claude 代开 PR、部署、线上复验。基于 `main@6425bce`，包含已发布的 #157 定位修复。

所有者指出：清太身旁三道白色弯钩看不懂像什么。Claude 在 collab 的 `2026-11-01-2350-claude-codex-请重画纸铺被风掀起的纸片.md` 指派重画。

## 改动

- `LooseSheets` 中原三条白钩改为两张米黄色纸片，有完整纸面、淡墨纸边、阴影和卷起的一角；静止也能看出纸张。
- 纸形为此组件原创 SVG 路径，没有新增位图或网络资源。与原画保持米黄/浅褐色调，未加入箭头、文字或常驻 UI 标识。
- 保留外层 `<g>` 的定位；内层 `.flap` 只做 `scaleY(0.92)` 轻颤，不产生横向位移。取消原 `skewX`，避免新纸边横向扭摆；原动画周期保持不变。
- 仍仅在 `poses.seita === 'press'` 时出现。文镇压好纸后，纸片与阴影一起消失。原游戏状态、热点、奖励、存档和声音不变。
- 减少动态时纸片完整静止，翻角不依赖动画来表达。
