# C1 中国整卷导出

入口：画册 →「把长卷带走」。不需要先解锁画页。按当前故事进度组合人物、船只和道具，采用原画日景，动态固定为静帧；说明可在弹窗展开。

| 选项 | 尺寸 | 实测文件大小 |
| --- | --- | --- |
| 手机一张 | 14280×700 | 约 3.4 MiB JPEG |
| 原素材分四张 | 5325×1024、5120×1024、5120×1024、5325×1024 | 每张约 1.3–1.8 MiB JPEG |

卷首在右、卷尾在左；第 1 张保存右端，第 4 张保存左端，各段内部不翻转。卷首题签「汴河拾光」，卷尾小落款；没有游戏统计、按钮、提示或存档数据。四张按 1024 像素原瓦片精度输出，不靠放大插值增加细节；JPEG 压缩不是无损保存。

## 构图与资源

- 从资源清单独立渲染全部 20 段，逐段生成 SVG，再内嵌素材合成 JPEG。没有截取屏幕、克隆实时 DOM 或序列化实时 Canvas。
- `PaintedLandscape` 的静态瓦片选项复用当前人物/船/道具定位与故事姿态，仅渲染与瓦片相交的叠层。水车从同一背板、轮面、桶图集第 0 帧与水纹素材构成纯 SVG；遮挡支架路径由实时与静态组件共用。
- 渲染器只在点击制作时加载；每次制作独立缓存素材，同一 URL 只读取一次。每张画布在成功、失败、取消时均清空尺寸；临时 SVG URL 释放。分张结果全部完成后才提供保存按钮，每张由用户单独保存。
- 制作开始时冻结输入进度，只读不写。支持逐段进度、立即取消、关闭中止、失败重试，以及整张失败后改为四张；旧任务不会把结果写进重新打开的弹窗。

## 验证

- 中国 77 项测试通过；新增覆盖全部瓦片与右起分组、画布面积/边长预算、静态水车无 Canvas、故事姿态与进度不变。
- 合入 `origin/main@f0173f3` 后，完整 build、独立域名构建、77 项中国测试与 488 项根测试通过；4 项原有数据集测试跳过。
- 浏览器走通两种模式的真实下载，文件名与实际 JPEG 尺寸一致，四个分张均已查看。20 段输出的像素抽查对应源瓦片，卷首/卷尾纸边存在；画布和 SVG URL 在完成后释放。
- 实际阻断素材请求后取消/关闭、503 后重试、2D context 分配失败后改四张、toBlob 返回 null 后重试均恢复，未出现页面脚本错误。导出前后存档原文一致。
- 360×740、390×844、1280×800，大字阅读：两种大小选项与四个保存按钮都在底部操作区上方；返回/取消不被内容遮挡；Escape 可退出。
- 无头 Chromium 390 像素宽：整张约 2.06 秒、四张约 1.90 秒。不是手机实测；Safari/iOS、真机内存上限和系统下载行为仍待验。
- 独立域名根路径与 `/qingming/` 的生产包均走通两种模式、真实下载和存档不变，无脚本或 HTTP 错误。渲染器没有在首屏/打开弹窗时下载，只在点击制作时请求，见 [production-result.json](production-result.json)。
