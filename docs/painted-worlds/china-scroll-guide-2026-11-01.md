# 中国长卷导览 · 2026-11-01

基于 PR131 `c875f17`，仅补入口。现有六个章节按钮在手机端隐藏，24000 单位长卷只能反复拖动，或在完整文字对象清单中查找远处对象；卷首、卷尾没有直接定位入口。

「附近」面板在三条故事后、完整文字清单前增加可折叠的「长卷导览」。按读卷顺序列出卷首野渡、乡野、货港、纸铺、茶坊、虹桥、城门、卷尾静巷八站。六处主景复用既有 CHAPTERS，不复制坐标；两端交给现有镜头边界夹取。按钮仅移动镜头，不增加游戏动作、奖励、画页或存档字段。

选择后收起面板，焦点回到可操作画卷，可立即按左右键继续走。桌面的原章节按钮保留。「关于」中“三段街景”的说明同步改为城内静巷至郊外野渡的长卷，故事和人物数量不变。
