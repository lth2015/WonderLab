# 水磨真实感精修 v2

状态：代码、素材与本地验证完成，待 Claude 代开 PR/部署复验。基于 `main@9637c35`（已上线 #161），分支 `codex/china-watermill-realism`。所有者看过上线图后要求更真实，本轮只精修水磨。

## 画面变化

- 原来伸出轮缘的辐条和大轮毂有车轮贴片感；新轮圈收回辐条，采用更小的轴心，木纹清晰度和色调与长卷原画衔接。
- 前后两个轮面之间有真实投影深度（原瓦片坐标19px横向、−5px纵向），20个木斗随转角改变露出的侧面、阴影与带水痕迹。前后轮圈与木斗共享28秒一圈的时钟。
- 支架、轴承和进水槽保留原画固定像素，不随轮转；收窄了旧轴心裁片，避免旧模糊轮毂大块盖住新轮盘。右侧湿木有固定受水暗色，底缘在水面处柔和浸入。
- 规则的白色水帘改为几股不均匀、带透明空隙的细碎水纹；沿固定落水曲线向下移动。木斗带水、落点小水花和错开的池面涟漪相衔接。

`evidence/before-v1-390.png` / `before-v1-1280.png` 是已交付v1画面；`after-*` 是本轮；`closeup-dpr3.png` 为浏览器原始近景截屏，没有后期重绘。

## 渲染与约束

`Waterwheel.tsx` 使用绘制好的前后轮面和投影木斗帧。木斗是20重对称结构，18°即1.4秒循环，用42帧覆盖；小画布只拷贝所需180×284像素，不逐帧重建多边形或大幅移动整张图集。侧层最多30次/秒更新，轮面与水纹保持连续CSS动画；不逐帧写React状态。

图集1260×1704，约2.15百万像素，解码RGBA约8.2MiB。取舍是增加一张局部图集，以保持复杂木斗的手机绘制开销可控。原始投影与生成脚本、`bucket-geometry.json` 可复建和核对。

- 只接近水磨才加载新素材，可见才运行；离开暂停、远离卸载。
- 应用减少动态、实时系统偏好和后台可见性信号停住轮面、木斗与水流，静态结构仍完整。
- 新图层全部加载和解码完成后才覆盖旧画面；图片或画布不可用时保留原静态瓦片。
- 不改故事、热区、奖励、保存、画页或任何江户代码。当前画页PNG使用独立SVG，未引入画布导出回归。未来整卷导出需直接合成资源和选定木斗帧，不能只序列化这个canvas/foreignObject。
- 四项运行资源的总字节数、尺寸、哈希见 `materials.json`；木纹小样仅供生成图集，运行时不请求。首屏新水磨请求仍为0。

## 验证证据

- 中国65测试、类型/独立中国构建、三作联合构建通过，diff检查通过。
- `result.json`：390/1280px，轮心不漂；前后轮盘/木斗时钟对应，多个相位的真实画布内容不同；1400ms循环首尾一致；离屏和减少动态时画布帧不变；刷新与60文保持，无普通存档污染或页面异常。
- `geometry-check.json`：42帧的469个可见木斗四边形均符合固定椭圆投影和(19,−5)前后深度。运行相位见 `phases-*`。
- `production.json`：独立根路径和联合 `/qingming/` 均加载/转动/停止正常；主动拒绝小画布上下文时完整回退到原画，无半截机器。
- `performance.json`：最终本地生产拖动检查，390px CPU4×降速与1280px均记录中位约16.7ms；准确p95/最大值以JSON为准。该记录是云端无头Chromium，不能当真实手机或线上帧率承诺。
