# 「万象」印章设计需求（给团队设计师）

> 2026-10-26 · 决定见 [02 §12](02-product-design.md)「印章本身该长什么样」。

## 为什么要重做

现在的印章是代码里临时画的：一个圆角的朱砂方块，用设备上碰巧有的楷体排出「万」「象」两字。没有楷体的设备会退回无衬线字；整体像 App 的图标徽章，不像一枚盖上去的印。它会出现在 15 秒录制、壁纸、实物卡片上，以后可能还有 App 图标和网站，是这个产品最核心的品牌标记。

## 要什么

| 项 | 要求 |
|---|---|
| 文字 | 「万象」两字（可用繁体「萬象」，由设计师判断哪个在篆书里更好看） |
| 字体 | **篆书**，人工书写或刻制，不直接套用现成字体文件 |
| 样式 | **白文**（阴刻）：朱底，字是留白 |
| 形状 | 方印，接近正方形；四角不要圆角，可以有刻印本身的轻微不规整 |
| 质感 | 保留「盖上去」的不完美：边缘轻微残缺、印泥有深浅。**只设计这一枚**，不做每次随机变化 |
| 颜色 | 朱砂 `#C8553D`（与 03 的 `--cinnabar` 一致）。留白处透出底色，不填浅色 |
| 尺寸 | 要在两种极端下都好看：手机录制里约 40–60 像素宽，以及实物卡片上印出约 12–15 毫米宽 |

## 交付

- **矢量文件 `seal.svg`**：只用路径（`<path>`），不含文字、不嵌字体、不嵌位图；单色朱砂，留白部分是真正的透明（镂空），这样放在任何底色上都对。
- 一张放在夜景深色底上的预览，一张放在白纸上的预览。
- 设计过程留存（草稿、扫描件或刻印照片、源文件）：02 §14.4 写明，品牌素材必须有明确的人类创作并保留过程记录。**不使用图像模型生成。**

## 权属

印章是品牌素材，归产品所有者个人所有（02 §14.4），不进开源的免费素材。设计师是团队成员，按团队的雇佣或委托约定处理；如有外部协助，著作权归属要在合同里写清楚。

## 交付之后（工程）

代码里把临时画的印章换成这份矢量图形：录制和壁纸共用同一处绘制（`src/record/recorder.ts` 的 `drawSeal`），实物卡片的印制文件也用它。和其他冻结后的改动一起合并，不进 R1。
