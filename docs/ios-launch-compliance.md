# 上架前合规清单（iOS 日本区首发 · 实物销售）

> 2026-10-26 草稿。**这不是法律意见**：这里列出要求、我们的现状和要谁确认，结论由常合作的行政书士（必要时律师）确认。标「需确认」的事项，提交审核或开始销售前必须有专业意见。决定见 02 §12「公开上线时的合规要求」。

## 一、App Store 上架

| 要求 | 我们的现状 | 负责 / 需确认 |
|---|---|---|
| 隐私政策网址（不收集数据也必须提供） | 草稿见 [privacy-policy-draft.md](privacy-policy-draft.md)；日文版由日语母语同事写，行政书士审阅 | 需确认 |
| App 隐私标签（App Privacy） | 预期申报「不收集数据」：世界、测试记录都只在本机；无账户；无第三方统计、崩溃上报或广告 SDK。**前提是 iOS 构建确实不含任何这类 SDK**，提交前逐项核对 | 工程核对 |
| 年龄分级问卷 | 4+，不进「儿童」分类（02 §12「适合全家」）；外部链接和购买前加家长确认 | 产品 |
| 用户生成内容（App Review Guidelines 1.2：举报、屏蔽、过滤） | **需确认。** 送一条鱼会把用户画的笔画和一个字的落款发给对方，审核可能视为用户生成内容。缓解条件：落款只能是一个字母、数字或汉字；只在朋友之间点对点发送，没有公开的信息流、评论或账号；收到的人轻触水面才收下，也可以随时放生。提交时在审核备注里说明；如审核要求，再考虑加「不再接收这个人的鱼」之类的屏蔽 | 需确认 |
| 首版不含账户、支付、加密货币相关代码 | 已决定（决策 5、§14.5）；iOS 构建已剔除，提交前复核 | 工程核对 |
| 不使用远程 AI（首版只用本地规则） | 已决定（决策 5）；R1 也已在打包时固定为本地规则 | — |
| 开发者信息展示（个人账号显示法定姓名） | 所有者已接受（02 §13）。仅日本区，不涉及欧盟 DSA 的 trader 信息 | — |

## 二、素材与字体的权利

| 素材 | 现状 | 需确认 |
|---|---|---|
| 霞鹜文楷（LXGW WenKai）字形子集，`src/assets/fonts/wenkai-subset.woff2` | SIL Open Font License 1.1。OFL 允许打包进软件分发、商业使用，不允许单独出售字体；子集属于「修改版本」 | 是否声明了保留字体名、子集文件的命名和附带许可文本是否符合要求；App 内的「关于」或致谢页写明字体与许可 |
| 锦鲤、月亮贴图（`public/art`） | 由图像模型生成（`scripts/gen-art.mjs`：TokenStars 或 ChatGPT），已以 Apache-2.0 公开（§14.4） | ① 生成服务的条款是否允许商业使用（App 内展示、**印在出售的实物上**）；② 这类素材在日本的著作权保护可能较弱（§14.4），他人复制时难以主张权利。实物和以后付费的「地方」所用的商业素材，应由人创作并保留过程记录 |
| 「万象」印章 | 由团队设计师重新设计（[seal-brief.md](seal-brief.md)），归所有者个人 | 设计师与所有者之间的权利约定（雇佣或委托） |
| 回应的诗句（echo） | 中文古诗，均已进入公有领域 | 确认所用版本没有现代注释、译文等仍受保护的部分 |
| 声音 | 全部程序化合成，没有音频文件 | — |

## 三、实物销售（「一条鱼的来信」「我的湖」，人工收单）

| 要求 | 我们的现状 | 需确认 |
|---|---|---|
| 《特定商取引法》的标示（卖家姓名、地址、联系方式、价格、运费、付款与交付时间、退货与取消条件等） | 还没有。**以谁的名义卖，等实物进入真实购买之前，与行政书士一起定**（个人名义：要标示姓名和地址，个人可选择收到请求后再告知；公司名义：涉及与所有者之间的品牌与素材授权，§14.4） | 需确认 |
| 《个人信息保护法》：订单含姓名、地址，以及要印的作品图像 | 原则已定（print-readiness §2.5）：下单前告知给谁（我们和印刷商）、做什么（只为这一单印刷和交付）、何时删除；只交印刷用图像，不交世界存档和笔迹 | 告知文字和删除期限；与印刷商之间的处理约定 |
| 用户作品的授权 | 已定（§14.4）：用户买实物时，只授权这一单的印刷与交付 | 订单页上的授权说明文字 |
| 付款方式 | 人工收单阶段未定（不开发支付系统） | 选定后再看相应要求 |

## 四、以后的数字内容（新的「地方」，§14.6）

App 内购买走苹果的规则（退款、恢复购买由苹果处理）。平台和版本还没定，届时再补本节；《特定商取引法》在 App 内购买场景下怎么标示，到时一并请行政书士确认。
