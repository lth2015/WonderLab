# 阶段 D 测量有效性审查

基线：main `9966852`（PR #7）。本补丁保留 H1 ≥80%、H2 ≥60%（自由段 ≥3 次无提示创造）、H3 ≥30%。没有真实访谈或测试结果。

## 发现与最小修正

| 风险 | 修正 |
|---|---|
| 「你想怎么处理」后的回答被当作主动意愿 | H3 在任何访谈或导出指令之前冻结；访谈回答另记、仅作定性 |
| `askedToSend=true` 无法区分主动与被问 | 保留字段读取兼容性，但不再用它评分；新增 `h3Observation` |
| `save` / 录制完成只能证明操作，不能证明主动性 | 继续统计漏斗；H3 仅使用有证据的观察判定，不能从日志自动推测 |
| 缺少观察被算否，或从分母剔除而提高比例 | 缺失、非法状态、空证据一律未知；保留总人数，沿用上下界判定 |
| 引导段提前结束、自由段时长或文本不一致 | 开测前锁定下表；偏离逐人记录，不能测完再为通过率修改流程 |

`h3Observation` 是观察员的明确证据判定，不是程序对自然语言的分类。`spontaneous` 表示至少一次合格主动行为；即使后续有被提示行为，先前证据仍有效。`prompted_only` / `not_observed` 须有 `windowComplete: true`，表示完整窗口已核对，且没有合格主动行为；未明确确认完整则代码记未知。若自由段期间是否受到外部提示、或行为先后无法确认，使用 `unknown`。不为补全记录而在访谈后诱导重演。

## 旧数据兼容与迁移

日志结构、文件名键、`helpBeforeFirstStroke` 和旧 `askedToSend` 都不变；旧文件可直接运行分析，无需批量改写。新字段缺失时 H3 为未知，即使旧布尔值为 true/false 或日志有成功保存。报告会列出未知记录及原因警告。

仅当已有的同期记录能确认动作/原话、阶段时间和主持人是否事先提示时，人工补录 `h3Observation`；保留旧字段和原始文件，迁移另存副本并记录依据。无法确认保持未知，禁止从「保存过」「说过愿意分享」倒推主动性。示例见 `notes.example.json`（全部为虚构记录）。访谈后的意愿不回填冻结的 H3，可留在观察表访谈栏。

## 其他判读边界

- H1 沿用「可交互后5秒内首笔且无求助」；主持人不能示范。首屏提示不算教程；自动演示算教程，已移到可交互 6 秒后（5 秒窗口之外），看过演示后的首笔不计成功（02 §1 H1 口径，2026-10-25）。当前无首笔日志按既有代码判否，设备/日志故障须在批次异常记录中单独说明，不能解释成用户失败。
- H2 沿用产品定义和现有10秒产品提示标记，不更改为「四次」；主持人全程离场，不给额外创作提示。忘记切自由段为未知。自由段计时由最后日志事件估计，不等同真实主动停手时长；实际结束时间仍以观察表记录为准。
- 5–10人的结论是本批方向性验证，不代表总体用户比例。所有未知仍保留在分母，报告应同时列出成功/未知/总人数。
