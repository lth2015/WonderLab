## 判定规则（写报告前不改）

- **阈值**（02 §1，事先约定）：H1 ≥ 80% 的测试者 5 秒内无求助落下第一笔；H2 ≥ 60% 的测试者在自由段有 ≥ 3 次无提示创造；H3 ≥ 30% 的测试者主动保存或询问如何发送。
- **无提示创造**：自由段内、且不在任何情境提示出现后 10 秒内的创造（画出鱼、月、星、流星、云、行星，或提交一句话）。
- **判定**（`src/lib/sessions.ts`，`npm run analyze` 直接给出）：缺观察记录或没有自由段的测试者记为「未知」。即使所有未知都不达标也达到阈值，判**成立**；即使所有未知都达标也达不到阈值，判**不成立**；否则判**不确定**。
- **解读时注意**：人数少时一个人就能改变结论。比例离阈值只差一个人以内的，报告里应该写明「勉强成立」或「勉强不成立」；测试者不到 5 人时，无论判定如何，都只作参考。
- 5–10 人的结论只作方向判断，不是统计结论（04 §三）。结论为「不确定」时，优先扩大样本，而不是扩大功能。
