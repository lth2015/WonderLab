## H3 观察（导出日志指令和所有访谈问题之前冻结）

| 项 | 记录 |
|---|---|
| 观察截止时间 / 窗口是否完整 | __:__　☐ 完整 → `windowComplete: true`　☐ 有缺口 → `windowComplete: false`（原因：____） |
| 主动性判定 → `h3Observation.status` | ☐ spontaneous 主动　☐ prompted_only 仅被提示　☐ not_observed 未发生　☐ unknown 未知 |
| 证据 → `h3Observation.evidence` | 原话/动作：____；阶段/时间：____；此前主持人提问/提示及其原话（无也写明）：____ |
| 日志核对 | 保存事件____次；是否能确认提示来源：____；观察缺口：____ |

`spontaneous` 为成功；`prompted_only` / `not_observed` 仅在窗口完整、有证据时为否；有缺口或先后不清填 `unknown`。保存日志不自动证明主动性。导出后只允许按截止前的日志核对；访谈回答不得补成主动证据。
