## 首位接入

1. 主持人核对以上缺项和设备，向参与者说明同意书，确认年满18岁、自愿参加；只使用P01编号，签名材料不放入公开仓库。
2. 在未向参与者演示玩法前打开全新世界；保持主持面板关闭。只说「这是一个网页，你可以随便玩」。
3. 按固定时长执行引导段和自由段；记录首笔前求助情况。不向参与者公开假设或测试阈值。
4. 收尾时先记录自然请求和截止时间，再导出日志。保存有疑点就用unknown；明确否定必须填windowComplete=true并有覆盖证据。
5. 再按手册访谈；回答单列为访谈资料。保存日志与notes到私有测试数据目录，运行分析。首位完成只汇报单例，不能宣称验证已通过。

远程时由人类主持人建立通话、实时观察并记录；本聊天可协助核对记录和分析导出数据，不会自动看到参与者操作。若由产品开发者本人演练，归入内部演练，不能代替首次接触产品的真实用户样本。
