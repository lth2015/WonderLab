# 送鱼实验说明（`poc-gift-r1`，验证路线图 §4.3）

送鱼人是**已经完成自己实验**（主持测试或日记式测试，含最终访谈）的 B、C 组参与者；收鱼人（D 组）是**从没见过这个产品**的朋友。

## 给送鱼人（研究人员当面交代）

1. 用测试说明里的地址（`gift` 站点）打开，画一条你想送的鱼。
2. 长按那条鱼，点「送给朋友」，可以填一个字的落款，也可以不填。
3. 把链接发给一位**从没见过这个产品**的朋友，用你们平常聊天的方式就好。
4. **只发链接，不讲怎么玩、不教怎么画。** 朋友问起时，可以说「你点开看看」。正常聊天不用避讳；如果你解释或指导了，请告诉研究人员，我们会单独标注。

## 发给收鱼人的测试说明（研究人员发出，送鱼人的链接之外单独发）

> 你好，感谢你帮忙。你的朋友会发给你一个链接，那是一个叫 Wonderful World 的小作品。你想打开就打开，想怎么玩就怎么玩，不想玩也完全没关系。
>
> 这台设备会记录你使用它的时间和次数（什么时候打开、停留多久、做了几次创造、收下了几条鱼）。**不记录你画的内容、写的字、你的名字和任何链接，也不会自动发给任何人。**
>
> 三天后，如果你愿意，请打开下面这个地址，看一看记录了什么，再决定要不要导出发给我们：
> `https://gift.want.world/?study`（编号：Dxx）
>
> 你也可以在那里删除全部记录。不导出、不参加，都没有关系。

## 三天后

1. 收鱼人自己打开 `/?study`，填写编号，选择导出；文件按约定方式发给研究人员。
2. 简短访谈（可选，5 分钟）：
   - 打开链接时看到了什么？你觉得那是什么？
   - 你收下那条鱼了吗？是怎么收下的？
   - 你知道它是朋友亲手画的吗？
   - 你自己画过鱼吗？送给过别人吗？
   - 送鱼的朋友有没有跟你解释过怎么玩？
3. 分析：`npm run analyze -- 导出的文件.json`，看「收到一条鱼之后」一节；漏斗各环节见验证路线图 §4.3。
