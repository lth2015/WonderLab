## 准备

- **设备：** iPhone（Safari），最好再加一台 Android（Chrome）。
- **静音键拨到响铃，音量中等**（不然 C、H 两节没法看）。
- **三个地址**，在公司电脑上的仓库目录里运行（手机和电脑连同一个 Wi‑Fi，`<IP>` 换成电脑的局域网地址，如 `10.5.1.154`）：

| 用途 | 命令 | 手机打开 |
|---|---|---|
| 开发版（A–H 节） | `npm run dev -- --host` | `http://<IP>:5173/?fresh` |
| R1 构建（I 节：只有实验构建才有「测试记录」菜单） | `npm run build:r1 && npx vite preview --host --port 4175` | `http://<IP>:4175/` |

## 清单

| 节 | 怎么做 | 通过的标准 | 结果 |
|---|---|---|---|
| **A 首屏** | 开发版 `?fresh` 打开，什么也不碰 | 约 0.6 秒出现「轻轻画一笔，看看会发生什么」；**约 6 秒**（不是 4 秒）才出现自动演示的那一笔 | |
| **B 画鱼** | 在湖面画 3 条鱼，快慢、曲直各不相同 | 每条都成鱼；第一条鱼胸鳍有一点朱砂（本命鱼）；长按一条鱼，当初那一笔在水面重画一遍 | |
| **C 流星鱼** | 在天上从高处往下快速画一道，落到地平线附近 | 落进湖里溅起水花，游出一条**小的黄金锦鲤**（有鳍有鳞，不是淡色弯月）；身下水面微亮，不刺眼 | |
| **D 画月** | 在天上画一个圆 | 月亮从地平线升起 | |
| **E 写给鱼的话** | 依次输入「它想看看外面的世界」「大家在一起吧」「累了，睡吧」「跳起来玩吧」 | 分别是：鱼各自游远 / 聚成一圈或聚到第一条鱼身边 / 慢下来浮上水面（**看得出来**）/ 一两条跃出水面；文字不会变出新的鱼 | |
| **F 湖满了** | 继续画，直到第 9 条鱼 | 最老的一条（不是本命鱼）游向远处、淡去，节奏自然 | |
