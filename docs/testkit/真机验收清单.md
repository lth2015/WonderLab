# 真机验收清单（10/30 冻结前）

> 2026-10-26 整理。把散在路线图 §6、各 PR 和讨论里的真机检查集中到一处，按操作顺序排列，约 30–40 分钟。每项写「怎么做」和「看到什么算通过」。结果填在最后一列，有问题记下现象和截图，再开 PR 修。

## 准备

- **设备：** iPhone（Safari），最好再加一台 Android（Chrome）。
- **静音键拨到响铃，音量中等**（不然 C、H 两节没法看）。
- **三个地址**，在公司电脑上的仓库目录里运行（手机和电脑连同一个 Wi‑Fi，`<IP>` 换成电脑的局域网地址，如 `10.5.1.154`）：

| 用途 | 命令 | 手机打开 |
|---|---|---|
| 开发版（A–H 节） | `npm run dev -- --host` | `http://<IP>:5173/?fresh` |
| R1 构建（I、J 节：只有实验构建才有本机记录和「测试记录」菜单） | `npm run build:r1 && npx vite preview --host --port 4175` | `http://<IP>:4175/` |
| 送鱼构建（K 节） | `npm run build:gift && npx vite preview --host --port 4174 --outDir dist` | `http://<IP>:4174/` |

  两个构建都输出到 `dist/`，**一次只开一个**：做完 I、J 再构建送鱼版本。

- **局域网是 `http://`，不是 `https://`。** 浏览器在非 HTTPS 下不提供系统分享面板和剪贴板：J 节的「导出」会变成下载文件，K 节的「复制链接」可能失败。这两步如果在局域网上不行，**不算失败**，记下来，等 SRE 部署好 HTTPS 测试站点后再补测。

| 节 | 怎么做 | 通过的标准 | 结果 |
|---|---|---|---|

| **B 画鱼** | 在湖面画 3 条鱼，快慢、曲直各不相同 | 每条都成鱼；第一条鱼胸鳍有一点朱砂（本命鱼）；长按一条鱼，当初那一笔在水面重画一遍 | |

| **D 画月** | 在天上画一个圆 | 月亮从地平线升起 | |
