# 阶段 D 招募

> 对应 [02 产品设计](../02-product-design.md) §2（用户与场景）、§9（阶段 D）。测试流程见 [主持人手册](主持人手册.md)。

## 一、要招谁

| 条件 | 要求 | 原因 |
|---|---|---|
| 年龄 | 18 岁以上 | PoC 只对成年受邀者开放（02 §2，01 P9） |
| 人数 | 5–10 人，至少 5 人才有方向结论 | 02 §1 |
| 设备 | 约一半主要用手机、一半用电脑测试 | 02 §2 |
| 背景 | 混合：至少一半**不是**设计、开发或艺术从业者 | 避免“懂行”的人替我们找补 |
| 语言 | **能流畅阅读中文**（2026-10-26 决定，适用于主持测试、日记式测试和送鱼实验的收鱼人） | 界面、提示和「一句成境」只有中文；看不懂提示会让 H2 的「有提示 / 无提示」失去意义，写不了中文就测不到「一句成境」。日语用户的体验等日语版做出来再单独测 |
| 排除 | 参与过 Wonderful World 开发或看过演示的人；项目成员的直系亲属 | 已有预期，测不出“无需教程” |

画像以「路过的好奇者」为主，「爱分享的创作者」为辅（02 §2）。不需要会画画。

## 二、邀请消息（可直接发）

> 你好！我们在做一个小网页实验，想请你花 25 分钟试玩一下，聊聊感受。不用准备，不需要会画画，没有对错。
>
> 时间：____ 地点：____（或线上视频）
> 设备：用你平时的手机或电脑就行。
> 我们不会录像录音，也不收集你的个人信息，只记录页面上的点击类型。
>
> 方便的话回复下面几个问题，我们来安排时间 🙏

---

## 三、筛选问卷（6 题）

1. 你今年是否已满 18 岁？ 是 / 否 → 否则不邀请
2. 你平时上网主要用：手机 / 电脑 / 差不多 → 用于平衡设备
3. 你的工作或专业和设计、软件开发、美术有关吗？ 有 / 没有 → 控制在一半以内
4. 你之前见过或听说过「Wonderful World」（或开发代号 WonderLab、旧名万象生）吗？ 见过 / 没有 → 见过的不邀请
5. 你能流畅阅读中文吗？ 能 / 不太能 → 不太能的不邀请（这一轮只有中文界面）
6. 方便的时间段：____

不问姓名以外的个人信息；联系方式只用于约时间，测试结束后删除。测试者在所有记录里只用编号（P01、P02…）。
