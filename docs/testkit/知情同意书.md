# 测试参与知情同意书（模板）

> 模板。正式使用前请把「〔 〕」里的内容换成实际信息，并请负责人确认措辞。

感谢你参与「Wonderful World」的体验测试。开始之前，请读一下下面的内容。

**这是什么测试。** 我们在测试一个互动网页的早期版本，想了解第一次看到它的人会怎么玩。我们测试的是这个网页，不是你：没有对错，也没有「玩得好不好」。

**过程。** 预留约40分钟，可提前结束。先请你自由体验，中间有一段时间工作人员会离开，你可以一个人玩，想停就停；之后有一段简短的聊天。

**我们会记录什么。**

- 网页在这台设备上记下的操作事件：例如什么时候画了第一笔、生成了什么、点了哪里、有没有保存。**操作事件日志不记录你输入的文字内容，不上传你画的画。** 开启 AI 的「一句成境」会将输入文字发送至本测试服务端及其配置的 AI 服务提供方进行处理；请勿输入姓名、联系方式或其他敏感信息。
- 工作人员的手写观察和聊天记录。记录里只用编号，不写你的名字。
- 你保存的视频或图片只留在你自己选择保存的地方，我们不会收走。

**我们不会做的事。** 不录像、不录音（如需录音，会另外单独征求你的同意）；观察记录只用编号；AI 文本处理范围如上所述。远程参加时，前一段会通过视频通话实时看你操作，通话不录制；工作人员离开的那一段会关掉摄像头。

**你的权利。** 参与完全自愿。你可以随时停止，不需要说明理由；也可以在测试后〔 天〕内联系我们，要求删除和你编号对应的记录。
