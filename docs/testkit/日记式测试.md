# 日记式测试：一周回访（02 §5.6）

主持测试每人只测一次，回答不了「会不会自己回来」。这里补一个轻量的测试：3–5 人在**自己的手机**上用一周，看他们自然回来了几次、回来时看到了什么、说了什么。

## 原则

- **不催促、不提醒。** 一周里不发消息问「今天玩了吗」。提醒会污染「自然回来」这个信号。
- **不讲机制。** 不提鱼会长大、离开时会发生事情、长按能看见那一笔。
- 只说：「这是一个小东西，你想打开就打开，不想打开也没关系。一周后我们聊十分钟。」

## 准备

1. 招募 3–5 人：成年、没参加过主持测试、没看过演示（[招募.md](招募.md) 的排除条件同样适用）。
2. 在对方手机上打开测试网址（不要加 `?fresh`，世界要一直保留），可以「添加到主屏幕」。
3. 当场让对方画第一笔，然后就不再介入。
4. 记下开始日期和对方的匿名代号（P01…）。

## 一周后

1. 先访谈，再导出（访谈时手机还在对方手里）：
   - 这一周你打开过它吗？大概几次？什么时候想到打开的？
   - 打开的时候，有没有发现什么变化？（**先问开放的，不要提具体机制**）
   - 有没有哪条鱼你特别记得？为什么？
   - （最后再问）你知道长按鱼会怎样吗？
2. 用 `?mod` 打开同一个网址，左上角快速点 5 下，在「主持人」面板里点「**导出回访记录**」。
3. 记录文件只有：每次打开的时间、停留时长、这次做了几次创造。**没有画的内容、没有写的字。**

## 看什么

| 问题 | 来源 |
|---|---|
| 一周里自然回来了几次，间隔多长 | 回访记录 |
| 回来时有没有察觉变化，察觉到的是哪一件 | 访谈 |
| 回来后是继续创造，还是只是看看 | 回访记录（每次的创造次数）+ 访谈 |
| 有没有自己发现长按、发现鱼长大了 | 访谈 |

首轮只作描述，不设门槛。
