# 日记式测试：一周回访（02 §5.6）

主持测试每人只测一次，回答不了「会不会自己回来」。这里补一个轻量的测试：3–5 人在**自己的手机**上用一周，看他们自然回来了几次、回来时看到了什么、说了什么。

## 原则

- **不催促、不提醒。** 一周里不发消息问「今天玩了吗」。提醒会污染「自然回来」这个信号。
- **不讲机制。** 不提鱼会长大、离开时会发生事情、长按能看见那一笔。
- 只说：「这是一个小东西，你想打开就打开，不想打开也没关系。一周后我们聊十分钟。」

## 准备

1. 招募 3–5 人：成年、没参加过主持测试、没看过演示（[招募.md](招募.md) 的排除条件同样适用）。
2. **所有参与者都把它加到主屏幕**（2026-10-26 决定：入口条件统一，日记不达标时才能区分「缺少陪伴价值」和「入口障碍」，见[验证路线图](../验证路线图.md) §7）。顺序不能反：
   1. 在对方手机的浏览器里打开测试网址（不要加 `?fresh`）；
   2. **先**「添加到主屏幕」（iPhone：分享 → 添加到主屏幕；Android：菜单 → 添加到主屏幕 / 安装应用）；
   3. **从主屏幕图标打开**，在图标里画第一笔。之后也只从图标打开。

   原因：iPhone 上从主屏幕图标打开的网页，存储可能和浏览器里的是分开的（以真机验证为准）。在浏览器里画了第一笔再加图标，图标里会是一个空的世界，回访记录也会分在两处。
3. 当场让对方画第一笔（在图标里），然后就不再介入。
4. 记下开始日期和对方的匿名代号（P01…）。

## 一周后

1. 先访谈，再导出（访谈时手机还在对方手里）：
   - 这一周你打开过它吗？大概几次？什么时候想到打开的？
   - 打开的时候，有没有发现什么变化？（**先问开放的，不要提具体机制**）
   - 有没有哪条鱼你特别记得？为什么？
   - （最后再问）你知道长按鱼会怎样吗？
   - **实物意愿**（02 §14，放在最后，前面的问题问完再问）：
     - 如果能把你的湖，或者其中一条鱼，印成一张真的卡片或画，你会想要吗？为什么？
     - 是想留给自己，还是想送给谁？
     - 你觉得这样一件东西大概值多少钱？有什么顾虑？
     - 记录原话。**口头意愿不等于会付钱**：这些回答只用来理解动机和价格预期，不当作购买率。
2. 请参与者**自己**从主屏幕图标打开，点右上角「···」→「测试记录」（只有从图标打开时才有这一项；从浏览器打开时用 `/?study` 地址）：页面上写着记录了什么、没记录什么，以及各项计数。参与者填写编号后自己选择导出，也可以不导出或删除记录。（备用：研究人员在场时也可以用 `?mod` 面板的「导出回访记录」，但要先征得同意。）
3. 记录只有：每次打开的时间、停留时长、做了几次创造、事件类型和时间，以及来自哪个版本。**没有画的内容、没有写的字、没有名字和链接。**
4. 日记测试的参与者完成上面全部步骤后，才可以参加送鱼（[送鱼实验说明.md](送鱼实验说明.md)），不能更早。

## 看什么

| 问题 | 来源 |
|---|---|
| 一周里自然回来了几次，间隔多长 | 回访记录 |
| 回来时有没有察觉变化，察觉到的是哪一件 | 访谈 |
| 回来后是继续创造，还是只是看看 | 回访记录（每次的创造次数）+ 访谈 |
| 有没有自己发现长按、发现鱼长大了 | 访谈 |
| 想不想把作品变成实物，自用还是送人，心理价位与顾虑 | 访谈（02 §14，只作需求探索） |

首轮只作描述，不设门槛。
