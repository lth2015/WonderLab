## 今天的问题与教训

1. **样式表漏了右括号（Claude 的失误）**：上午解决 styles.css 合并冲突时少了一个 `}`，其后的规则全被嵌套进去：难语点线、♪ 按钮大小、「試遊会」小标在线上都没生效。构建不报错，所以一直没发现。晚上做 1A 时构建失败才查出。已修，并加测试检查括号是否闭合（#159）。以后解决 CSS 冲突后要跑这项测试。
2. **白纸闪烁**：同一个 SVG 元素上同时有定位 `transform` 和 CSS 动画，动画把位置覆盖了。原则：**外层负责定位、内层负责动画**。已用脚本查过全场景，没有同类问题。
3. **部署卡住**：两次遇到集群旧 Pod 不退出（`1 old replicas are pending termination`）。等几分钟后重试就好，站点期间一直正常。
4. Codex 云端访问 want.world 会被拦（403），线上复验统一由 Claude 做。
