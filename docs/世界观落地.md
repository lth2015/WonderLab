# 世界观落地路线

> 2026-10-29 起草（Claude）。世界观由 Codex 编写，维护在分支 `codex/wonderful-world-values` 的 `value/` 目录；所有者已认可，并请 Claude 接受它、设计路径实现。本文是实现路线，世界本身以 Codex 的文稿为准。

## 一句话

**一念起，万物生。** 人随手留下一个生命，它有自己的日子，也能承载送给朋友的心意。

Codex 用四个字组织创作：**形**（人的动作留在生命的模样里）、**息**（风、水与光使它有自己的生活）、**痕**（后来的变化仍让人认得出来处）、**意**（相处中慢慢生出的意义，也许愿意送给朋友）。画面直接让人看见它们，不讲解词义。

## 落地的原则

1. **从眼前这片湖开始**：世界里的雪山、听雨林、云眠原、海与远方，先以「回声」出现在湖上：一片花、一阵风、一种水色。不一次铺开新地图。
2. **同一条鱼贯穿**：每加一种景色，都要让已有的生命多显露一点，而不是只多一样东西。
3. **人先动，世界才回应**（产品原则「画是主角，写是魔法」）。新生灵和远方以世界回应的方式到来，不抢用户的创造。
4. **每一批都可单独上线**，按发布流程走：分支 → CI → 部署到 want.world 验收 → 合并 → 打标签。

## 三根线，三批实现

对应 Codex 文稿 09 §十六的三根线：沿着一个生命、沿着一个地方、沿着一份心意。

### 第一批：同一个生命，在不同光阴里被看见（沿着一个生命）

Claude 实现，2026-10-29 夜。

| 片段（09） | 做什么 |
|---|---|
| §三 落日 | 鱼游进落日的金色光路，背上泛一层金；出了光路又慢慢暗回去 |
| §四 月夜 | 每条鱼有自己的偏爱：有的贴着月光路的中央，有的在外缘；人慢慢能从位置认出它们 |
| §五 荷塘 | 鱼经过荷叶下时慢下来，像在凉荫里歇一会儿 |
| §十一 河灯 | 鱼从河灯下游过，烛光在水里晃一下 |
| §十 星河与流星 | 天上落下的小金鱼，和一条画出来的鱼同行一段，再各走各的 |

已经有的根：白天画圆是太阳、夜里是月亮（同一个圆，09 §二）；月下跃鲤与鱼背银光；荷塘、河灯、流星入湖。

### 第二批：一处地方，照应许多生活（沿着一个地方）

| 片段（09） | 做什么 | 分工 |
|---|---|---|
| §十三 近岸 | **近岸花枝**（2026-10-29 原型已上线，网址加 `?shore`；待所有者看过再定手势、存档与是否默认开启）：人在水边画一笔，这一笔就是枝干（保留墨线），花沿枝开；花瓣落进水里，鱼来碰散花影；黄昏有蝶停在枝上，夜里萤火从花间起 | Codex 定花与蝶的种类、出图（交接文件 `collab` 分支 `docs/handoff/codex-shore-branch-art.md`）；Claude 设计手势、实现、接入 |
| §十二 重逢 | **远处的旧鱼轮流回来**（02 决策 12 的后半）：湖满以后去了远处的鱼，平时轮流游回来；再见时认得出它的笔性 | Claude |
| §九 春花与秋叶 | 有了花枝以后，落花有了近处的来处：花瓣从枝上落下，而不只是从天上飘来 | Claude |

花枝的手势需要设计：现在湖上的笔画是鱼，天上的笔画是月亮、星或流星。候选做法是从屏幕左右下角的岸边向湖里斜着画出的一笔（起笔落在岸边区域）。手势定稿前会先做原型，再请所有者确认。

### 第三批：远方与心意（沿着一份心意）

需要所有者决定是否展开，以及新美术。

- **新生灵作为世界的回应**（06 生灵博物志）：舟背龟在荷叶旁的浅水停下，听雨蜗在雨里沿近岸的叶子走，衔花雀落在花枝上。它们不是用户画的，是世界的回应，也不计入湖里鱼的上限。
- **赠予的世界解释**（09 §十四）：送出的那一笔在朋友的天地里重新出现，两边各自生长。现有送鱼实验的语义保持不变，只在文案和画面上照应「同源而各自生活」。
- **远方的回声**：雪山的清水、海上的风，以季节和天气的细节出现在湖上，不新开画面。
