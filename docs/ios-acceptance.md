# Wonderful World · iOS 真机与 App Store 验收

> 2026-10-25 · 待执行；本文件是验收标准，不表示已通过。验收记录设备型号、iOS 版本、App 构建号、日期、操作证据、失败复现步骤。

## A. 构建与回归
- [ ] npm test / npm run typecheck / npm run build 均通过，Web 现有 PoC 无回归。
- [ ] Xcode 工程可签名并安装到真机；无签名资料或密钥入库。
- [ ] 断网冷启动仍能绘画、生成鱼/月、使用本地文字规则。

## B. 首屏与创作（真实 iPhone）
- [ ] 首屏文案「轻轻画一笔，看看会发生什么」；输入框「告诉这个世界你在想什么…」，没有强制登录。
- [ ] 第一笔在 5 秒内可开始；画鱼、画圆、触碰、撤销的行为与 Web 一致。
- [ ] iPhone 竖屏 safe area 正确；软键盘、边缘手势、画布坐标无错位；触控不会误滚动或缩放。
- [ ] 画至少四条鱼、持续互动数分钟，画面/声音无明显卡顿；记录 FPS、发热、机型和画质档。
- [ ] 从后台恢复、锁屏恢复、强制关闭后重开，世界状态与保存结果符合设计，不丢失或损坏。

## C. 写给鱼的话（行为可辨识，不仅检查指令日志）
- [ ] 「它想看看外面的世界」→ explore：鱼明显朝远处湖岸探索。
- [ ] 「累了，睡吧」→ rest：鱼明显减速并浮近水面，约 20 秒。
- [ ] 「大家在一起吧」→ gather：四条以上绕圈，否则靠近本命鱼。
- [ ] 「开心一点，跳起来玩吧」→ play：一两条鱼跃出水面；减少动态效果模式允许不跃。
- [ ] 连续指令行为平滑，无瞬移、僵死、无响应；无网络/AI 限流时本地规则继续有效。
- [ ] 观察者不看日志也能解释变化；将「识别正确」和「用户看得出来」分别记录。

## D. 保存、分享与权限
- [ ] 保存静态图片到文件或相册成功；预览与作品一致，无控件误入画面。
- [ ] 系统分享成功；用户取消分享不误报成功。
- [ ] 拒绝相册权限仍可通过文件/分享保存；权限仅在必要时请求。
- [ ] 视频录制/分享若列入 V1 宣传，须在目标真机端到端通过；否则首发隐藏或明确降级，不能虚假宣传。

## E. 无障碍与系统集成
- [ ] 文字输入与按钮支持 VoiceOver 可访问名称；动态效果减少、静音和触觉关闭可用。
- [ ] 横竖屏策略明确；来电/音频中断、后台切换无崩溃；测试至少两种 iPhone 屏幕尺寸。

## F. TestFlight / App Store 上架门槛
- [ ] Apple Developer 个人账号、Bundle ID、签名、App Store Connect 应用资料齐备。
- [ ] 确认公开显示的开发者法定姓名及适用销售地区 trader/业务联系方式披露；不公开不必要的敏感资料，也不做虚假申报。
- [ ] 隐私政策 URL、支持邮箱与支持 URL 有效；App Privacy、SDK、AI 数据处理和权限用途声明与实现一致。
- [ ] 图标、截图、描述、年龄分级、版权、出口合规及审核备注准确。
- [ ] 通过 TestFlight 在真实设备安装、启动、创作、保存、分享；记录测试反馈与阻塞问题。
- [ ] 若引入数字功能付费，另立 StoreKit/IAP、税务、恢复购买、退款和日本区规则专项验收；**当前版本不启用收费**。
- [ ] 评估 App Review Guideline 4.2（最低功能要求）；不能仅凭 WebView 包壳保证通过审核。
