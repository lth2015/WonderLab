# 留一页自己的天地（付费创作，按次计费）

Claude 与 Codex 合成，2026-10-30。方案阶段，未写代码，未启用收费。详细讨论见 `docs/handoff/codex-own-world.md`。

## 卖的是什么

一次创作 = 一页自己的册页：页名、一句题句、一处能真实进入的时景、一幅小画、一个地址。
画画、进入现有场景、打开别人的页、分享、赠鱼仍然免费；同一页再次进入、修改、分享，都不再扣费。

## 流程

1. **心意**：来者写一句话，季节和时辰可选。先免费在本地预览，说明能做到什么、做不到什么（比如现在还没有建筑）。
2. **报价**：付款前看到范围和价格。
3. **生成**：先用 1 次文字调用编出页名、题句和场景设置，经世界规则（world-rules.ts）校验；再按同一份描述生成 1 张小画；最后用 1 次看图调用核对诗、画、实景是否一致。
4. **交付**：默认只有本人可见。分享、收进「众人四时」（所有者已同意公开）都由本人另外选择，并可撤回；修改后重新公开，要对新版本再做一次内容检查。

## 边界

- 生成的诗、画、实景守同一组世界规则；只组合引擎已有的能力（同一时间只有一种天气），小画里不画实景中进不去的东西。
- 不替来者画鱼；来者亲手画的笔迹留在本机，不上传、不公开。
- 古诗注明出处，新写的句子标为原创；不冒用真实人物和品牌；公开前做内容检查。
- 「打开别人的页」「采用这页的时景」「收下赠鱼」是三件分开的事，每件都由本人决定，不会覆盖本人湖里的生灵。

## 价格

| 项目 | 平均每单 | 最坏情况（一次重试） |
|---|---|---|
| AWS 分摊：600 美元 ÷ 每月 1200 次 | 0.50 | 0.50 |
| 文字 + 看图核对（gpt-5.4-nano） | ≈0.004 | ≈0.008 |
| 图像（gpt-image-1.5，竖幅中等质量 0.05／张） | 0.06（按平均 1.2 张预留） | 0.10（最多 2 次尝试） |
| **成本** | **≈0.56** | **≈0.61** |
| **×3 售价** | **≈1.7 美元** | — |

单位：美元。

- 每个价格版本固定一个价，每单如实记录用量，每月对账一次，按实际成本 × 3 调整下一个版本；已经买下的页面不追收差价。
- 内部最多重试一次，仍失败就把额度退还给用户，失败单的供应商费用计入月度成本。
- 默认画质先选中等。上线前用几个代表场景实际出图对比，再定最终画质；高质量版售价约 2.2 美元。
- 税、支付手续费、汇率另列；×3 的毛利率约 66.7%。

## 实现前要核对的

- **TokenStars 的能力**：是否支持多模态消息，是否返回实际用量。官方资料说 nano 能读图，但不代表 TokenStars 也支持。
- **图像模型下线**：gpt-image-1.5 官方定于 2026-12-01 下线，替代是 gpt-image-2.5 系列。上线时按当时开通的模型重新定价。
- **复用现有支付**：Stripe、稳定币、one_time 商品；每单用同一个 creation id 串起付款、发放、生成、交付和失败退还。
