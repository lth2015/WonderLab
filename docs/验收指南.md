# 验收指南（2026-10-27 周一）

上次验收之后，画面、互动、声音和测试工具都有不少变化。这份指南按「打开 → 看 → 判断」排好顺序，大约 30–40 分钟。每一项后面写着怎么操作、看什么；看完在方框里打勾，或者把意见记在旁边。

## 0. 准备（5 分钟）

```bash
git checkout main && git pull
npm ci
npm run dev            # 只看画面和互动
npm run server         # 另开一个终端：要试「一句成境」的 AI 时才需要（.env 里有 TokenStars 和 INVITE_TOKENS）
```

- 桌面：打开 http://localhost:5173/?fresh 。要用 AI 时，第一次打开 `http://localhost:5173/?fresh#invite=<你的令牌>`。
- 手机（同一 Wi-Fi）：`npm run dev -- --host`，用它打印的 Network 地址加 `?fresh` 打开。
- 声音：电脑音量开到中等。

`?fresh` 每次都从一个全新的世界开始；验收时随时可以加上它重来。

## 1. 第一眼（不要动，先看 15 秒）

- [ ] 画面能当壁纸吗：夜湖、远山、星空，留白足够
- [ ] 约 0.6 秒后出现「轻轻画一笔，看看会发生什么」；4 秒不动会有一条示范的淡淡虚影鱼；输入框里是「告诉这个世界你在想什么…」
- [ ] 右上角三个图标（声音、录制、更多），底部输入框；没有其它说明文字

## 2. 互动（这次重点）

| 试什么 | 怎么做 | 看什么 |
|---|---|---|
| 落笔 | 在湖面按住不动 | 立刻出现一个**圆形墨点**，边缘有一点晕开（以前是方块） |
| 化鱼 | 在湖面画一条弯线 | 墨线化成锦鲤（照片质感贴图、半透明的鳍、水下的影子） |
| 结伴同游 | 画 3–4 条鱼，看半分钟 | 鱼会**两两结伴、一起游一段又分开**；有的鱼喜欢独处 |
| 触碰 | 点一条鱼；很快再点同一条 | 受惊游开；再点会跃出水面 |
| 湖面 | 点空白水面 / 长按 | 涟漪；附近的鱼游过来 |
| 月亮 | 在天上画一个圆 | 月亮升起，湖面出现一道被打碎的月光（浮光跃金） |
| 星球 | 有月亮后再画圆 | **水墨淡彩的小星球**（石青、赭石、藤黄），最多 3 个 |
| 天空 | 在天上点 / 短划 / 长划 | 星星闪烁 / 一颗星 / 流星 |
| 一句成境 | 输入「今夜下一场小雨」回车 | 文字化墨点飘上天，开始下雨，雨声渐入；稍后出现一句古诗，**不会压在月亮上** |
| 写给鱼的话 | 有几条鱼后，输入「它想看看外面的世界」/「大家在一起吧」/「累了，睡吧」/「跳起来玩吧」 | 鱼各自游向远处 / 聚成一圈或聚到第一条鱼身边 / 慢下来浮上水面 / 一两条跃出水面；**文字不会变出新的鱼** |
| 撤销 | 创造后旁边的小墨点；或 Ctrl/⌘+Z | 刚才的东西墨散消失 |
| 光标（桌面） | 鼠标在画面上移动；移到鱼或月亮上 | **毛笔笔尖**光标；在鱼和月亮上变成墨点 |
| 提示 | 画一条鱼后什么都不做 | 「点一点小鱼」；没理它的话，约半分钟后**再出现一次**，之后不再出现 |

### 时间与回访（02 §5.6）

- [ ] 长按一条你画的鱼：当初那一笔在水面上重画一遍，鱼游回收笔的地方，墨迹再化入水中；长按空白水面仍是鱼游过来
- [ ] 画几条鱼，关掉页面，半小时后再打开：世界里多了一件小事（一颗星，或第一条鱼回到了它出生的地方）；没有任何弹窗或文字
- [ ] 刷新页面：世界原样，不会每次刷新都多出东西
- [ ] 几天后再打开：鱼略大了一点（不必刻意找，看得出来更好）

### 送一条鱼（原型，只在 `?giftlab` 下；02 §5.7）

用两台设备（或电脑上两个不同的浏览器）：

- [ ] A 打开 `?fresh&giftlab`，画一条鱼，长按它 → 「送给朋友」 → 落款填一个字 → 发送（或复制链接）
- [ ] B 打开这个链接：远处水面上出现 A 的那一笔，末端有落款，化成一条鱼在湖边游；「一条鱼游到了你的湖边」
- [ ] B 不点：鱼一直在湖边游；刷新后它不在了
- [ ] B 轻触水面：鱼游进来；刷新后还在；长按它能看到 A 的那一笔和落款
- [ ] B 再打开同一个链接：「它已经在你的湖里了」，不会多出一条
- [ ] B 长按收到的鱼 → 「让它游向远方」：鱼游远、淡去，刷新后不在了
- [ ] 仪式感：B 第一次看到时，是觉得「收到了礼物」，还是「出了什么问题」？「轻触水面」能自己想到吗？

## 3. 声音

- [ ] 第一笔之后，水声和远处虫鸣慢慢淡入（不刺耳、不抢戏）
- [ ] 化鱼是一声水滴，月升是一声磬，星星是高音；连点时不会吵
- [ ] 下雨时雨声随天气渐入
- [ ] 右上角喇叭能关掉，刷新后仍是关的

## 4. 保存与分享

- [ ] 「录制」：3-2-1 倒计时，录 15 秒；预览里有画面、诗句、右下角「万象」印章，**没有按钮**；声音开着时视频有声音
- [ ] 「更多 → 保存为壁纸」：得到一张高清 PNG
- [ ] 手机上旋转屏幕：画面淡出再淡入，鱼还在

## 5. 主持测试工具（给阶段 D 用）

- [ ] 用 `?fresh&mod` 打开；手机上在左上角快速点 5 下，出现「主持人」面板（开始自由段 / 导出日志 / 换下一位）
- [ ] 不带 `?mod` 时，左上角点 5 下什么也不发生
- [ ] 读一遍 [testkit/README.md](testkit/README.md) 和主持人手册

## 7. 自动检查（不用你做，已经通过）

单元测试、数据库测试、类型检查、打包、Docker 镜像构建，每个 PR 都由 GitHub CI 自动跑（项数随功能增加，以 CI 结果为准）。可量化的验收项（控件面积、点击区域、对比度、键盘操作、软键盘、录制内容）记录在 [03 §14](03-ux-ui-design.md) 末尾。
