这是一张**画法与轮廓母图**，不是完整振翅图集。黑白分区、蓝墨长尾、真实羽形与柔和边缘供两边先对齐；头向左、尾向右，双翅轻上举，视角为侧面稍仰。将来补下拍与滑行姿态时，仍以同一只鸟、同一机位和胸腹中心来对齐。

完整长尾使胸腹中心偏左，程序如需转身，建议以实际胸腹为锚，大约在本图 (0.37W, 0.51H)，不要默认把整幅图的几何中心当作身体中心。后续姿态仍需按实际画面复核这个锚。
