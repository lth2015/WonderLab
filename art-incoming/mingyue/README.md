目前已交付**同体三姿候选**，供 Claude 选取与接入。最初的画法与轮廓母图保留：黑白分区、蓝墨长尾、真实羽形与柔和边缘；头向左、尾向右，视角为侧面稍仰。后两姿以它为参考，保留同一只鸟、机位、头与尾的朝向，再改变翅姿。

完整长尾使胸腹中心偏左，程序如需转身，建议以实际胸腹为锚，大约在本图 (0.37W, 0.51H)，不要默认把整幅图的几何中心当作身体中心。后续姿态仍需按实际画面复核这个锚。

本轮使用 image_gen 生成。源图保留，交付图仅做等比尺寸归一与透明留边；尺寸为 512×512，alpha 范围 0–255，四边有透明留白。已看完整鸟形，喙、翼尖与尾尖均在画面内；也已在浏览器浅底、深底和小尺寸下检查，未见明显实底白框或亮边，长尾与黑白翼区在小尺寸仍可辨。

头部区域的最佳匹配平移分别为源图 1px／0px 和 0px／0px，检查记录在 pose-alignment-check.json。这仅说明头部对齐较稳定，胸腹、翼根与飞行过程仍应在实际切帧里核对。

检查图没有套用引擎的夜间光照；接入时让白羽与黑羽一起受到当前时景影响。三张候选都看过完整鸟形、透明边缘及小尺寸，预览页面可解码切换，无页面错误；当前不把它写成引擎动画已验收、已上线或所有者已经确认。

简单预览使用上举—滑行—下拍—滑行的切换，仅供对照身体与轮廓。真正飞行仍让它先短扑几下，再有一段滑行，由 Claude 决定节奏与帧序。停姿等真正有合适承重位置的场景再补。树与承重枝留在画外，避免为了展示鸟而重建孤立的粗枝。

## 放回柳景看尺度

scene-scale-preview.html 使用 Claude 已交付的 claude-v4-day-still.jpg 与 claude-v4-moon-still.jpg。背景仍是静帧，鸟为原 PNG 的浏览器显示；没有改动任何源图，也没有把两幅图的排版伪装成实际引擎画面。

以 alpha > 32 的轮廓计，三姿的可见宽分别为 436、437、436px，约占 512px 画布的 85%。因此 390px 手机画幅内可见约 30px 的近鹊，对应整张透明方图约 35.2px；远处可见 16px 对应方图约 18.8px。使用统一比例，不按每帧包围盒缩放，以免扑翼时身体呼吸般变大变小。

静态对照的近处身体位置为 (0.65W, 0.19H)，远处为 (0.17W, 0.26H)，都在山线上方。近处黑白长尾可认，远处可以只留掠影；实际起飞仍从树冠深处来，入画处需要真实的柳叶遮挡，不能让鸟一直像贴在柳叶前面。

月夜原始白羽偏醒目，CSS 明度 0.58 的对照更接近周围柳、水的重量。这只是给 Claude 判断的视觉参照，不能直接复制成引擎 uniform；最终仍应受当前天色、空气与远近影响。预览中的位置滑块不代表飞速曲线，三姿也未在实际引擎中验收。
